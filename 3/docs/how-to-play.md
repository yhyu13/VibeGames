# Alien Invader (no React) — How to Play

> The same premise, stripped of React entirely: a bare Three.js invasion loop.
> You are the invader; Earth hardens, resists, and fights back.

## Quick start

```bash
npm install
npm run dev      # open the printed localhost URL
```

## Controls

| Input | Action |
|---|---|
| `W` / `S` | Thrust forward / backward |
| `A` / `D` | Strafe |
| `Space` / `C` | Move up / down |
| `Shift` | Boost (2.2×) |
| `1` / `2` / `3` | Cycle weapons |
| Left mouse | Fire |
| Right mouse | (held for secondary action) |

## How a run works

Seven escalating days: an adaptive counter-engine reads your habits and
telegraphs its answer. Real-time combat vs. Earth's defense grid, then the
choice between annihilation and infiltration (propaganda / virus puzzle
phases). Win by destroying all key targets or by breaking Earth's resolve.
