# 纯白枪骑兵 重制版 — 设计文档

## 1. 概述

基于原版《纯白枪骑兵》Flash 游戏的 3D 第三人称空战射击重制版，使用 KIMI3 技术栈开发。

## 2. 技术栈

| 层次 | 选型 | 说明 |
|------|------|------|
| 语言 | TypeScript (strict) | 全量类型检查 |
| 框架 | React 19 | UI 层 |
| 渲染 | Three.js (WebGL) | 3D 场景渲染 |
| 特效 | WebGL2 (post-processing) | Bloom、辉光、粒子 |
| 样式 | Tailwind CSS | UI 样式 |
| 构建 | Vite | 开发/生产构建 |
| 音频 | Web Audio API | 程序化合成，零音频文件 |
| 状态 | Zustand | 全局状态管理 |
| 物理 | 自定义 | 简单碰撞检测 |

## 3. 核心玩法

### 3.1 基本操作
- **WASD**: 前后左右移动
- **鼠标**: 瞄准
- **左键**: 射击
- **空格**: 闪避/冲刺
- **Q/E**: 技能1/技能2
- **R**: 大招/必杀技
- **数字键 1-4**: 切换武器
- **Tab**: 锁定目标切换

### 3.2 游戏模式
- **PVE 模式**: 波次生存 + Boss 战
- **1v1 模式**: 本地分屏对战（上下分屏）

### 3.3 武器系统（6种）
| 武器 | 特性 | 解锁条件 |
|------|------|----------|
| 光束机枪 | 快速连射，基础伤害 | 初始 |
| 导弹发射器 | 追踪导弹，自动瞄准 | 等级 2 |
| 光束加农 | 蓄力高伤，穿透效果 | 等级 3 |
| 散射弹幕 | 扇形扩散，近距离爆发 | 等级 4 |
| 狙击光束 | 远程高伤，穿透敌人 | 等级 5 |
| 浮游炮 | 自动攻击，多目标 | Boss 掉落 |

### 3.4 技能系统（每个玩家可选 3 个）

| 技能 | 效果 | 冷却 |
|------|------|------|
| 护盾 | 生成 3 秒无敌护盾 | 15s |
| 时间减速 | 周围敌人减速 50% | 20s |
| 全弹发射 | 所有武器同时攻击 | 30s |
| 修复 | 恢复 30% HP | 25s |
| 电磁脉冲 | 范围内敌人眩晕 3 秒 | 25s |
| 推进爆发 | 3 秒内移速 x3 + 无敌 | 20s |

### 3.5 必杀技（气力槽满时释放）
- **全屏光束**: 大范围高伤害扫描
- **卫星轨道炮**: 单目标极高伤害
- **分身突击**: 召唤 3 个分身协同攻击

## 4. 敌人 AI 系统

### 4.1 常规敌人类型
| 类型 | 行为 | 难度 |
|------|------|------|
| 侦察兵 | 直线巡逻，发现玩家后追踪 | 简单 |
| 突击兵 | 高速冲向玩家，近距离开火 | 中等 |
| 狙击手 | 保持距离，精准射击 | 中等 |
| 护盾兵 | 正面护盾，需要绕后 | 困难 |
| 自爆兵 | 高速冲向玩家自爆 | 中等 |
| 指挥官 | 指挥周围单位，提供 buff | 困难 |

### 4.2 AI 状态机
每个敌人使用 FSM（有限状态机）：
```
IDLE → PATROL → ALERT → CHASE → ATTACK → COOLDOWN → (loop)
                                      ↓
                                  FLEE (低血量时)
```

### 4.3 Boss 设计（3 个 Boss）
| Boss | 阶段 | 攻击模式 | 掉落 |
|------|------|----------|------|
| 巨型运输舰 | 3 阶段 | 弹幕散布、召唤小兵、轨道炮 | 浮游炮 |
| 实验体-α | 3 阶段 | 高速突进、分身攻击、全屏激光 | 必杀技升级 |
| 最终兵器 | 4 阶段 | 多重导弹、力场护盾、终极光束 | 传说武器 |

## 5. 多人模式

### 5.1 本地分屏 1v1
- 上下分屏，各占一半屏幕
- 每个玩家独立摄像机、独立 HUD
- 键盘 WASD + 鼠标（玩家1）
- 方向键 + 鼠标/键盘（玩家2）
- 可选项：地图、时间限制、生命值

### 5.2 对战规则
- 3 局 2 胜
- 每局限时 3 分钟
- 时间到则 HP 高者胜
- 可拾取地图上的道具（护盾、加速、回血）

## 7. 视觉风格

- 3D 第三人称视角，摄像机跟随玩家
- 明亮的太空/城市背景
- 机甲使用程序化几何体生成（BoxGeometry + CylinderGeometry 组合）
- 弹道使用发光线条/球体（MeshBasicMaterial + Emissive）
- 粒子系统：爆炸火花、尾迹、命中特效
- 后处理：Bloom（辉光泛光效果）
- 颜色方案：蓝/青（玩家）、红/橙（敌人）、紫（Boss）

## 8. 音频设计

全部使用 Web Audio API 程序化合成：
- 射击音效：OscillatorNode 短脉冲
- 爆炸音效：Noise + 衰减
- 引擎声：低频振荡器
- BGM：循环音序（节奏+和弦）
- 命中音效：短促高频
- 语音提示：合成语音（Boss 出场、必杀技）
