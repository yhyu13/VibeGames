## 1. 概述

基于原版《纯白枪骑兵》（phixcat, 2008, Flash 第一人称空战射击）的 3D 第三人称空战射击重制版，使用 KIMI3 技术栈开发。核心体验：在 3D 空间中自由飞行的机甲，鼠标瞄准、全向弹幕对抗、波次生存 + Boss 战。

## 3. 核心玩法

### 3.1 基本操作（对齐原作，`reference/d.md`）

| 输入 | 功能 |
|------|------|
| **WASD** | 前后左右移动（全 3D 飞行，速度矢量积分） |
| **Shift / Ctrl** | 上升 / 下降（垂直轴） |
| **鼠标** | **武器准星（核心）**：相对增量控制；锁定时可围绕目标扭摆准心打提前量 |
| **左键** | 射击（按武器 `fireRate` 冷却） |
| **空格（按住）** | 引擎助推（加速，带喷气火焰特效） |
| **空格（双击）** | 闪避冲刺：沿 **WASD 输入方向**（无输入则沿机头朝向）短时高速位移 + 无敌帧 + 多重残影，冷却 2.5s |
| **E** | 急停（强减速制动） |
| **数字键 1-4** | 切换武器 |
| **Tab** | **锁定切换**（切换制）：锁定范围内最近敌人；机头自动面向目标，助推/闪避时解锁 |
| **Z** | 必杀技（气力槽满时） |
| **Esc / Enter** | 暂停 |

> **机头朝向优先级**：锁定目标 > 鼠标准星方向；助推/闪避期间解锁为自由瞄准。

### 3.2 游戏结构（Roguelike 选关地图，v1.6 定案）

**一局 = 一次地图行军**：从起点出发，在 4 层节点图中逐层选择路径，每层 2-3 个节点选 1 个，第 4 层为最终 Boss。**清场过关 = 胜利**（有「赢」的状态）；阵亡 = 本局结束。

| 节点类型 | 内容 | 风险 / 回报 |
|----------|------|-------------|
| 普通战 | 标准波次（2 波） | 低风险 / 基础奖励 |
| 精英战 | 3 波强化敌人（数量 ×1.5、血量 ×1.3）；小概率刷**实验体-α 弱化版**（分身攻击） | **高风险高回报**：奖励三选一 |
| 补给 | 回血 / 本局强化选择（无战斗或迷你战） | 无风险 / 战术选择 |
| 乱入 Boss（隐藏） | **巨型运输舰**：地图不显示；玩家只被告知一个 Boss；第 2 层首场战斗第 1 波清完后**警报 + 突然入场** | 资源消耗 / 高价值三选一 |
| 最终 Boss（第 4 层） | **最终兵器**（多重导弹/力场护盾/激光网/终极光束） | 过关 = 本局胜利 |

> **资源焦虑设计（v1.7）**：① 地图只画一个 Boss（最终兵器），玩家按「一个 Boss」规划资源；② 乱入 Boss 中途吃掉一波资源（HP/强化机会）；③ 补给节点有限且选路可能错过；④ 最终 Boss 前无强制补给、不预告强度——「我够不够格」由选路决策决定。

**奖励分层**（v1.6 起为**纯 Roguelike**——所有局内获得死亡清零，仅初始武器常驻）：
- **初始武器**（常驻）：1-3 号基础武器始终可用（对应原作「初期 3 部弱机体」），等级恒为 1
- **武器解锁**（仅本局）：精英/过关奖励解锁 4/5/6 号，死亡后消失
- **武器升级**（仅本局）：提升已持武器的伤害/射速等级，死亡后消失
- **本局强化**（仅本局）：伤害倍率 / 射速倍率 / 最大 HP / 移速，可叠加
- **回血**：恢复 HP

**决策导向「下一局」**：MapScreen 展示全程 4 层路线图，选路 = 前瞻规划（何时该打精英、何时留补给）；死亡不带走数值，但带走**路线经验与武器熟练**——玩家决策时优先想「这条路线下一把怎么走更赚」。

**流程**：主菜单 → 选关地图（MapScreen，全图预览）→ 节点战斗 → 回地图（发放奖励）→ … → 最终 Boss → 胜利结算。

### 3.3 武器系统（6种）

| 武器 | 特性 | 解锁条件 |
|------|------|----------|
| 光束机枪 | 快速连射，基础伤害 | 初始 |
| 导弹发射器 | **半制导**：锁定中持续追踪，破锁/机动变直弹 | 等级 2 |
| 光束加农 | 蓄力高伤，穿透效果 | 等级 3 |
| 散射弹幕 | 扇形扩散，近距离爆发 | 等级 4 |
| 狙击光束 | 远程高伤，穿透敌人 | 等级 5 |
| 浮游炮 | 自动攻击，多目标 | Boss 掉落 |

> **半制导模型（v1.4 定案）**：导弹在「锁定中」每帧转向目标；一旦破锁（Tab 切换、助推、闪避、目标死亡/超程）立即变直弹。锁定中扭摆准星 = 修正导弹初始朝向（打提前量），与「鼠标=准星」模型同源。

> 当前状态：玩家初始持有 1-3 号武器；4-6 号解锁路径未实现（见实施计划「遗留问题」）。

### 3.4 机动系统（替代原「技能系统」）

| 机动 | 效果 |
|------|------|
| 引擎助推（空格按住） | 加速（速度上限 x2.5）+ 喷气火焰特效 |
| 闪避冲刺（双击空格） | 沿 **WASD 输入方向**（无输入沿机头）短时高速位移 + 无敌帧 + **多重残影**（Sandevistan 风格），冷却 2.5s |
| 急停（E） | 强阻尼，快速刹停 |
| 必杀技（Z） | 气力槽满（100）时释放，全屏光束 AOE |

### 3.5 必杀技（气力槽满时释放，Z）

- **全屏光束**（已实现）：大范围高伤害扫描
- **卫星轨道炮**（计划）：单目标极高伤害
- **分身突击**（计划）：召唤 3 个分身协同攻击

## 4. 敌人 AI 系统

### 4.1 常规敌人类型

| 类型 | 行为 | 难度 |
|------|------|------|
| 侦察兵 | 直线巡逻，发现玩家后追踪 | 简单 |
| 突击兵 | 高速冲向玩家，近距离开火 | 中等 |
| 狙击手 | 保持距离，精准射击 | 中等 |
| 护盾兵 | 正面护盾，需要绕后 | 困难 |
| 自爆兵 | 高速冲向玩家自爆 | 中等 |
| 指挥官 | 指挥周围单位，提供 buff | 困难 |

> 全 3D：敌人与玩家同处 3D 空间，生成时带高度差，追击/射击使用 3D 向量。

### 4.2 AI 状态机

每个敌人使用 FSM（有限状态机）：
```
IDLE → PATROL → ALERT → CHASE → ATTACK → COOLDOWN → (loop)
                                      ↓
                                  FLEE (低血量时)
```

### 4.3 Boss 设计（3 个 Boss，v1.7 分工）

| Boss | 阶段 | 攻击模式 | 出场 |
|------|------|----------|------|
| 巨型运输舰 | 3 阶段 | 弹幕散布、召唤小兵、轨道炮 | **乱入中 Boss**（第 2 层首场战斗中途入场，地图不显示） |
| 实验体-α | 3 阶段 | 高速突进、分身攻击、全屏激光 | **精英战变体**（弱化版，分身攻击；精英节点小概率出现） |
| 最终兵器 | 4 阶段 | 多重导弹、力场护盾、终极光束 | **最终 Boss**（第 4 层，地图唯一显示的 Boss） |

> 遗留修复：移除 `currentBossIndex < 0` 循环门控（Boss 2/3 不可达 bug）；`spawnBoss(index)` 显式指定 Boss。

## 6. 视觉风格（对齐原作）

- 3D 第三人称视角，摄像机 3D 跟随玩家（含垂直）
- **纯白机甲**（原作「机体贴图全为白色」）：**白底 + 少量蓝色描边**（蓝仅用于座舱/面罩/推进器光效等小面积点缀，移除大块蓝色装甲板）
- **敌人统一橘/红系**（侦察/突击/狙击/护盾/自爆/指挥官均属橙红色相，靠轮廓与明度区分）；**Boss 红白特殊色**（白色主体 + 红色核心/光环）
- **太空背景**：黑幕 + 彩色星野 + 白色云层地球 + 橙色太阳（程序化球体 + 点光源），**无地面/网格**（2D 平面残留已移除）
- 弹道使用发光线条/球体（MeshBasicMaterial + Emissive）；敌方弹幕继承敌人橘/红系
- 粒子系统：爆炸火花、命中特效、助推喷气火焰、闪避多重残影、**太空尘埃流**（速度感参照）
- 后处理：Bloom（辉光泛光效果，计划）
- **速度感（定案）**：主角 = 方向——**太空尘埃流**（世界静止尘埃自然流过 + 极速流线层）；配角 = 助推时 FOV 外扩（60→72）+ 摄像机拉远（15→20）、受击震屏 + HUD 红闪

## 7. 音频设计

全部使用 Web Audio API 程序化合成：
- 射击音效：OscillatorNode 短脉冲
- 爆炸音效：Noise + 衰减
- 引擎声：低频振荡器（BGM 占位，计划升级为循环音序）
- BGM：循环音序（节奏+和弦）— **计划**，当前为低频嗡鸣
- 命中音效：短促高频
- 助推/闪避音效：上行/下行扫频
- 语音提示：合成语音（Boss 出场、必杀技）— **计划**
