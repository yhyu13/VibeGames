# 纯白枪骑兵 · 怎么玩

> 基于 phixcat 2008 年 Flash 原作《纯白枪骑兵》的 3D 重制版：一台纯白机甲对抗纯黑虚空，WASD 全 3D 飞行、鼠标瞄准射击、锁定、以及留下残影的加速冲刺。

## 快速开始

```bash
npm install
npm run dev      # 打开 http://localhost:3000
```

## 操作

| 输入 | 作用 |
|---|---|
| `W` / `A` / `S` / `D` | 前 / 左 / 后 / 右移动（机头方向） |
| `Shift` | 上升 |
| `Ctrl` | 下降 |
| 鼠标移动 | 瞄准（武器准星；锁定中可小幅预判） |
| 鼠标左键 | 射击（按住连发） |
| `Space` | 按住 = 加速助推（消耗 EN）；300ms 内双击 = 闪避冲刺（短时无敌，带冷却） |
| `E` | 急停 |
| `Tab` | 锁定切换（范围内最近敌人，机头自动转向；助推/闪避时解锁） |
| `Z` | 特殊技能 |
| `1`–`9` | 切换武器（武器 1–3 常驻，4–6 需局内解锁） |
| `Esc` / `Enter` | 暂停 / 确认 |

## 一局怎么打

Roguelite 战争行军：

1. **选路** — 每次出发在四层节点地图上逐层选择路线：普通战 / 高风险的精英战（高回报）/ 稀缺的补给点 / 最终 Boss。
2. **清场过关 = 胜利** — 击杀目标、捡强化、带回升级；奖励分两栏：跨局武器解锁（1–3 号常驻）+ 本局强化与回血。
3. **小心不速之客** — 一个**未预告的中 Boss** 可能中途闯入战斗，烧掉你为终点攒的资源。
4. **死亡代价** — 死亡清空全部局内收益（武器解锁 4/5/6、强化、血量），只保留路径知识；**只有起始 3 把武器跨局保留**。

> 资源焦虑就是设计本身：「我够不够强」这个问题，由你选的路线来回答。
