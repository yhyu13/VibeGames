# 《Boss 的焦虑》— GDD + TDD

> 一句话 pitch：你扮演 RPG 里的最终 Boss，等玩家来挑战你，但真正让你紧张的不是打不打得过 —— 而是"我今天表演够不够精彩"。

---

## 1. 高概念

**Genre**: 动作 + 情感叙事 / 单幕戏 / 5–8 分钟一次循环
**Tone**: 黑色幽默 + 意外的温柔，参考《Gris》《Celeste》的情感密度，但舞台只有一个 Boss 房
**Tension 轴**: 不是"输赢"，而是"我是否被看见"
**Reference**: 情绪层借鉴 *Disco Elysium* 内独白密度；机制层借鉴 *Getting Over It* 的"过程即叙事"

---

## 2. 核心循环

```
等 (Wait) → 察觉玩家 (Sense) → 上场 (Perform) → 自评 (Self-Evaluate) → 循环
```

每一轮约 60–90 秒：
- **Wait**：Boss 独坐王座，翻看"历任挑战者档案"，可以点开看前任玩家怎么评价这场战斗
- **Sense**：玩家从远处走来，Boss 进入"准备态"
- **Perform**：3 个攻击阶段，Boss 必须按"剧本"演，但压力会让他动作变形
- **Self-Evaluate**：战斗结束，无论输赢，Boss 给自己 1–5 星，并写下评语；评语影响下一轮心态

---

## 3. 核心机制

### 3.1 焦虑值（Anxiety Meter）
- 隐藏数值 0–100，影响：攻击速度、台词完整度、攻击威力（焦虑高 → 颤抖、忘词、攻击打偏）
- 来源：玩家走得越稳 → 焦虑 +；玩家看攻略弹幕 → 焦虑 ++；Boss 自己选的"剧本难度"越高 → 焦虑起步越高

### 3.2 表演评分（Performance Rating）
- 战斗结束弹出"本场演出自评表"：
  - 走位流畅度 ⭐
  - 台词感染力 ⭐
  - 视觉效果 ⭐
  - "我有没有让玩家记住这场战斗" ⭐
- 玩家也能给 Boss 评分（可选项）。如果玩家打 5 星，Boss 会困惑："……你为什么要鼓励一个要杀你的人？"

### 3.3 剧本选择（Pattern Picker）
- 每轮开始 Boss 从 3 个"表演剧本"里挑：庄重威严 / 癫狂戏剧 / 悲情独白
- 玩家可以中途打断剧本；打断会让 Boss 出戏，进入"自由发挥"模式（攻击力随机，但台词会更真实）

### 3.4 自我关怀（Hidden Mechanic）
- Boss 有一本日记，每次自评后可以写一句话
- 如果连写 3 次 "我不够好" → 解锁隐藏结局：**Boss 拒绝战斗，坐下问玩家："你为什么一定要杀我？"**
- 玩家选"我也累了" → 共同沉默画面 → The End

## 4. 情感节拍（5 分钟体验曲线）

| 时间 | 事件 | 情绪 |
|------|------|------|
| 0:00 | Boss 独坐王座，喃喃"又是新的一天" | 孤独 |
| 0:30 | 玩家从远处走来，Boss 慌忙整理盔甲 | 紧张、喜感 |
| 1:30 | 战斗开始，Boss 念台词但忘词 | 心疼 |
| 3:00 | Boss 第一次被打倒，爬起来先整理头发 | 意外、笑 |
| 4:00 | 真正表演开始，玩家意识到"他在认真演" | 共情 |
| 4:30 | 战斗结束，无论输赢，Boss 写日记 | 反思 |
| 5:00 | 玩家离开，Boss 对着空房间鞠躬谢幕 | 留白、回味 |

## 5. Art & Audio Direction

- **视角**：固定摄像机，对角线构图，舞台剧感
- **Boss 形象**：传统魔王造型但带生活痕迹（眼镜、老茧、护甲划痕写满前任玩家名字）
- **场景**：哥特王座厅，单点暖光（烛火），其余冷蓝
- **配色**：深蓝 + 暖橙 + 偶尔爆发的血红（攻击时）
- **音乐**：单人钢琴 + 不稳定的弦乐，Boss 焦虑时小提琴走音
- **音效**：王座吱呀声、盔甲片摩擦、远处水滴回响（"空房间"的具象化）

## 6. TDD（技术设计）

### 6.1 技术栈
- **Three.js**（渲染）+ **TypeScript**（类型安全）
- **Vite**（HMR 快，jam 友好）
- **GSAP**（Boss 情绪化动画 / 时间线）
- **Howler.js**（音效 + 音乐分层）
- **Tweakpane**（开发期调试焦虑值 / 自评表）

### 6.2 架构
```
src/
├── core/           # Game loop, FSM (Wait/Sense/Perform/Evaluate)
├── scene/          # Three.js scene, lighting, throne
├── entities/
│   ├── Boss.ts     # 状态机 + 焦虑值 + 动画
│   └── Player.ts   # 简化（不必实现完整玩家，AI 替身即可）
├── combat/         # 攻击模式 / 命中 / 反馈
├── ui/             # 自评表 / 日记 / HUD
├── audio/          # 音乐分层 + 动态混音
└── content/        # 台词 JSON / 剧本 JSON / 日记文本
```

### 6.3 关键系统

**Boss 状态机**（FSM）：
```
IDLE → ALERT → PERFORM → HIT → RECOVER → EVALUATE → IDLE
                ↘ BREAK_CHARACTER ↗
```

**焦虑值衰减模型**：
- 战斗开始时：基线 30 + 剧本难度加成
- 玩家攻击命中：+5
- 玩家完美闪避：+10
- 自评给 5 星：-15
- 日记写正面句子：-10/句

### 6.4 性能预算
- 目标：60 FPS @ 1080p
- 多边形预算：场景 < 50k tris，Boss < 8k tris
- 阴影：单方向 PCF 软阴影，1024×1024
- 后期：Bloom（轻量）+ Vignette，无 SSR

### 6.5 资产策略（jam 友好）
- **建模**：Boss 用单 mesh + 顶点动画，不用骨骼
- **动画**：全部走 timeline 关键帧，不上 rig
- **材质**：MeshStandardMaterial 为主，控制 < 20 个材质实例
- **音效**：免费素材 + 自录喘息声
- **音乐**：用 Tone.js 实时合成，不依赖外部长音频

## 7. 3 天里程碑

| Day | 目标 | 交付 |
|-----|------|------|
| **D1** | 场景 + Boss 立绘 + IDLE 状态 | 玩家能走进 Boss 房，看到 Boss 坐着自言自语 |
| **D2** | 战斗系统 + 焦虑值 + 3 个攻击模式 | 完整打一轮，能输能赢 |
| **D3** | 自评表 + 日记 + 隐藏结局 + 音效 + 调手感 | 完整 5 分钟体验 |

### 7.1 可砍清单（如果赶不上）
- ⛔ 第三种剧本（癫狂戏剧）→ 砍
- ⛔ 玩家 AI 替身 → 改成"想象玩家"（只有脚步声）
- ⛔ 隐藏结局 → 留到 stretch
- ⛔ 日记系统 → 只做 1 条预设评语

### 7.2 Stretch Goals
- 玩家打字回复 Boss 日记
- Boss 根据玩家历史自评生成新台词
- 多语言（中/英/日）

---

## 8. 关键风险 & 对策

| 风险 | 对策 |
|------|------|
| 战斗无聊（玩家是 AI 替身） | 抽象化呈现（脚步声 / 影子 / 飞回的剑），把"玩家"做成一个概念而非实体 |
| 情感不到位 | Day 2 晚上强制 playtest，不通就砍战斗时长、加台词 |
| Three.js 性能吃紧 | 严格 mesh 复用，Boss 一开始就别用骨骼 |

---

## 9. 一句话总结

> **你不只是一个 Boss，你是一个在空房间里练习谢幕的演员。玩家只是你的观众 —— 也是你存在的理由。**
