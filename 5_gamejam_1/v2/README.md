# 《Boss 的焦虑》V2 — 终场直播

> 你扮演最终 Boss：一个在空房间里排练谢幕、却突然发现直播间有人进来的演员。
> 观众不露脸，只用弹幕评价你的每一次走位、挥剑和忘词。

V2 是《Boss 的焦虑》的重制版：在 v1/v2 玩法（鼠标节奏 + 观众弹幕）之上从零重建引擎与 UI，
修复旧版全部手感问题，并加入新机制。独立项目，跑在 `5_gamejam_1/v2/`，端口 **5174**。

## 运行

```bash
cd 5_gamejam_1/v2
npm install        # 首次
npm run dev        # http://localhost:5173 → 本目录为 5174
npm run build      # tsc -b && vite build
npm test           # vitest（核心模拟层单测，29 用例）
```

验证门 = `npx tsc -b --noEmit` + `npm test` + `npm run build`。

## 一句话玩法

3D 舞台上同时经营两件事：用 `WASD` 把 Boss 放到正确的舞台位置，再用鼠标完成一段
**osu 式缩圈节奏谱**（approach 圈从 3.2× 缩到判定圈重合即节拍点）。谱面结束后，
观众用 B 站式弹幕即时起哄。最多 4 轮，结局由评分、被看见度与三次击倒决定。

```text
标题 → 候场选剧本 → 影子逼近 → 走位 + 鼠标短谱 → 弹幕爆发 → 自评 → 日记 → 下一轮 / 结局
```

## 操作

| 输入 | 作用 |
|---|---|
| `WASD` | 屏幕相对走位（固定机位地面轴，镜头晃动不漂移） |
| 鼠标移动 + `左键` | 光标移入目标，approach 圈缩到判定圈时点击 |
| 前摇窗口内按左键 | 完美闪避替身出招（替身举剑发红光 = 警告） |
| `1` / `2` / `3` | 选庄重 / 悲情 / 癫狂剧本 |
| `Enter` / `空格` | 开始演出 / 推进对白（结局界面 = 重开） |
| `Esc` | 暂停 |

## V2 相比旧版的增强（ground-up rework）

### 手感修复（旧版玩家投诉全部落实）
- **osu 缩圈方向修正**：approach 圈 3.2× → 1.0× 收缩压到判定圈（旧版是错误地扩大）；
  判定分档 300/100/50（完美/良好/普通）+ 早晚方向箭头 + 落空 ×。
- **Boss 接地**：脚底 y=0，王座厅里不再悬空 1 米。
- **Boss 面向移动方向/目标/替身**：走位时转身看路，不再只有僵硬的 rootYaw 姿态。
- **焦虑可读**：HUD 心跳 + 频段文字（从容/紧张/发抖/恐慌）+ 频段变化 toast 提示 + 镜头推进/FOV/晃动代理。

### 新机制
- **长按目标（R3+）**：按住剑蓄力，进度条走满即命中。
- **替身追踪目标（R3+）**：终结目标绑定玩家替身，跟着它移动并踩节拍。
- **替身出招前摇**：1.1s 举剑红光预告，前摇内点击 = 完美闪避（+10 焦虑，0 伤害）；
  攻击节拍中替身停手围观（不打断演出）。
- **走位奖励**：站进金色光圈 → 下一组谱判定窗口 +12% 倍率，组结束清零。
- **醒目留言（SC）**：舰长金框弹幕。
- **观众人数 HUD**：随被看见度/轮次/评分增长，结局统计观众峰值。
- **日记手打**（`STRETCH_FLAGS.playerTyping = true`）：预设词条之外可直接输入自己的日记。
- **存档统计**：生涯场次、最佳连击、完美总数、见证结局、观众峰值。

### 技术
- C.A.T 架构：`src/core/`（纯模拟：FSM + 焦虑模型 + osu 判定 + 弹幕调度 + 确定性替身）、
  `src/engine/`（Three.js 舞台：程序化王座厅、Boss 骨架 + 弹簧链披风、替身、粒子、bloom/暗角后期）、
  `src/store.ts` + `components/`（React 19 + zustand）。
- 零素材：全部程序化几何 + Web Audio 合成（分层 BGM 随焦虑变化 + 分档音效）。
- 模拟层 29 个 vitest 单测（谱面生成确定性、判定窗口、hold 头尾、FSM 全流程、闪避反制、隐藏结局链）。

## 三个剧本

| 剧本 | 谱面风格 | 观众口味 |
|---|---|---|
| 庄重威严 | 大跨度、稀疏、重拍 | 吐槽披风、站姿和装腔 |
| 悲情独白 | 较长连击、舒缓节拍 | 一边催哭一边嫌台词长 |
| 癫狂戏剧 | 高速折返、密集短目标 | 表情包、复读词、集体起哄 |

超时未选剧本 → 自动进入「即兴演出」（freePlay）。

## 结局

- **掌声谢幕**：四轮完成，总评 ≥3.5 或被看见度 ≥60。
- **空房间**：四轮完成但口碑崩盘。
- **提前谢幕**：被击倒 3 次。
- **疯狂的一夜（隐藏）**：癫狂剧本 + 口碑崩盘（not-good-enough 日记 ≥2）+ 结局对话选 B「毁掉这场演出」。
