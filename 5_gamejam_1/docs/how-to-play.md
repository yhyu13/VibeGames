# 《Boss 的焦虑》— 怎么玩 v2

> 你扮演最终 Boss：一个在空房间里排练谢幕、却突然发现直播间有人进来的演员。
> 观众不露脸，只用弹幕评价你的每一次走位、挥剑和忘词。

**在线试玩**：`npm run dev` 后打开 http://localhost:5173

> 本页描述 v2 的目标玩法：鼠标谱、屏幕相对 WASD 和丰富观众弹幕。v1 的旧操作说明与截图保存在 [`docs/v1/`](v1/)。

---

## 一、一句话玩法

你在 3D 舞台上同时经营两件事：用 `WASD` 把 Boss 放到正确的舞台位置，再用鼠标完成一小段节奏点击谱。谱面结束后，观众会用 B 站式弹幕即时起哄、刷屏或发无厘头评论。

```text
等玩家 → 观众上线 → 相机相对走位 → 鼠标短谱 → 弹幕爆发 → 自评 → 下一轮 / 结局
```

一轮由多段短演出组成，最多 4 轮。攻击不再是等待 10 秒后只按一次，而是 3–6 秒内连续移动光标、找目标、踩节拍。

## 二、操作

| 输入 | 作用 |
|---|---|
| `W` | 按固定基础相机的地面方向，向屏幕上方移动 |
| `S` | 向屏幕下方移动 |
| `A` / `D` | 向屏幕左 / 右移动 |
| 鼠标移动 | 瞄准当前屏幕目标 |
| 鼠标左键 | 在目标缩圈到节拍窗口时点击 |
| `1` / `2` / `3` | 选择庄重 / 悲情 / 癫狂剧本 |
| `Enter` / `空格` | 开始演出或跳过对白 |
| `Esc` | 暂停 |

### WASD 的方向规则

WASD 使用**固定设计相机**的地面投影，不使用焦虑抖动后的镜头方向。因此镜头晃动时，`W` 仍然是屏幕上方，`A/D` 仍然是屏幕左右，不会出现按键方向跟着镜头漂移的问题。

## 三、Perform：先站位，再出手

Perform 不再是“走位、等红圈、按一次”的单调循环，而是两个短环节交替：

1. **舞台走位**：把 Boss 送进金色光圈。站位正确会让下一组鼠标谱的判定窗口和倍率短暂提升；这一组结束后奖励清零，避免滚雪球。
2. **鼠标短谱**：屏幕出现连续点击目标。光标进入目标后，在目标内部缩圈收紧到节拍窗口时按左键；点中后下一个目标立即出现。

单组最后一个目标可能绑定玩家替身。替身移动时，终结目标跟随它平滑移动，但节拍不变——这是一次需要真正追着玩家视线走的终结击。

| 目标状态 | 你要做的事 | 结果 |
|---|---|---|
| 缩圈目标 | 移入圆圈，在缩圈窗口点击 | 完美 / 良好 / 普通 / 落空 |
| 连续目标 | 点击成功后立即追下一个 | 连击累积 |
| 替身终结目标 | 追随移动目标，在节拍点点击 | 结束本组鼠标谱 |

鼠标谱的中央约 60% 是安全操作区。弹幕主要走顶部、底部和边缘，目标层永远显示在弹幕上方。

## 四、判定与连击

每个目标独立判定，整组结束时汇总为组级结果：

| 判定 | 含义 |
|---|---|
| **完美** | 几乎踩中节拍，必定成功，连击继续 |
| **良好** | 在较宽窗口内命中，按轮次概率结算 |
| **普通** | 勉强踩到窗口，按轮次概率结算 |
| **落空** | 点偏、太早或太晚，断当前连击 |

单个目标落空只断连击，不额外叠加焦虑；整组完全没有完成仍属于演出事故，会沿用旧的空挥焦虑规则。连续命中会把 `maxCombo` 带入 A3 评分，达到 4 连击即可满足 A3 的最高档条件。

站位奖励只服务下一组鼠标谱：扩大判定窗口并提高倍率，组结算后自动重置。

## 五、三个剧本、四轮变化

基础操作不变，但谱面语言随剧本变化：

| 剧本 | 鼠标谱风格 | 观众口味 |
|---|---|---|
| 庄重威严 | 大跨度、稀疏、重拍点击 | 吐槽披风、站姿和装腔 |
| 悲情独白 | 较长的连续点击和舒缓节拍 | 一边催哭，一边嫌台词长 |
| 癫狂戏剧 | 高速折返、密集短目标和问号刷屏 | 高速反应词、表情包和集体起哄 |

四轮逐步增加复杂度，而不是单纯把速度变成手速墙：

- **R1**：固定点击目标，学习缩圈与节拍。
- **R2**：连续目标变多，走位奖励开始重要。
- **R3**：终结目标绑定玩家替身，玩家需要追移动目标。
- **R4**：混合考试，谱面、站位、弹幕和连击一起考验。

## 六、观众弹幕：像 B 站直播间一样刷屏

弹幕是 v2 的核心反馈，不是装饰。它们既像直播间网友，也像 Boss 焦虑产生的脑内观众；游戏不解释它们到底是否真实。

### 五种表现

- **普通弹幕**：白字黑描边，沿 6 条固定轨道从右向左滚动，自动避开中央操作区。
- **顶部 / 底部大字**：重大事件才出现，统一粗体和黑描边，偶尔使用金色、红色、青色或粉色。
- **加速弹幕**：`草`、`危`、`？？？`、`泪目` 等短反应词快速飞过，模拟观众瞬间刷屏。
- **Emoji 弹幕**：`😂`、`👏👏👏`、`💀` 等高速横飞。
- **表情包弹幕**：`[战术后仰]`、`[地铁老人手机]`、`[我看不懂但我大受震撼]` 等卡片在屏幕边缘停留后淡出。

平时屏幕保持约 3–5 条环境弹幕；事件发生时在 0.5 秒聚合窗口内形成 2 / 4 / 8 条观众爆发。普通内容最近 10 条不重复，少量“草”“？？？”等复读词允许连续出现。

### 什么时候刷屏

弹幕会监听有限的核心情景：进场、选剧本、站位、完美、连击、落空、忘词、击倒、出戏、自评和谢幕。

- 完美命中：喝彩、`👏`、金色大字。
- 连击达到 4：观众开始刷“名场面”，可能出现加速追评。
- 落空：嘲笑、`💀`、底部红色大字，Boss 触发自嘲台词。
- 忘词 / 掉剑：弹幕从攻略变成看热闹，可能混入无厘头评论。
- 击倒 / 出戏 / 谢幕：重大事件，允许 8 条爆发和一条大字弹幕。

无厘头内容约占环境弹幕四分之一，事件爆发最多混入一条，例如：

```text
所以今晚吃什么
刚来，谁是 Boss
这个披风有链接吗
有人知道二楼厕所在哪吗
前面的别剧透
```

“被观看”本身仍然会增加焦虑，但只按整次爆发结算：普通 `+1`、明显 `+2`、重大 `+4`，不会按每条文字逐条叠加。

鼠标谱期间，中央安全区清空普通弹幕；顶部、底部和边缘仍保留观众反应，保证弹幕热闹但不遮挡目标。

## 七、焦虑与演出事故

焦虑值隐藏在 0–100，用镜头、音色、台词和弹幕表现：

| 区间 | 舞台表现 |
|---|---|
| 0–30 | 从容，台词完整，观众零星发言 |
| 31–60 | 紧张，起手犹豫，观众评论变多 |
| 61–85 | 发抖，忘词、打偏，弹幕开始刷屏 |
| 86–100 | 恐慌，剑可能脱手、跪地喘息，观众爆发 |

玩家影子会持续逼近并攻击 Boss。被击倒 3 次会提前谢幕；完成 4 轮则进入正常结局。自评高星、完成阶段和正面日记仍然提供缓解。

## 八、自评、日记与结局

每轮结束后进入四轴自评：走位、台词、视觉和“有没有让玩家记住”。高星不会替你完成鼠标谱，但会帮助下一轮控制焦虑。

写一句日记，或等待倒计时自动写下。第 4 轮结束或提前谢幕后进入结局；被看见度与累计演出质量决定最后是掌声，还是空房间。

## 九、弹幕设置

弹幕会占据屏幕边缘，因此提供两个简单选项：

- **显示 / 隐藏弹幕**：关闭后不影响谱面判定和游戏进度。
- **标准 / 稀疏密度**：稀疏模式降低环境弹幕和爆发条数，但保留重大事件提示。
