# 01 · 概念与核心循环设计（Concept & Core Loop）

> 供：Coder（TDD 契约方） / Content（台词 & 文本） / Audio / 3D/Art 代理阅读。
> 本文档只锁定**设计决策与数值**；最终接口签名、状态机实现细节由 TDD 代理决定。
> 技术方向：Three.js + TypeScript + Vite + React + zustand，程序化几何 + Web Audio 合成，C.A.T 架构（纯核心 core / 平台适配 engine）。
> 范围纪律：5–8 分钟循环；尊重 GDD §7.1 可砍清单（⛔ 标记 = cut-first）。

---

## 1. 高概念（High Concept）

- **Genre**：动作 + 情感叙事 / 单幕舞台剧 / 5–8 分钟一次完整循环（4 轮战斗 + 结局）。
- **张力轴（Tension Axis）**：不是"输赢"，而是 **"我是否被看见"**（Am I being seen?）。
  - 两条隐藏数值并行运行：`焦虑 0–100`（GDD 已定义）与 `被看见度 0–100`（本设计补充，见 §3.5）。
  - 被看见度的**唯一可见代理 = 舞台灯光亮度**：演得越被记住，灯光越亮；观众席始终空无一人，但光会说真话。
- **Tone**：黑色幽默 + 意外的温柔。参考密度：《Disco Elysium》内独白、《Getting Over It》的"过程即叙事"。
- **玩家扮演**：人类玩家扮演 **Boss**（第一人称意向上是"舞台上的演员"），固定对角线舞台视角。挑战者（"玩家"）是 AI 替身，抽象呈现，**不是角色**（见 §10）。
- **一句话**：你不只是一个 Boss，你是一个在空房间里练习谢幕的演员。

## 2. 核心循环（Core Loop）

```
Wait (8–12s) → Sense (5–8s) → Perform (40–55s) → Self-Evaluate (10s) → Diary (8s) → 下一轮 / 结局
```

每轮总时长 **60–90s**（设计基准：10 + 6 + 48 + 10 + 8 = **82s/轮**）。主循环 **4 轮** ≈ 5:28，加结局 0:30–1:00 → **总时长 6–6.5 分钟**，落在 5–8 分钟窗口内。

### 2.1 各阶段规格

| 阶段 | 时长 | 内容 | 关键事件 |
|------|------|------|----------|
| **Wait** | 8–12s | Boss 独坐王座，喃喃自语（L_AMB 池）；右侧浮出"历任挑战者档案"，可翻阅 | 首轮解锁 2 条预设档案；后续轮 +1 条"上轮实录生成档案" |
| **Sense** | 5–8s | 脚步声道具从走廊尽头渐强；影子沿地面拉长逼近；Boss 慌忙整理盔甲（动画） | 首次见到玩家 `+8` 焦虑；可能提前刷第一条弹幕 |
| **Perform** | 40–55s | 3 个剧本阶段，每个阶段 2–3 个攻击编排节拍（beat），人类玩家按节拍操作 | 每完成 1 阶段 `-8` 焦虑；全本完成额外 `-10` |
| **Self-Evaluate** | 10s | 自评表弹出：4 轴各 1–5 星（见 §4） | 星级 → 焦虑修正 → 影响下一轮心态 |
| **Diary** | 8s | 写一句话（4–6 条预设，⛔ 砍底：1 条预设自动写入） | 正面 `-10` / 负面 `+8`；计数"我不够好" |

### 2.2 轮次升级表（Multi-round Escalation）

| 参数 | R1 | R2 | R3 | R4（终演） |
|------|----|----|----|-----------|
| 玩家逼近速度 | 1.0 m/s | 1.15 m/s | 1.30 m/s | 1.50 m/s |
| 玩家攻击伤害 / Boss HP（100） | 20（5 击倒） | 22（5 击） | 25（4 击） | 30（4 击） |
| 玩家闪避率（普通） | 20% | 30% | 40% | 50% |
| 玩家完美闪避率 | 10% | 15% | 20% | 25% |
| 弹幕事件数/轮（上限） | 0–1 | 1–2 | 2–3 | 3（封顶） |
| 焦虑基线 | 30 | 34 | 38 | 42 |
| 被看见度（轮末继承） | 0 | 上轮 ×0.6 | 上轮 ×0.6 | 上轮 ×0.6 |
| 档案解锁 | 2 条预设 | +1 生成 | +1 生成 | +1 生成 |
| Boss 外观磨损 | 0 | +1 护甲划痕 | +1 划痕，头盔裂纹 | +1 划痕，披风破口 |

- **难度本质**：难度不在"打不打得过"，而在"演得稳不稳"——玩家闪避率上升 = 更少命中 → 更少"演出反馈"，但焦虑源（完美闪避 `+10`）增加。
- **每轮恒定**：剧本选择权、自评表、日记、可被打断出戏。

## 3. 焦虑值模型（Anxiety Meter 0–100）

隐藏数值，不显示数字；外部代理 = 弦乐走音程度 + 手部抖动幅度 + 呼吸声。`clamp(0,100)`。

### 3.1 焦虑来源表（Source Table，全部精确增量）

| ID | 来源 | 增量 | 触发条件 |
|----|------|------|----------|
| S01 | 起始基线 | 30 | 每轮开局固定 |
| S02 | 轮次疲劳 | +4 × (R−1) | 每轮开局（R=轮次） |
| S03 | 剧本难度加成 | 庄重威严 +8 / 悲情独白 +12 / 癫狂戏剧 +18 | 选择剧本时一次性 |
| S04 | 首见玩家 | +8 | Sense 阶段开始，单次 |
| S05 | 玩家稳步逼近 | +1.4/s | 玩家速度 0.9–1.4 m/s 且直线逼近王座 |
| S06 | 玩家犹豫逼近 | +0.6/s | 走走停停（速度 <0.9 m/s） |
| S07 | 攻略弹幕事件 | +12 / 条 | 每条弹幕出现（每轮最多 3 条，见 §2.2） |
| S08 | 玩家攻击命中 | +5 | 每次（GDD 已验证 ✓） |
| S09 | 玩家完美闪避 | +10 | 每次（GDD 已验证 ✓，时机窗口见 §10） |
| S10 | 玩家普通闪避 | +3 | 每次（补充） |
| S11 | 玩家攻击落空 | +2 | 每次（玩家攻击未命中 → 演出无反馈的困惑） |
| S12 | 忘词（整句遗忘） | +6 | 每次整句遗忘触发 |
| S13 | 剧本被打断 | +15 | 每次打断事件（见 §5.3） |

### 3.2 焦虑效果分带（Effect Bands）

| 区间 | 名称 | 攻速倍率 | 台词完整率 | 攻击威力 | 散射角 | 落空率 | 附加效果 |
|------|------|---------|-----------|---------|--------|--------|----------|
| 0–30 | 冷静 Calm | ×1.00 | 100%（完整） | ×1.00 | 0° | 0% | 无 |
| 31–60 | 紧张 Nervous | ×0.95 | 90%（每句 10% 轻微结巴/换一两个词） | ×1.05 | 2° | 5% | 动作间起手犹豫 +0.1s |
| 61–85 | 发抖 Shaky | ×0.85 | 65%（每句 35% 退化：15% 整句遗忘→停顿 1.5s 或补 L_PANIC 即兴，20% 结巴换词） | ×1.15 | 5° | 15% | 拔剑僵直 +0.3s |
| 86–100 | 恐慌 Panic | ×0.70 | 40%（每句 60% 退化：30% 整句遗忘，30% 破碎断句） | ×1.30 | 10° | 30% | 每次攻击 5% 概率剑脱手（1.2s 捡剑喜感节拍） |

- **台词完整率** = 逐句掷骰：完整说出的概率。整句遗忘时：台词跳过 + 静默 1.5s，60% 概率补一句 L_PANIC 即兴（更真实，见 §5.4）；无论补不补都触发 S12 `+6`。
- 攻速/威力/散射/落空率取**逐攻击实时采样当前焦虑值**，同一轮内可跨带。

### 3.3 衰减与安抚模型（Decay / Soothing，GDD 已验证项 ✓）

| ID | 来源 | 增量 | 说明 |
|----|------|------|------|
| R01 | 自然衰减 | −2/s | 连续 3s 无焦虑源后开始；战斗间隙（玩家读条、阶段间隙）触发 |
| R02 | 评估阶段衰减 | −4/s | Self-Evaluate 阶段全程（最多 −40，不会跌破 10） |
| R03 | 剧本阶段完成 | −8 / 阶段 | 每完成 1 个阶段（Relief） |
| R04 | 全本完成 | −10 | 3/3 阶段完成时额外一次 |
| R05 | 自评 5 星 | −15 | GDD ✓（若总评 ≥4.5） |
| R06 | 自评 4 星 | −6 | 补充 |
| R07 | 自评 3 星 | −2 | 补充 |
| R08 | 自评 ≤2 星 | +4 | 补充（心态崩坏） |
| R09 | 日记正面句子 | −10 / 句 | GDD ✓ |
| R10 | 日记负面句子 | +8 / 句 | 补充（含"我不够好"） |
| R11 | 玩家评分 5 星 | −12 | 补充；附带困惑事件（L_P5STAR 台词，见 §4.4） |

**验证结论**：GDD §6.3 的 5 条（命中 +5 / 完美闪避 +10 / 5 星自评 −15 / 正面日记 −10 / 起始基线 30 + 剧本加成）全部保留并纳入表；其余为该表的完整性补全（普通闪避、落空、忘词、打断、阶段完成、低星自评、负面日记、玩家 5 星、自然衰减）。

### 3.4 数值边界规则
- 焦虑 100：触发"恐慌崩溃"——本 beat 强制取消，Boss 原地跪下喘息 2s（喜剧+心疼节拍），之后焦虑立即回落至 70。
- 焦虑 <10 时不再自然衰减（避免永远冷静）。

## 4. 表演评分（Performance Rating）

### 4.1 四轴定义（各 1–5 星）

| 轴 | 名称 | 计算输入（事实数据） | 星级阈值 |
|----|------|---------------------|----------|
| A1 | 走位流畅度 | 移动抖动率（每 0.5s 位置突变幅度占比）+ 站位命中率（beat 要求站位 ±0.8m 内） | 5★: 站位 ≥90% 且抖动 <5% ｜ 4★: ≥75% 且 <10% ｜ 3★: ≥55% ｜ 2★: ≥35% ｜ 1★: 其余 |
| A2 | 台词感染力 | 台词完整率 + 忘词数 + 节奏偏差（实际对白时间 vs 锚点时间 ±15%） | 5★: 完整率 ≥95% 且忘词 0 ｜ 4★: ≥80% 且 ≤1 ｜ 3★: ≥60% ｜ 2★: ≥40% ｜ 1★: 其余 |
| A3 | 视觉效果 | 阶段完成数 + 最大连击（未被打断的连续攻击序列）+ VFX 触发数 | 5★: 3/3 阶段且连击 ≥4 ｜ 4★: 3/3 ｜ 3★: 2/3 ｜ 2★: 1/3 ｜ 1★: 0/3 |
| A4 | 有没有让玩家记住 | **系统代填**（Boss 无法自评）＝ 被看见度（§3.5） | ≥80→5★ ｜ ≥60→4★ ｜ ≥40→3★ ｜ ≥20→2★ ｜ 其余 1★ |

- **总评** = 四轴均值：≥4.5 完美 / ≥3.5 合格 / <3.5 失格。

### 4.2 自评交互（Self-Evaluation Timing）
- 时机：Perform 结束（无论胜负）→ 10s 倒计时窗口。
- A1/A2/A3：人类玩家自评，UI 同时展示**事实数据卡**（"忘词 ×2 · 站位 72% · 最大连击 5"），星数不强制与数据一致——**评分是一种自我认知行为，不是考试**。
- A4：系统自动填入，并展示证据（"玩家停留了 12 秒" / "玩家留下了 1 条弹幕"），Boss 看到 A4 时有一句对应反应台词（L_EVAL 池）。
- 总评决定焦虑修正（§3.3 R05–R08）。

### 4.3 玩家评分（可选）
- 轮末 30% 概率，抽象玩家以"墙上涂鸦"形式留下 1–5 星（概率判定：总评 ≥4★ 时才有）。
- 5★ → 特殊台词 L_P5STAR（"……你为什么要鼓励一个要杀你的人？"，困惑 + 眼眶湿），焦虑 −12；
- 4★ → 小确幸台词，−4；≤2★ → +6。

### 4.4 星级对下一轮心态的影响（Mindset）

| 上轮总评 | 下一轮修正 |
|----------|-----------|
| ≥4.5（完美） | 起始焦虑额外 −5；台词完整率 +5%（信心 buff） |
| ≥3.5（合格） | 无修正 |
| <3.5（失格） | 起始焦虑 +4；首句台词 30% 概率替换为自我怀疑句（L_SELFDOUBT 池） |

## 5. 剧本选择（Pattern Picker）

- 每轮 Wait 阶段末尾弹出选择 UI（数字键 1/2/3），选定后立即按 §3.1 S03 加焦虑起始值。
- 每个剧本 = 3 阶段 × 2–3 编排节拍（beat）。beat 类型：`move`（走位）/ `attack`（出招，左键触发）/ `line`（台词锚点）/ `vfx`（仪式光效）。
- 人类玩家控制：WASD 走位；LMB 在 beat 提示圈内出招；台词自动念出（受焦虑带影响）。

### 5.1 剧本 1 · 庄重威严（Dignity，难度加成 +8）

|------|------|-----------|----------|

| P3 献祭终幕 | 12–15s | ① line 自毁宣言 → ② attack 以自身为中心的爆发剑舞 2.5s → ③ vfx 血光爆闪 | L_MAD_303 |

**砍后降级路径**：若砍掉癫狂戏剧，剧本池只剩 2 个；需保证 Pattern Picker UI 对数量自适应（设计为 `SCRIPT_COUNT ≥ 2` 即可，不硬编码 3）。

### 5.4 打断剧本 → 出戏 / 自由发挥模式（Free Play）

**打断触发条件**（任一）：
1. 台词锚点进行中，玩家命中 Boss（S08 命中判定命中且正处 line beat）；
2. 弹幕在 line beat 中刷新（弹幕事件 S07）；
3. 同一阶段内忘词 2 次。

**出戏效果**（立即生效）：
- 焦虑 `+15`（S13），且焦虑带下限提升到当前带+1（最低 61 发抖带）；
- 剩余剧本时间缩短 20%（按原编排比例）；
- 攻击威力变为随机 `×[1.2–1.6]`，散射角 ×2，落空率 ×1.5；
- 台词池切换为 **L_FREE 真实台词池**（8 句，更短、更真、不再受完整率骰子约束——**自由发挥时台词 100% 完整**，这是"真实"的机制回报）；
- 视觉：舞台灯光转暖色，观众席方向出现一道人形阴影驻足观看（被看见度事件 +10）。

## 6. 自我关怀隐藏机制 + 隐藏结局 ⛔ stretch（GDD §7.1）

> 完整设计预留；若砍，则日记只保留 1 条预设自动写入（L_DIARY_01），隐藏结局不触发。

**触发链（严格顺序）**：
1. **Diary 计数**：日记选项含"我不够好"（L_DIARY_02 变体 ×3，措辞微不同但同 ID 计数）。
2. **累计 3 次"我不够好"** → 下一轮 Sense 阶段开始时触发 **拒绝战斗**：
   - 脚步影子逼近至 12m 处停止；Boss 从王座起身又坐回，台词 L_END_H1（"……今天不打了。"）。
   - 玩家影子停在原地，弹幕静默（所有弹幕源冻结）。
3. **Boss 坐下，问出 L_END_H2**："你为什么一定要杀我？" → 对话框给出 3 个选项：
   - A「因为你是 Boss 啊」→ 继续循环（本轮按"未演出"计，焦虑 +20，回到 Wait；不再次计入计数）。
   - B「我也不知道」→ 继续循环（同理，+10）。
   - C「我也累了」→ **隐藏结局**。
4. **隐藏结局**：双方沉默 10s（黑场渐入，只有脚步停止声与呼吸声）→ 日记自动写入"今天没有人受伤"（L_DIARY_09）→ 灯光全部熄灭 → 谢幕文案 + Credits → **The End（隐藏）**。

**规则**：计数跨轮累积；选择 A/B 不会清除计数（保留玩家再度触发权）。

## 7. 情感节拍表（0:00–5:00，展开 GDD §4）

| 0:45 | 战斗开始 | Perform P1 首 beat 亮起 | 屏息 | 焦虑 45± |

| 2:10 | 玩家完美闪避 | 玩家闪避判定完美（§10 窗口） | 挫败 | S09 +10 |

| 3:20 | 出戏 / 自由发挥 | 打断条件命中（§5.4） | 释放 | S13 +15；L_FREE 池 |
| 4:00 | 真正表演开始，玩家意识到"他在认真演" | R3/R4 任意 beat 连击 ≥4 或全本完成 | 共情 | 被看见度 +10；灯光 60%→100% |
| 4:30 | 战斗结束，写日记 | Perform 结束 → Evaluate → Diary | 反思 | 星级修正（§4.4） |

| 5:00 | 对着空房间鞠躬谢幕 | 第 4 轮 Diary 后进入 Ending（正常 A/B） | 留白、回味 | 灯光随被看见度定格 |

## 8. 胜负与"好/坏一轮"定义（Boss 视角）

| 结果 | 定义 | 后果 |
|------|------|------|
| **完美一轮（Win）** | 3/3 阶段完成 **且** 总评 ≥4.5 星 | 起始焦虑 −5（下轮）；被看见度 +10；玩家评分概率提升 |
| **合格一轮（Neutral）** | 2/3 阶段完成且总评 ≥3.5；**或** 击败玩家但剧本未演全 | 无修正；剧本判定为"演了但没演完" |
| **失格一轮（Lose）** | Boss HP 归零（第 1–2 次击倒）后第 3 阶段未完成；**或** 总评 <3.5 | 下轮起始焦虑 +4；首句 30% 自我怀疑句（§4.4） |

- **累计击倒 3 次** → 触发"提前谢幕"结局（正常结局 B 变体，总时长缩至 ~4 分钟）——Boss 第三次倒地后不再爬起，直接黑场鞠躬。
- **没有 Game Over**：每轮必然有结果，循环必继续，直到结局条件（第 4 轮末 / 提前谢幕 / 隐藏结局）。

## 9. 游戏状态（设计层 FSM）

```
menu → wait → sense → perform ─┬→ evaluate → diary →（wait | ending）
                               ├→ freeMode（perform 的子状态，打断触发）
                               └→ recover（HP 归零子状态，1.5s 整理发型后返回 perform）
ending: normalA（被看见度≥60，有纪念物）
      │ normalB（被看见度<60，空房间）
      │ hidden（3×"我不够好" → 对话 → "我也累了"）⛔
      └ 提前谢幕（累计击倒 3 次）
```

| 转移 | 条件 |
|------|------|
| menu → wait | 点击开始（跳过 intro 字幕，intro ≤8s 且可跳过） |
| wait → sense | 倒计时结束（或玩家音频 cue 触发）；Wait 最短 8s 保护 |
| sense → perform | 影子距离 < 12m |
| perform → evaluate | 阶段 3/3 完成 ｜ HP 归零 ｜ 90s 计时器（强制收尾） |
| perform → freeMode | §5.4 打断条件任一 |
| freeMode → evaluate | 出戏脚本剩余时间播完 ｜ HP 归零 |
| evaluate → diary | 自评提交（10s 倒计时到或玩家确认） |
| diary → wait | 第 1–3 轮且无结局条件 |
| diary → ending | 第 4 轮结束 ｜ 累计击倒 3 次 ｜ 隐藏结局触发链 |
| 任意 → pause | Esc；暂停时弹幕/脚步声/音乐全部冻结 |

## 10. "玩家"抽象规格（Player Abstraction）

**核心原则（GDD §8 风险对策）**：把"玩家"做成一个**概念而非实体**。全程**不渲染任何角色模型/立绘**。

### 10.1 唯一可见/可听呈现（共 5 种媒介）
1. **脚步声**（Web Audio 合成）：音量/声像随距离渐强，节奏随 approachSpeed。
2. **影子**（投射贴片，无实体）：长度 = f(1/距离)，逼近时拉长；攻击时影子处爆发光效。
3. **返回的剑**：命中后剑从 Boss 方向飞回影子处（"玩家接住剑"的暗示）。
4. **攻略弹幕**：屏幕边缘滚动文本（L_BARRAGE 池）。
5. **停留/离去**：轮末影子原地停留（lingerTime）或转身消失。

### 10.2 玩家替身暴露给 Boss 模拟的数据（PlayerSurrogate 快照）

```
PlayerSurrogateSnapshot {
  approachSpeed: 0.6–1.5 m/s      // 逼近速度（S05/S06 判定源）
  distanceToThrone: 0–40 m        // 距王座距离（Sense→Perform 转移条件）
  dodgeCount: int                 // 本轮闪避次数（S10 计数）
  hitsLanded: int                 // 本轮命中次数（S08 计数）
  dodgeTimingQuality: 0 | 0.5 | 1 // 完美闪避窗口 ±0.18s=1，普通 ±0.35s=0.5，其余 0
  barrageActive: bool             // 当前弹幕是否显示（S07 源）
  aggression: 0–1                 // 派生：0.5×approachSpeed + 0.5×hitRate
  lingerTime: 秒                   // 轮末停留时长（A4 轴证据）
  state: 'approaching' | 'engaging' | 'retreating' | 'gone'
}
```

- **消费方**：Boss 模拟（焦虑源、闪避判定、A4 轴、结局分支）每帧读取此快照；Boss 模拟**不直接驱动**影子/脚步渲染（渲染由 engine 适配层订阅快照）。
- **无直接控制**：人类玩家不操作替身（jam 范围确定；stretch 可加方向键 MASH 微调 aggression，但不进入基线范围）。
