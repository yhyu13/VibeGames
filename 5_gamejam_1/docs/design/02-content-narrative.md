## 1. 对话系统规格

### 1.1 呈现方式

- **打字机**：逐字出现，**40ms/字**；句号、省略号停顿 300ms；`……` 后停顿 600ms。
- **说话人标签**：对话窗左上角，显示 `魔王` / `你` / `档案` / `旁白`（旁白为屏幕底部细体小字，无对话框）。
- **Boss 台词可被打断**：打断 = 玩家对 Boss 执行一次攻击判定或按 B 键（见 §9 `ui.hint.script`）。被打断的当前行立即切换到 `variants.forgot`（焦虑 ≥ 60 时优先）或 `variants.free`（关键行）。
- **跳过**：玩家按 空格/回车 可整段跳过当前行（输入缓冲需延迟 150ms，防止误跳）。

### 1.2 行 id 约定

```
{state}.{beat}.{NN}[.{variant}]
```

| 段 | 取值 | 示例 |
|----|------|------|
| `state` | `wait` / `sense` / `perform` / `hit` / `recover` / `break` / `moment` / `evaluate` / `diary` / `ending` / `curtain` / `ui` / `playerrate` / `rating` | `wait` |
| `beat` | 该状态下的语义小节，如 `idle` / `archive` / `armor` / `p1` / `struck` / `star5` … | `archive` |
| `NN` | 两位流水号，从 01 起 | `03` |
| `variant` | `forgot`（忘词）/ `free`（自由发挥） | `forgot` |

变体行 = 主行 id 追加后缀，如 `perform.majesty.p1.03.forgot`。**变体不是独立行**，它们挂在主行的 `variants` 字段（见 §12）。

### 1.3 触发上下文 → FSM 状态映射

| FSM 状态 | 触发上下文 id 前缀 | 触发条件 |
|----------|-------------------|----------|
| `WAIT` | `wait.idle.*` `wait.archive.*` `wait.archive.react.*` | 循环开始，Boss 独坐王座；玩家打开档案 |
| `ALERT` | `sense.*` | 玩家进入 Boss 房（脚步声事件） |
| `PERFORM` | `perform.*`（主行 + `forgot` 变体） | 战斗阶段推进；每阶段切换时拉取下一批 |
| `BREAK_CHARACTER` | `break.transition.*` + 各行 `free` 变体 | 玩家打断剧本 / 焦虑 ≥ 80 触发"出戏" |
| `HIT` | `hit.*` | Boss 被命中 |
| `RECOVER` | `recover.*` | Boss 倒地 → 起身 |
| `EVALUATE` | `evaluate.*` `diary.*` | 战斗结束（无论输赢）→ 自评表 → 日记 |
| `END`（隐藏结局） | `ending.*` | 连续 3 条负面日记 → 下场战斗开场触发 |
| `END`（谢幕/结局屏） | `curtain.*` `ending.screen.*` | 玩家离开 / 结局画面 |

### 1.4 演出流程总览（GDD §4 情感节拍 ↔ 台词）

| GDD 节拍 | 时间 | 台词段 | 情绪 |
|----------|------|--------|------|

## 4. Perform 状态 — 三个剧本

### 4.1 通用规则

- 每个剧本 3 阶段（phase），每阶段 5 行主台词。
- **每行都有 `forgot`（忘词）变体**：焦虑 ≥ 60 或被打断时，优先用 forgot 替换。
- **关键行有 `free`（自由发挥）变体**：玩家打断剧本（B 键/攻击）时触发，Boss 出戏说真话；自由发挥期间焦虑值不再上升。
- 剧本难度（GDD §6.3）：`majesty=1`、`tragic=2`、`mad=3`（焦虑起步加成）。
- 变体替换规则：同一行若同时满足 forgot 与 free 条件 → 优先 `free`（出戏权重更高）。
- 打断后先播 `break.transition.*`（§4.4），再按关键性选择 `free` 变体。

## 12. 内容数据 Schema 提案（TS / JSON）

### 12.1 类型定义

```ts
// content/types.ts —— 全部数据为纯文本数据，零逻辑

export type FSMTrigger =
  | 'wait' | 'sense' | 'perform' | 'hit' | 'recover'
  | 'break' | 'evaluate' | 'diary' | 'ending';

export type Speaker = 'boss' | 'player' | 'archive' | 'system' | 'narration';

export interface DialogueLine {
  id: string;                    // 如 "perform.majesty.p1.01"
  speaker: Speaker;              // 说话人
  text: string;                  // 主台词（中文，定稿文本）
  trigger: FSMTrigger;           // 触发上下文（§1.3）
  variants?: {                   // 变体（变体 id = `${id}.forgot|free`）
    forgot?: string;             // 忘词：焦虑 ≥ 60 / 被打断时替换
    free?: string;               // 自由发挥：玩家打断剧本时替换（仅关键行）
  };
  timing?: {                     // 可选：打字机微调
    cps?: number;                // 字/秒，默认 25（40ms/字）
    pauseAfter?: number;         // 播完后的额外停顿 ms
  };
  next?: string | string[];      // 可选：下一行 id；数组 = 分支候选
}

export interface ScriptDef {
  id: 'majesty' | 'tragic' | 'mad';
  name: string;                  // "庄重威严" | "悲情独白" | "癫狂戏剧"
  difficulty: 1 | 2 | 3;         // 焦虑起步加成（GDD §6.3）
  cutList: boolean;              // true = 癫狂戏剧
  phases: {                      // 3 个阶段
    phase: 1 | 2 | 3;
    lines: string[];             // DialogueLine.id 列表，顺序播放
  }[];
}

export interface RatingAxis {
  id: 'movement' | 'lines' | 'visuals' | 'memory';
  label: string;                 // "走位流畅度" …
  stars: [string, string, string, string, string]; // 1–5 星描述
}

export interface DiaryEntry {
  id: string;                    // "diary.entry.01"
  text: string;
  mood: 'self-critical' | 'positive';
}

export interface ChallengerArchive {
  id: string;                    // "wait.archive.01"
  author: string;                // 落款
  text: string;                  // 评价正文
  reactionId: string;            // Boss 反应行 id → "wait.archive.react.01"
}

export interface ContentBundle {
  lines: Record<string, DialogueLine>;
  scripts: ScriptDef[];
  ratingAxes: RatingAxis[];
  diaryEntries: DiaryEntry[];
  archives: ChallengerArchive[];
  ui: Record<string, string>;    // §9 全部文案
}
```
