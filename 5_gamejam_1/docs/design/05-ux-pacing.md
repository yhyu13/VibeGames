# 05 · UX 与节奏设计（UX & Pacing）

> 供：Coder（TDD 契约方）/ UI / Content / Audio / 3D 代理阅读。
> 本文档锁定**屏幕流程、HUD 规格、输入方案、节奏时间线、可访问性、验收清单**；与 `01-concept-core-loop.md` 的数值/状态机/内容 id 严格对齐，不重复定义机制数值。
> 范围纪律：单次体验 5–8 分钟（4 轮 + 结局）；GDD §7.1 可砍项以 ⛔ 标记；本文档所有可降级项见 §8。
> 通用规范：1080p 基准；所有 UI 元素锚定百分比坐标（等比缩放）；HUD 总占用 < 12% 屏幕面积。

## 1. 屏幕流程（Screen Flow）

### 1.1 状态图

│ 主菜单  │ ◄────────── │ 过场字幕 │                      │ wait→sense→perform   │
└─────────┘   R / 按钮   └─────────┘                      │ (freeMode|recover)   │
     ▲                                                      │ →evaluate→diary→…   │
     │                        ┌───────────┐                └──────────┬───────────┘
     │  R / 返回标题           │  pause    │◄── Esc（run 内任意时刻）     │
     └────────────────────────│ 暂停遮罩  │                            │
                              └─────┬─────┘                            │
                                    │ 继续 / 重来 / 返回标题 / 静音        │ 第4轮结束 或 击倒×3 或 隐藏链

### 1.2 状态与转移表

| 状态 | 何时进入 | 退出条件 | UI 元素 |
|------|----------|----------|---------|
| title | 启动 / 任意结算返回 | 点击开始 → intro | 标题、副标题、开始按钮、设置（文本缩放、静音） |
| intro | 点击开始 | 播完 ≤8s 或任意键 | 字幕叠印（L_TITLE），无交互控件 |
| wait | intro 结束 / 上轮 diary 结束 | Wait 最短 8s 保护 + 倒计时结束 | 档案栈（右缘）、自语字幕、轮次标记「第 N 幕」 |
| sense | wait 倒计时结束 | 影子距离 < 12m | 脚步音渐强、弹幕 overlay、Boss 整理盔甲动画 |
| perform | 影子 < 12m | 3/3 阶段 ｜ HP 归零 ｜ 90s 强制收尾 | 剧本选择卡（进入时）、beat 圈、对话盒、HUD |
| freeMode / recover | §01-5.4 打断 ｜ HP 归零 | 出戏脚本播完 ｜ 1.5s 整理动画 | 灯光转暖、对话盒（L_FREE）、镜头微推 |
| evaluate | perform 结束 | 提交（≤10s） | 自评表、事实数据卡、玩家评分按钮 |
| diary | 自评提交 | 选择句子（或 ⛔ 自动写入） | 日记本面板、候选句 chips |
| ending | 第 4 轮日记后 ｜ 击倒 ×3 ｜ 隐藏链 | R 重新挑战 / 返回标题 | 结算屏、谢幕文案、Credits |
| pause | run 内任意时刻 Esc | 继续 / 重来 / 返回标题 | 半透明遮罩 + 菜单；弹幕/脚步/音乐全冻结 |

### 1.3 Pause 与 Restart 细则

- **暂停**：Esc 任意时刻（含 dialogue 打字中、自评表计时中）→ 时间冻结，弹幕、脚步、音乐、自评倒计时全部暂停。恢复无跳变（同帧继续）。
- **重开流程**：pause 菜单「重新开始」（R 快捷键）→ 弹出确认条「确定要重新开始吗？本轮进度将丢失」[确认 Enter / 取消 Esc] → 确认后回 title。ending 结算屏按 R = 直接重新挑战（无确认，因为一轮已结束）。
- **M 静音**：任意状态可用，右下角 1.5s toast 图标提示；设置存 localStorage。

## 2. HUD 规格

### 2.1 焦虑呈现（三层代理，无数字）

**原则**：焦虑永远不显示数值；三层代理叠加、任何一层都可单独读出；形状线索优先于颜色（色盲安全，见 §6）。

| 层 | 位置/规格 | 0–30 冷静 | 31–60 紧张 | 61–85 发抖 | 86–100 恐慌 |
|----|-----------|-----------|-----------|-----------|-------------|
| **L1 Vignette** | 全屏边缘径向渐变，静态 | 透明度 0.00 | 0.08（纯黑） | 0.18（#ff5a3c 混入 5%） | 0.32 + 边缘 0.3s 周期微颤（幅度 ±0.03，**非频闪**，峰值 ≤0.35） |
| **L2 Mini Meter** | 屏幕底部中央偏左，120×10px 胶囊条 + 上方 120×12px 波形线 | 填充 0–30%，波形**平线**（±1px 静止） | 填充 30–60%，波形**小波浪**（±1.5px @0.8Hz） | 填充 60–85%，波形**锯齿**（±2.5px @2Hz） | 填充 85–100%，波形**尖刺**（±4px @3.5Hz）+ 波形顶端出现小「!」符号 |
| **L3 Boss 体态**（diegetic） | Boss mesh 微抖 + 呼吸 + 手部 | 静止 | 呼吸频率 +30%，剑柄微抖 | 身体 ±0.01m 抖动，拔剑僵直 +0.3s | ±0.02m 抖，剑脱手喜感节拍（§01-3.2） |

- **色盲安全**：色相编码（蓝 #4a90d9 → 橙 #f5a623 → 红 #d93025）仅作辅助，主线索是 **L2 波形形状（平→尖）** 与 **L3 姿势抖动**；L1 透明度递增对全色盲亦成立。
- **注意力纪律**：meter 常驻但小；焦虑 < 40 且 5s 无增量时 meter 淡至 20% 透明度（不消失，保持可读）。
- **禁止项**：不弹「焦虑 +12」数字气泡、不做屏幕中央任何常驻条、不改变全局色相（红场冲击只允许 vignette 与攻击特效）。

### 2.2 剧本选择 UI（Pattern Picker）

- **出现时机**：Wait 阶段末尾（wait 倒计时 ≥ 1s 时入场动画 0.3s），玩家未选不进入 sense。
- **布局**：屏幕水平居中偏下 40%，3 张卡横排（⛔ 砍癫狂戏剧后自适应为 2 张，`SCRIPT_COUNT ≥ 2` 即可）。卡规格 240×150px、间距 24px。
- **卡片内容**：① 剧本名（庄重威严 / 悲情独白 / 癫狂戏剧⛔）② 一句风味文案（一句，≤12 字）③ 难度星 ★☆☆ / ★★☆ / ★★★ + 难度文字（从容 / 吃力 / 失控）④ 右下角按键徽章「1 / 2 / 3」。
- **交互**：hover 卡片上浮 6px + 暖光描边；数字键或点击选择 → 卡片 0.25s 白化收缩 → 进入 sense。**无闪烁**（允许 ≤0.25s 单次淡出）。
- **首轮提示**：卡片上方一行小字「难度越高，开场越紧张」（仅第一轮显示）。

### 2.3 对话呈现（Dialogue Box）

| 规格 | 值 |
|------|-----|
| 位置/尺寸 | 底部居中，宽 60%，高 ~90px，距底 24px；圆角面板，深蓝底 85% 不透明 |
| 说话人标签 | 盒内左上角「魔王 · 洛根」（L 池对应标签），18px 金色 |
| 打字机 | 18 字/s；打字中按 Space = 立即补全；句间不自动推进 |
| 多句队列 | 右下角「▼」提示还有待播句 |

**焦虑对打字机渲染的影响**（形状化的"忘词"，颜色均为辅助）：

| 效果 | 触发 | 渲染样式 |
|------|------|----------|
| 结巴 | 紧张带 10% | 单字重复 + 省略：「我…我…我是这座城堡的」 |
| 整句遗忘 | 发抖带 15% / 恐慌带 30% | 文本替换为「……」静默 1.5s；60% 概率补一句 L_PANIC 即兴（**琥珀色 #ff9a76**，无打字机断续） |
| 破碎断句 | 恐慌带 30% | 文本断行、词间留白不均：「不—— 这不对—— 你们不该」 |
| 自由发挥 | 打断出戏（§01-5.4） | 文本色 **暖橙 #ffb36b**，左上角标签「即兴」；100% 完整、无断续（真实性奖励） |

### 2.4 自评表 UI（Rating Sheet）

- **出现**：perform 结束 → 全屏 40% 暗化遮罩（舞台仍可见），中央面板 480×420px。
- **结构**：4 行轴，每行 = 轴名 + 1–5 星按钮 + 事实数据卡：

| 行 | 轴名 | 星级描述（1–5 hover 显示） | 事实数据卡（常显） |
|----|------|----------------------------|--------------------|
| A1 | 走位流畅度 | 灾难/勉强/一般/不错/惊艳 | 「站位 72% · 抖动 3%」 |
| A2 | 台词感染力 | 同上 | 「忘词 ×2 · 完整率 85%」 |
| A3 | 视觉效果 | 同上 | 「阶段 2/3 · 最大连击 5」 |
| A4 | 有没有让玩家记住 | 不可点（🔒 系统代填） | 「玩家停留 12s · 弹幕 1 条」+ L_EVAL 反应句 |

- **输入**：↑/↓ 选行 → ←/→ 或数字 1–5 打星；鼠标直接点星；Space/Enter 提交。10s 倒计时环（面板右上角，剩余 3s 变橙）。
- **提交反馈**：总评结果 0.6s 横幅（完美 ★4.5+ / 合格 / 失格）+ 焦虑修正的柔和色脉冲（绿/灰/红，≤0.3s，无闪字）。
- **玩家评分（可选）**：底部按钮「看看玩家怎么说」（E 或点击）——仅当 30% 概率判定生效且总评 ≥4★ 时显示；触发后揭晓墙上涂鸦 1–5★；5★ → L_P5STAR 特殊台词（困惑 + 眼眶湿）。

### 2.5 日记 UI（Diary）

- **出现**：自评提交后，右侧翻开"日记本"面板（羊皮纸色 320×400px，书页翻页动画 0.4s）。
- **内容**：4–6 条候选句 chips（来自 L_DIARY 池，含「我不够好」变体 ×3），每条带情绪色标：正面（绿 #7ac97a）/ 负面（灰蓝 #8a9bb5）/ 自嘲（橙 #e8a25a）。
- **交互**：方向键或 1–6 选择 → Space/点击盖章（0.3s 印章动画 + 墨迹音）→ 句子写入当日页 → 焦虑修正脉冲（R09 −10 绿 / R10 +8 灰蓝）→ 面板合拢 → diary → wait。
- **⛔ 砍底**：只保留 1 条预设自动写入（L_DIARY_01），跳过选择 UI，仅播放书写动画。

### 2.6 档案 UI（Archive）

- **位置**：Wait 阶段屏幕右缘，纵向堆叠卡片（最多 3 张可见，其余收进堆叠）。
- **卡片**：泛黄纸片 200×120px，正面 = 挑战者代号（匿名，如「剑士 乙」）+ 星级 + 一句评语（L_ARCH_xx，1–2 句）。
- **交互**：E 或点击翻开 → 放大到 360×240px 停留（阅读约 3–4s，不自动关闭）→ 再按 E/点击合拢。首轮 2 张预设档案；每轮结束后追加 1 张"上轮实录生成档案"（L_ARCH_GEN 模板填数据）。
- **数值挂钩**：每翻开 1 条 +2 焦虑（单轮上限 +4，翻到上限后卡片变灰不可再开）。

### 2.7 攻略弹幕 Overlay（Barrage）

- **出现**：Sense 阶段开始（R1 概率 40%，随轮次升级见 §01-2.2）+ Perform 中 line beat 触发；每轮 ≤3 条。
- **呈现**：屏幕顶部 12% 高度区域，从右向左滚动（60px/s），白字 85% 不透明 + 深色描边，字号 20px；同屏 ≤3 条。
- **触发反馈**：每条出现时 S07 +12 焦虑 + 边缘 1.2s 橙色微闪（透明度 ≤0.25，**无频闪**）。
- **文本**：L_BARRAGE_01..06（攻略向、略带损）。
- **共情后（§5 4:00 pivot）**：新弹幕停止生成；已有弹幕 2s 内淡出（Boss 不再被"弹幕"打扰）。

## 3. 输入方案（全键盘 + 鼠标）

| 键 | 状态 | 作用 |
|----|------|------|
| W / A / S / D | perform（自由模式亦同） | 控制 Boss 走位（移动） |
| 鼠标移动 | perform | 瞄准（剑气方向）；无需锁定准星 UI，用 beat 圈提示 |
| LMB | perform | 在 beat 提示圈内出招（attack beat 触发）；圈外按 = 无效挥剑（不触发惩罚） |
| E | wait / evaluate / diary / 档案 | 交互键：翻开档案、确认自评、提交日记、触发「看看玩家怎么说」 |
| Space | 全局 | 推进对话 / 补全打字机 / 确认选择（自评、日记、pause 菜单确认） |
| 1 / 2 / 3 | wait 末尾 | 选择剧本卡片（对应卡片角标） |
| ↑ / ↓ | evaluate / diary | 自评表换行 / 日记候选句上下选择 |
| ← / → 或 1–5 | evaluate | 当前行打星 1–5 |
| Esc | run 任意时刻 | 打开/关闭暂停；打开状态下冻结一切计时 |
| R | pause / ending / title | 重新开始：pause 中需经确认条；ending 直接重开；title 无效 |
| M | 任意状态 | 静音/取消静音（toast 反馈，设置持久化） |
| Enter | 全局 | 等效 Space |
| 任意键 | intro | 跳过过场字幕 |

**冲突规避**：WASD 与剧本键 1–3、打星键 1–5 不同状态，无冲突；pause 冻结期间所有输入仅响应菜单项。

## 4. 节奏时间线（0:00–5:30，四轮基准）

> 列说明：**触发** = 状态 × 事件；**内容 id** 见 §01-11；**焦虑预期** 为典型值（不含玩家差异）。

| 时间 | 状态 | 触发事件 | 内容 id | 玩家感受 | 焦虑预期 |
|------|------|----------|---------|----------|----------|
| 0:00 | title/intro | 启动 → 字幕「又是新的一天」 | L_TITLE | 孤独、好奇 | — |
| 0:10 | wait(R1) | 字幕结束 → 王座自语 | L_AMB_01 | 沉浸 | 30 |
| 0:14 | wait(R1) | 2s 后档案栈浮出 | L_ARCH_01/02 | 心虚、好笑 | 30（翻档案 +2） |
| 0:32 | sense(R1) | 脚步渐强 + 影子拉长；首见 S04 | — | 紧张、喜感 | 30→38 |
| 0:36 | sense(R1) | 第一条弹幕（40%） | L_BARRAGE_xx | 社死 | +12 |
| 0:40 | perform(R1) | 剧本选择卡 → 选定 → P1 首 beat | script_dignity/tragic | 屏息 | +8/+12 剧本加成 |
| 1:10 | perform | 台词锚点，紧张带 10% 结巴/忘词 | L_DIG_102 等 | 心疼 | S12 +6 |
| 1:40 | perform | 玩家完美闪避 | — | 挫败 | S09 +10 |
| 2:10 | perform | 阶段完成 → 小喘息 | R03 −8 | 松一口气 | 回落 |
| 2:50 | perform | 第一次击倒 → 爬起先整理头发（RECOVER 1.5s） | — | 意外、笑 | HP 归零不终止轮次 |
| 3:10 | perform | 打断/出戏（若触发）→ 灯光转暖 | L_FREE_xx | 释放、真实 | S13 +15 |
| **4:00** | perform | **共情 pivot（§5 触发条件）** | — | 屏息、被看见 | **焦虑停止爬升** |
| 4:30 | evaluate | 战斗收尾（3/3 或 90s 或击倒）→ 自评表 | L_EVAL_xx | 反思 | R05–R08 修正 |
| 4:45 | evaluate | （可选）玩家评分揭示 | L_P5STAR | 困惑、眼眶湿 | R11 −12 |
| 4:55 | diary | 日记书写 | L_DIARY_xx | 温柔 | R09 −10 / R10 +8 |
| 5:10 | wait/ending | R1→R2 循环；第 4 轮后进结算 | L_ARCH_GEN | 悬念 | 轮次疲劳 +4 |
| 5:28 | ending | 谢幕：normalA（被看见度≥60，暖）/ normalB（冷） | L_END_N1/N2 | 留白、回味 | 灯光随被看见度定格 |

- **轮次节奏律**：每轮 = 紧张渐强（sense→perform 前 2 阶段）→ 释放（阶段完成/评估）→ 沉思（diary），避免连续 30s 无喘息。
- **强制收尾**：perform ≥90s 强制进入 evaluate，保证四轮 ≤ 6.5 分钟。

### 4.1 共情 pivot（4:00）——游戏性实际改变清单

**触发条件**（一次，满足即永久生效）：R3 或 R4 中，`被看见度 ≥ 60` 且（单次连击 ≥4 **或** 全本 3/3 完成）。触发时镜头 4s 内缓推 1.0→1.12，灯光 60%→100%，弦乐走音消失、钢琴主导。

| # | 改变 | 具体实现（core/engine 侧） |
|---|------|----------------------------|
| 1 | **焦虑停止爬升** | 所有焦虑源 S05–S11 增量乘 0（弹幕冻结、忘词停发）；自然衰减 R01 继续；当前值即上限 |
| 2 | **Boss 打偏变"编排"** | 落空渲染类别切换：剑光落点变成地面星尘图案 + 灯光造型（不再是"打偏"红叉/尘土），命中判定不变 |
| 3 | **接剑变慢** | 玩家剑返回速度 ×0.45，慢动作 + 音调下沉 2 个半音（"玩家也放慢了"） |
| 4 | **台词 100% 完整** | 完整率骰子强制通过，即使处于恐慌带也不忘词——"他在认真演" |
| 5 | **弹幕消失** | 新弹幕不再生成，已有弹幕 2s 淡出（§2.7） |
| 6 | **影子减速** | PlayerSurrogate.approachSpeed ×0.8（玩家影子逼近放缓） |
| 7 | **A4 轴证据暖心化** | 评估表 A4 证据文案从「停留 12s」变为「……他看了很久」 |

> 设计意图：pivot 是"表演"与"被看见"的合流——机制上立刻放松（不再惩罚失误），情绪上立刻收紧（Boss 第一次不演、而是真的在演）。玩家察觉到的不是数值变化，而是**失误被允许了**。

## 5. 可访问性（Accessibility）

| 项 | 规格 |
|----|------|
| 随时暂停 | Esc 任意时刻（含倒计时/打字中），冻结一切；无惩罚 |
| 文字大小 | 对话 ≥ 22px（1080p 等效）；title 设置提供文本缩放 100% / 125% / 150%（localStorage 持久化，三档循环切换） |
| 无频闪 | 全局规则：任何闪烁不透明度 ≤0.35、单次 ≤0.3s、频率 ≤3Hz；vignette 为静态渐变；弹幕无闪烁；自评/日记反馈均为柔和色脉冲 |
| 色盲安全 | 焦虑主线索 = 形状（波形 平→尖 + Boss 姿势抖动 + vignette 明度）；颜色仅辅助；星级 = 星形填充 + 数字标签（★4/5 同时显示）；剧本难度 = ★ 数量 + 难度文字 |
| 信息冗余 | 每一条音效都有视觉对应：脚步声→影子拉长，弹幕→文本，命中→光效，忘词→「……」文本；M 静音后游戏仍完整可玩 |
| 输入宽容 | 所有关键输入有鼠标 + 键盘双路径；自评 10s 倒计时到自动提交当前选择（不丢进度） |

## 6. Playtest 验收清单（单次 5 分钟通关后判定）

> 一项为假 = 该里程碑不合格，优先修对应条目（括号内为责任人）。

1. 玩家 60s 内理解「我是 Boss，挑战者只是影子」（不需要教程文字）——（UX/3D）
2. 不读任何说明也能完成第一轮 3 阶段——（UX/combat）
3. 玩家能说出"焦虑在涨/跌"且不依赖任何数字——（UX/HUD）
4. 忘词出现时玩家感到"心疼"而非"出 bug"——（UX/content）
5. 自评表 4 轴 10s 内可完成提交，且玩家觉得"公平"（事实卡与星数对得上）——（UX）
6. 剧本选择 3 卡（或 2 卡）在 5s 内完成决策，难度星与开局手感一致——（UX/balance）
7. 玩家意识到日记里"我不够好"的隐喻（被引导、不被强推）——（UX/content）
8. 4:00 共情 pivot 可被明确感知（玩家会说"他好像认真起来了"）——（UX/audio/3D）
9. 单轮 60–90s；四轮 + 结局总时长落在 5–8 分钟——（core/pacing）
10. 全程无超阈值闪烁；模拟色盲（灰阶截图）下焦虑/星级/难度仍可读——（UX）
11. Esc 暂停任意时刻可用，恢复后无跳变；R 重开有确认——（core/UX）
12. 弹幕每轮 ≤3 条、不遮挡舞台中线、文本可读——（UX）
13. 结局后玩家愿意看完谢幕再退出（不主动关页）——（UX/content）
14. ⛔ 隐藏结局（若保留）：连续 3 次"我不够好"可在 3 轮内自然达成——（core/UX）
15. 60 FPS @ 1080p，HUD 总占用 < 12% 屏幕面积——（engine/UX）
