# 《Boss 的焦虑》— 美术方向设计（03）

> 适用于 Designer Agent 3 / 场景 · Boss · 动画 · FX 的全部实现细节。
> 所有数值均为可直接编码的具体值；坐标系：Three.js 右手系，Y 向上，单位米（m）。
> 资源策略：**零资产文件**。全部使用 Three.js 图元 + 程序化 Canvas 纹理（≤ 1024²）。

---

## 1. 总览

- **视觉基调**：一座只有 Boss 一个人的哥特王座厅。冷蓝"空房间" + 单点暖橙烛光 + 攻击瞬间的血红。舞台剧感（固定摄像机 + 对角线构图 + 雾 + 暗角）。
- **渲染管线（顺序）**：Scene → 阴影（1 盏方向光 PCFSoft 1024）→ 后处理链 `[UnrealBloomPass] → [VignettePass]` → 输出。无 SSR / SSAO / DOF。
- **Renderer 设置**：`antialias: true`、`toneMapping = ACESFilmic`、`exposure = 1.1`、`pixelRatio = min(devicePixelRatio, 1.75)`。
- **场景层级**：
  ```
  GameScene (Group)
  ├── room      (floor, walls, columns, windows, door arch)
  ├── dais      (台阶 2 级)
  ├── throne    (王座, 高 2.6m)
  ├── archive   (档案架 + 24 本书 InstancedMesh)
  ├── candles   (蜡台 ×6, 每个 = 蜡体 + 火焰 sprite)
  ├── chains    (锁链 ×2, InstancedMesh)
  ├── rug       (地毯)
  ├── boss      (Boss 根节点, 见 §6)
  ├── playerConcept (影子 blob + 脚步声 + 剑)
  ├── fx        (粒子池 / 弹幕 billboard / 全屏 flash)
  └── lights    (方向光 / 半球光 / 环境光 / 主烛光 PointLight)
  ```

### 3.2 每材质使用规则

1. **环境冷色**（墙/柱/锁链/台阶）只用 base 蓝系 4 色，材质粗糙度 ≥ 0.85 —— 保证 Boss 和暖光是画面里唯一的高亮。
2. **暖橙只出现在"有火焰的地方"**：烛火 sprite、PointLight、蜡烛蜡体高光。禁止暖橙出现在金属/石头上（除烛台反射外）。
3. **血红是"事件色"**：只用于 3 类时机 —— 攻击 telegraph（蓄力辉光）、命中反馈（spark/血闪）、Boss 胸甲受击脉冲。常态画面不允许出现血红（地毯暗红 `#8B0000` 例外，作为纯度极低的底色）。
4. **Boss 本体**：盔甲只用钢系 + 哑金 + 旧皮，亮度必须比后墙高 ≥ 2.5×（对比度规则，见 §5.4），靠钢亮 `#4A5878` 与冷蓝环境区分。
5. **玻璃/透明材质**：透明度必须 < 0.4，且 `depthWrite: false`，避免半透明排序问题。
6. **自发光**（火焰、玻璃窗、弹幕）统一走 `MeshBasicMaterial` + `toneMapped: false`，是 Bloom 的唯一来源，强度 ∈ [1.2, 2.5]。

## 4. 灯光 spec

### 4.1 主光：烛火 PointLight（暖橙，无阴影）

- `THREE.PointLight(0xFF9E4F, 50, 22, 2)`，位置 **(-5.5, 1.05, -4.5)**（台阶左烛上方）。
- **不 castShadow**（点光源阴影 = 6 面 cubemap，烛火闪烁下重渲成本爆炸，由 §4.2 方向光统一承担阴影）。
- **闪烁噪声 spec**：
  - 主频：1D 值噪声（hash + smoothstep 插值），采样频率 `t × 11.3`，输出 n ∈ [0,1]；
  - 强度公式：`I(t) = 50 × (1 + 0.13 × noise(t·11.3) + 0.07 × sin(2π × 0.7 × t + φ))`，φ 每次进入 Wait 态随机；
  - 位置抖动：±0.02 m，同噪声采样 `t × 11.3`，沿 x、z 各乘 0.5 系数；
  - 火焰 Sprite 的 scale 同步 = `0.16 × (1 + 0.15 × noise(t·11.3))`，颜色在 `#FF9E4F ↔ #FFB066` 之间 lerp（同一噪声源）。
- 表演态（Perform 阶段）：强度 ×1.3；自评态（Evaluate）：×0.8。

### 4.2 填充光：冷色 DirectionalLight（唯一阴影源）

- `THREE.DirectionalLight(0x6E8FBF, 0.35)`，位置 (-6, 9, 2)，target (-2, 1, -4)。
- **castShadow = true**：
  - `shadow.mapSize = 1024×1024`，`shadow.camera` 盒 ±14，near 1 / far 30；
  - `shadow.bias = -0.0005`，`shadow.normalBias = 0.02`；
  - `renderer.shadowMap.type = THREE.PCFSoftShadowMap`。
- 只有"大件"castShadow：Boss、王座、台阶、柱子、档案架、玩家影子 blob。蜡烛/书/锁链/火焰不参与，省 20% 阴影工作量。

### 4.3 环境光

- `THREE.HemisphereLight(0x2A3E66, 0x0A0C16, 0.35)`（天空冷蓝 / 地面近黑）。
- `THREE.AmbientLight(0x141B33, 0.25)`。

### 4.4 雾

- `THREE.Fog(0x0A0E22, 12, 44)`：王座距相机 ≈ 19 m → 雾系数 ≈ 0.16（Boss 完全清晰）；后墙 ≈ 24% 雾化；房间远端角落消失。
- 悲情独白剧本：`Fog(0x0A0E22, 8, 30)`（更浓，更孤独）。
- 隐藏结局（stretch）：`Fog(0x101A3A, 4, 18)` + 暖白光（见 §10）。

## 5. 摄像机 spec（固定对角舞台构图）

### 5.1 基础位姿

| 参数 | 值 |
|---|---|
| position | **(9.5, 6.5, 8.5)** |
| lookAt 目标 | **(-1, 1.8, -6.5)**（王座 + Boss 头部高度） |
| up | (0, 1, 0) |
| quaternion（等价，用 `camera.lookAt` 计算即可） | (w,x,y,z) = **(0.9464, -0.1197, 0.2980, 0.0377)**，误差 < 0.5°，允许 lookAt 优先 |
| FOV（垂直） | **40°**（舞台感；焦虑拉到 34°，见 5.3） |
| near / far | 0.5 / 80 |
| DOF 注 | Three.js 无内置 DOF；**默认用雾 + 暗角伪装景深，不开 BokehPass**（在可砍清单）。若上 BokehPass：focus = 19.4 m（相机→王座距离 ≈ 19），aperture 0.012，maxblur 0.006 |

### 5.2 缓慢漂移（呼吸感）

- 目标偏移量公式：
  ```
  A = 0.08                                    // 基线振幅
  A = lerp(A, 0.16, clamp((anxiety-60)/25, 0, 1))   // 焦虑放大
  offset = A × ( sin(0.11·2π·t) · (1.0, 0.35, 0.8)
              + 0.5 × sin(0.23·2π·t + 1.7) · (0.6, 0.15, 0.5) )
  camera.position = basePos + offset          // 逐帧 damped: pos = lerp(pos, base+offset, 0.04)
  ```
- lookAt 目标微漂移 ±0.05 m（同公式 × 0.6，低频分量）。
- 焦虑 > 85：叠加 2.5 Hz 微颤，振幅 0.01，用随机相位正弦。

### 5.3 焦虑联动

- FOV：`fov = 40 → 34`（焦虑 0→100，lerp 系数 0.03/帧）——焦虑越高视野越"窄"，压迫感。
- 振幅 A：见 5.2。命中瞬间：一次性脉冲 `A += 0.05`，0.6 s 内回落到当前带目标。

### 5.4 构图规则（美术铁律）

1. **Boss 永远在画面左 1/3**：王座 x=-4.2 在 1080p 下投影到屏幕左 1/3 竖线附近。任何新道具不得把 Boss 挤出该区域。
2. **玩家走道永远在右 1/3**：门洞 (11.9, 2) → 站位 (1.5, -1) 连线投影覆盖右 1/3。中 1/3 留白给"动作发生空间"。
3. **不许遮挡**：柱 (-7,-8.2) 投影在 Boss 左侧约 1/4 屏外 —— 保持现有坐标，Boss 头部 (y≈1.9) 不得与任何窗口/蜡烛在屏上重合（窗口在 x=-0.5、5.5，已留出间隙）。
4. **对比度**：Boss 主体（钢亮 `#4A5878`）与后墙（`#0B1026`）亮度比 ≥ 2.5:1；当 Boss 处于暗位时用烛火 PointLight 补光，不许调环境光。
5. **红色只进事件帧**：任何时刻画面血红像素占比 < 5%（命中帧除外）。

## 6. Boss 视觉 spec

### 6.1 总参数

- 坐姿总高 ≈ 1.95 m（角顶），站姿 ≈ 2.6 m；肩宽 1.2 m。
- 根节点 `boss` 放置在 **(x, 1.0, z)**，y=1.0 = 髋部 = 坐姿座面高度（世界坐标就位后局部坐标以髋为原点）。Battle 时位置 (0, 1.0, -5.8)（王座前 1 m）。
- 朝向 +z。所有关节部件挂在 **pivot Group** 上（见 §7 动画机制）。
- **总 tris ≈ 2.4k**（预算 8k，余量充足）。
- silhouette 规则：
  - 外轮廓必须一眼读出"宽肩 + 角 + 眼镜 + 大披风"四个特征（近景、剪影测试 ≤ 0.5 s 识别）；
  - 眼镜是唯一"错误地精致"的物件（反差的温柔），永远不许被角/披风遮住；
  - 头部/角区不与其他高亮物重叠（见 §5.4 规则 3）。

## 7. 动画 spec（无骨骼：pivot Group + 手动 lerp / GSAP timeline）

### 7.1 通用机制

- 每个关节 = 一个 pivot Group（肩/肘/手/头/根/胸），动画 = `damp(current, target, lambda, dt)`（lambda 默认 12）或 GSAP keyframe timeline。
- 根节点可整体位移/旋转（跌倒、颤抖、起身）；躯干/头/手各自在 pivot 上旋转。
- 所有动画时间单位秒，easing 用 GSAP 命名（`power2.out` 等）或等价缓动函数。
- 状态切换时统一 `damp` 过渡，禁止瞬移（忘词 freeze 除外，见 7.12）。

### 7.2 动画清单

| # | 动画 | 时长 | easing | 触发 | 参数（精确值） |
|---|---|---|---|---|---|
| A1 | idle 呼吸 | ∞ | 正弦 | Wait 态常驻 | 根 y = base + `0.03·sin(2π·0.22·t)`；胸 scale (1, `1+0.012·sin`, 1)；头 y +0.008 同相 |
| A2 | 手指敲桌 | 3–8 s 随机 | 线性 | Wait > 25 s 或焦虑 40–70 | 食指 ±9°、中指 ±7° 绕 x，2.2 Hz；开场 2 下重敲（幅度 ×1.6） |
| A3 | 整理盔甲 | 0.8 s | power2.out | Sense 开始 | 右肩 pivot yaw -15°→0；右手 2 次拍胸（0.2 s/次，拍时 x 转 -12°） |
| A4 | 翻档案 | 2.5 s | power2.inOut | Wait 态中随机 | 头倾斜 -18°；右手前伸（肩 yaw +35°、pitch -20°）→ 取书 → 收回胸前；书 pivot 每 1.4 s 翻页 20° |
| A5 | 挥手（攻击开场） | 1.7 s | power2.out / power2.inOut | Perform 每阶段开始 | 0.5 s 抬臂（OutBack）；剑 glow 亮起；0.8 s 横扫 60°→-60°（InOutQuad，弧顶出 trail）；0.4 s 收臂 |
| A6 | 踉跄（被命中） | 0.85 s | power2.in / power2.out | 受到任何命中 | 0.35 s 根后仰 12° + 位移 (0, 0, +0.15)（InOutCubic）；0.5 s 回正；头同时 -8° |
| A7 | 跌倒 + 整理头发 | **3.35 s 精确节拍** | 见下 | 首次被打倒 | **编排见 7.3** |
| A8 | 鞠躬（谢幕） | 3.0 s | 见下 | 玩家离开 / 结局 | 1.1 s 根前倾 -28°（power2.out）+ 右臂胸前横扫 90°（0.9 s）+ 头 -20°；hold 1.0 s；0.9 s 起身（power2.in）；鞠躬时烛光 ×1.15、Bloom 0.55→0.7 |
| A9 | 写日记 | 6.0 s | 见下 | Evaluate 态 | **编排见 7.4** |
| A10 | 焦虑颤抖 | 持续 | 正弦（随机相位） | 焦虑 > 30 | **按档位见 7.5** |
| A11 | 忘词 freeze | 1.2 s | — | 台词耗尽 & 焦虑 > 70 | **见 7.6** |
| A12 | 披风摆动 | 持续 | 正弦 | 常驻 | 披风 Group 绕 z 摇摆 ±2° @ 0.6 Hz + 根动时幅度 ×2（由根速度驱动，阻尼 4） |
| A13 | 翻页（档案） | 0.15 s | power2.in | A4 循环 | 书 pivot 绕 y 15°，回 0 |

### 7.3 跌倒 + 整理头发（精确编排）

| t (s) | 事件 | 参数 |
|---|---|---|
| 0.00 | 命中 flash + 踉跄 | 见 A6 前 0.35 s |
| 0.00–0.70 | 跌倒 | 根 pitch → -75°（power2.in），根 y → 0.35（-0.65 m），头 roll +15° |
| 0.70–1.15 | 趴地静止 | 全动画目标冻结；披风 settle 绕 z 0→0.12（0.3 s） |
| 1.15 | **整理头发 beat** | 右手 pivot 至头部（0.22 s，power3.out），头倾斜 -10° |
| 1.37–1.87 | 捋发 2 下 | 手绕 x ±6° @ 4 Hz（0.5 s），幅度 0.03 m 位移 |
| 1.87–2.15 | 收手抬头 | 手回位（0.28 s power2.inOut），头回正 |
| 2.15–2.95 | 起身 | 根 y → 1.0、pitch → 0（0.8 s power2.out）；左手同时撑膝（pivot yaw +20° → 0） |
| 2.95–3.35 | 整理盔甲收尾 | 复用 A3（0.8 s，幅度 ×0.7） |

**喜剧核心**：1.15 s 的"先整理头发再站起"绝不能调快；若 jam 时间紧只保留 1.15–1.87 段 + 直接起身。

### 7.4 写日记（编排）

| t (s) | 事件 | 参数 |
|---|---|---|
| 0.0–0.4 | 日记出现 | 书 Group 从腰侧移到膝上 (0.35, 0.75, 0.35)，旋转 -30°（power2.out） |
| 0.4–0.8 | 右手就位 | 手 pivot 到书上方，握笔 |
| 0.8–4.3 | 书写 | 手绕 z ±3° @ 3.5 Hz + 小幅位移（0.02 m 椭圆），头低 12° |
| 4.3–4.9 | 思考停顿 | 头抬起 15°（power2.inOut），手停，眼望远处（根微转 yaw 6°） |
| 4.9–6.0 | 翻页合书 | 书 y 转 15°（0.15 s）→ 合拢（0.4 s）；手回收；书降回腰侧 |

### 7.5 焦虑颤抖（分档位，根 + 头叠加）

| 焦虑带 | 根振幅 / 频率 | 头额外 | 摄像机联动 |
|---|---|---|---|
| 0–30 | 无（平静） | 0 | 无 |
| 30–50 | 0.01 m / 1.5 Hz | +0.005 m | 无 |
| 50–70 | 0.02 m / 2.2 Hz | +0.01 m | FOV -2° |
| 70–90 | 0.035 m / 3.2 Hz | +0.02 m | FOV -4°，相机 A→0.16 |
| 90–100 | 0.06 m / 4.5 Hz | +0.03 m | FOV -6°，相机 A→0.22 + 0.01 微颤 |

- 颤抖 = 两个不同相正弦之和，**每 1 s 重掷随机相位**（避免可预测循环）。
- 跨档过渡：振幅 lerp，系数 0.08/帧。

### 7.6 忘词 freeze

- 触发：台词队列为空 且 焦虑 > 70。
- 表现：所有 damp lambda 置 0（动画"冻住"）1.2 s；前 0.5 s 头缓慢下垂 8°（power2.inOut）；第 1.2 s 后恢复 lambda=12 并衔接 A3（假装整理盔甲掩饰）。
- 附加：若焦虑 > 85，头单独 8 Hz / 0.005 m 微颤（嘴硬抖动）。

- `windowCanvas` 512²：`#0A0E22`→`#5A7BB0` 竖向渐变 + 窗棂格线（4×3）+ 拱顶弧线。
- `textCanvas`（弹幕）：`fillText` 白字 + 1px 黑描边，128×32 按文案实时生成。
