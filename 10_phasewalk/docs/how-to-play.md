# PHASEWALK（四相行者）· 怎么玩

> 四层世界同时叠在一张纸里：固 / 液 / 气 / 等离子。你只能站在与你同相的那一层——**切相就是换关卡**，空中的**相弹**就是你的二段跳（动量守恒）。

## 快速开始

```bash
npm install
npm run dev      # 打开 http://localhost:5187
```

## 操作

| 输入 | 作用 |
|---|---|
| `W` / `A` / `S` / `D`（或方向键） | 移动 |
| `Space` | 跳跃（按住持续跳/游/悬停，随相变化） |
| `Tab`（按住） | 打开**四相径向菜单**；WASD / 鼠标悬停选相，松开 Tab 切换 |
| `Enter` / `Space` | 开始演出 / 通过层卡 |
| `Esc` / `P` | 暂停 |
| `R` | 重开（层 / 整局） |

**径向菜单象限**：`↑` = 气 · `↓` = 固 · `←` = 液 · `→` = 焰。松开 Tab 即切换，冷却 0.15s。

## 四种相 = 四种玩法

| 相 | 动词 | 说明 |
|---|---|---|
| 固 solid | 固化造路 | 凝相液池成可站立的桥 |
| 液 liquid | 游泳 | 按住 Space 在水中游动 |
| 气 gas | 悬停 | 按住 Space 缓慢飘浮，穿过无实形的通风口 |
| 焰 plasma | 爆冲 + 反射 | 二段爆冲；把子弹弹回去拆掉发射器 |

空中的**相弹**：起跳后切相，动量保持、重力瞬间换挡——这是全游戏唯一的二段跳。

## 一关怎么打

- **5 层四相塔**：F1 启示厅（四相各一条路汇入金门）→ F2–F4 单相深化（流瀑/息井/焰网）→ F5 相核室四相均衡收尾。
- **收集 20 枚相尘**（每层 4 枚）：收集数就是结局的投票。
- **死亡有代价但公平**：地面全相实心，摔倒永不致死；唯一死因 = 危险区 + 子弹（无相区灰斑全相即死、雷云、相灵弹）。死后**回到出生点 + 相位移回固相**，相尘保留——损失的是路线，不是收藏。
- **金门开启**需要至少 3 种相：换相探索是唯一的通关方式。
