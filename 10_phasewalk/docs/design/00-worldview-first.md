# 00 — 世界观先行 (Worldview-First) + 前 5 分钟体验剧本

> **宣言**：PHASEWALK 的体验不是"玩法 + 世界观皮肤"，而是**世界观的复刻**——玩家在 5 分钟内亲身重演"四相裂变"这个宇宙事件。世界观是唯一的事实源；每一个机制、每一秒剧本、每一个声音都要能回答"这是世界观的哪一句"。
> 读者：所有人（团队 + 未来 agent onboarding）。这是本项目**第一个**要读的文档。

## 1. 世界观的 9 句事实（The 9 Facts — 一切从此推导）

1. **世界裂成四层**：固/液/气/等离子四相重叠在同一空间，各归其位、互不相通（石中人不渡水）。
2. **相核碎了**：世界本是一纸，相核是压纸的镇石；它碎了，纸页散开成四张。
3. **相行者生在裂缝**：阿行不属于任何一相——所以它能站上任何一层（代价：任何一层都不真正记住它）。
4. **相弹是裂变的重演**：裂变那刻，万物是在"动量守恒"里散开的——所以切相时动量守恒，是宇宙的法律，不是游戏规则。
5. **相尘是相核的碎屑**：收集相尘 = 拼回世界。每捡一颗，世界离"归一或共存"近一步。
6. **无相者吃相**：它不站任何一层，它把层吃掉——被吃的区域四层同时褪色为灰白静滞。
7. **四相灵是失职的守卫**：它们不是敌人，是太久没人经过、忘了本职的孤独者。
8. **锁链金是四相的缝合线**：塔身四道锁链=四种真理；金色 = 跨相之处的颜色。
9. **塔是轴心**：只有塔里，四层还重叠得可以互相看见——爬塔 = 让世界重新互相看见。

## 2. 世界观 → 机制映射表（每句事实必须落成可玩的东西）

| 世界观事实 | 机制落点 | 剧本拍（§3） |
|---|---|---|
| ① 四层重叠 | 4 层几何**同时渲染**；切相 = 换碰撞组 = 换关卡 | 0:12 四相同现 |
| ① 各相各归其位 | 碰撞按相过滤；固相断口只有液管可渡 | 1:30 断口 |
| ③ 相行者无相 | 切相只冷却 0.15s、无代价——"凡人"叙事反衬 | 全程 |
| ④ 动量守恒 | 相弹法则：velocity 不变、重力换档、零特例 | 1:30 / 4:00 |
| ⑤ 相尘 = 拼回 | 收集即进度；≥3/4 开门（硬核线漏 1 枚 = 世界没拼完的隐喻） | 全层 |
| ⑥ 无相者 | 出生点脚下 = 灰白无相区：**无声、无 BGM、无 HUD 提示**——静滞本身是叙事 | 0:00 |
| ⑧ 锁链金 | 金线门/金线 = 所有跨相机关的提示色 | 4:45 |
| ⑨ 塔是轴心 | 塔内 4 层才同时可见（塔外各归其位）——关卡制而非开放世界的叙事理由 | 全程 |

## 3. 前 5 分钟体验剧本（The First Five Minutes）

> 目标：**每 60 秒一个新真相，5 分钟 5 个真相，3 个极致时刻。** 情绪曲线：困惑 → 震撼 → 掌控 → 顿悟 → 轻盈 → 迅捷 → 圆满。

| 时间 | 拍 (beat) | 真相 | 极致时刻 |
|---|---|---|---|
| 0:00–0:12 | **出生**：黑幕 0.5s → 落在灰白无相区上（无声，无 BGM，无 HUD）→ 字幕 2s：「四相裂变之后，你是唯一能同时站在四层上的人。」 | ⑥ 静滞 | — |
| 0:12–0:45 | **四相同现**：走向石阶，按下 1（固相）→ 其余三层瞬间显现为幽灵纸片（青管/白风/紫线，15% 半透明）→ BGM 起（石相 drone + 缓拍） | ① 世界有四层 | ⭐① **四相同现** |
| 0:45–1:30 | **石阶上行**：走跳于固相石阶，捡第一颗相尘（固） | ⑤ | — |
| 1:30–2:30 | **断口**：石阶断裂，跳不过；幽灵管道横穿断口——按下 2（液相）→ 起跳瞬间切相（**相弹**）→ 动量带你坠进管口 → 顺流而下 → 液相尘 → 管尾切回固相落地 | ①④ 相弹 | ⭐② **第一次相弹** |
| 2:30–3:15 | **息井**：竖井无阶，风洞向上——按下 3（气相）乘风升起 → 气相尘 → 高台切回固相 | ① | — |
| 3:15–4:00 | **焰网**：深渊横亘，电线跨过——按下 4（等离子）沿电线滑行 → 焰相尘 → 跳线切回固相 | ① | — |
| 4:00–4:45 | **真相合流**：最后断口——**相弹二连**（固起跳 → 气腾空 → 固急坠）落在金门前的平台 | ④⑧ | ⭐③ **相弹二连** |
| 4:45–5:00 | **金门**：相尘 ≥3 → 锁链金点亮，门开 → 登层结算：「塔，还高着。」→ F2 预告黑场 | ⑤⑧ | — |

**节奏铁律（frozen）**：
- 每拍 ≤60s；超时 = 关卡设计失败（不是玩家慢）
- 死亡只在"重生点即脚下"的前提下允许（重生 ≤2s，不打断启示节奏）
- 无声 = 叙事（只有出生点无相区敢全静音）；相位切换永远有音叉声（220/330/440/660 Hz = 固/液/气/焰）
- HUD 前 45s 不显示（四相同现之前，世界不允许被 UI 打扰）

## 4. 极致时刻的"极致"标准（polish 验收）

| 时刻 | 验收标准 |
|---|---|
| ⭐① 四相同现 | 按下 1 的瞬间，3 层幽灵纸片 0.3s 内淡入 + 各相位音叉三连音；截图可当海报（4 层厚度肉眼可辨） |
| ⭐② 第一次相弹 | 玩家跳起→切相→坠入管口全程**零按键卡顿**；动量轨迹肉眼可见（保留 0.5s 拖尾）；首次 100% 成功率（管口捕获半径 1.2m 兜底） |
| ⭐③ 相弹二连 | 气→固急坠有 0.2s 的"失重拉长"帧；落地无硬直；失败 = 回到断口前 1s 处（不惩罚） |

## 5. 体验与世界观的一致性审计（每版 playtest 必答）

1. 有没有任何一个机制无法引用 §1 的事实？→ 砍掉
2. 有没有世界观事实没有机制落点？→ §2 表补行
3. 出生点是否绝对无声？切换是否有音叉？金线只出现在跨相处？
4. 5 分钟剧本有没有一拍超 60s？极致时刻是否满足 §4 验收？
5. 灰度模拟下（色弱模式）真相仍可被"形状语言"传达？
