# 01 — 美术方向头脑风暴：卡通渲染 3D (Toon Shading Art Direction)

> 用户指定偏好：**toon shading 3D**。本文 = 6 个候选视觉风格头脑风暴 → 评估矩阵 → 冻结选定 + 技术契约。
> 为什么 toon 是 PHASEWALK 的最优解（评审 D1）：4 层世界同时可见需要**颜色即信息**——toon 的平涂色块 + 墨线轮廓把"哪层是实心"变成一眼可读；PBR 的材质细节反而会淹没相位色。

## 1. 风格候选（头脑风暴 6 案）

### A. 皮影剪纸·纸叠 (Shadow-Puppet Paper-Cut) ⭐推荐
- **视觉**：每相 = 一张半透明纸片层，4 张纸叠成一座塔。平涂 2 阶色（受光/背光）+ 相位墨线轮廓 + 纸纹颗粒 + 硬投影（像皮影打在幕布上）
- **隐喻**：机制本身（4 层重叠）就是纸的物理——玩家切相 = 把手指压到另一张纸上
- **文化**：皮影戏 = 中国基因（仓库序列：股神模拟器/hotlineShanghai）+ 世界级视觉辨识度
- **技术**：MeshToonMaterial 4 阶 ramp + 倒置壳轮廓 + canvas 程序化纸纹 + 幕布硬阴影——**与 toon 管线 1:1 映射**
- **风险**：低。纸片半透明 alpha 排序需小心（按层深排序即可）

### B. 赛璐璐动画 (Cel Anime)
- **视觉**：干净赛璐璐 + 高饱和相位色 + 角色大眼睛 + 边缘光
- **优势**：玩家认知成本最低（动漫即卡通）；缺点：太常见，失去"没见过"的辨识度，4 层叠色容易像 UI 叠图

### C. 厚涂版画 (Thick Oil Print)
- **视觉**：油画厚涂 + 版画刀刻线，相位色做旧
- **优势**：艺术感强；缺点：旧化颗粒与 4 层透明叠加互相污染，可读性最差——**否决主因**

### D. 浮世绘叠层 (Ukiyo-e Layers)
- **视觉**：浮世绘平涂 + 云纹 + 每相一个经典浮世绘主色
- **优势**：层次美；缺点：日本基因与皮影中国基因重叠，仓库已有中国序列，且"叠层"浮世绘观感更轻浮

### E. 霓虹轮廓 (Neon Outline)
- **视觉**：黑底 + 相位霓虹线框 + 赛博网格
- **优势**：科技感、轮廓信息极强；缺点：世界观（相灵/塔/裂变）是东方幻想，霓虹错配；且"线框"看起来像 debug 模式

### F. 博物馆玻璃展柜 (Museum Vitrine)
- **视觉**：柔和天光 + 磨砂玻璃相层 + 展品式打光
- **优势**：4 层像 4 个展柜标本，"看见"的叙事最贴切；缺点：磨砂玻璃在 WebGL 需模糊贴花，成本高；气质偏静、缺动作游戏的"脆"

## 3. 冻结风格契约（A 案）

### 3.1 三铁律
1. **一纸一相**：每个相位 = 一张纸，纸的透明度 = 距离当前相的距离（当前相 100%，其余 15%）
2. **剪影即信息**：所有几何先保证剪影可读（黑暗中看轮廓也能认出是石阶/相液池/相灵眼/子弹）
3. **墨线即边界**：相内几何用**相位墨线**描边；跨相接触用**金线**（塔的锁链色）提示"这里有跨相机关"

### 3.2 四相调色板（frozen，8 色封顶）

| 相 | 纸色 | 受光 | 背光 | 墨线 | 高光 |
|---|---|---|---|---|---|
| 固 石 | #f2c57c 砂岩金 | #ffe1a8 | #b98e4e | #2a1f14 | #fff4d8 |
| 液 流 | #2ec4b6 湖青 | #6fe3d8 | #17857a | #0d2a33 | #d8fffb |
| 气 息 | #eef4f8 冷云白 | #ffffff | #9fb2c8 | #3a4a5c | #ffffff |
| 等离子 焰 | #b26bff 电紫 | #d9a6ff | #7a3fd0 | #1c0f2e | #f2e4ff |

> **polish 修订（2026-08-13, playtest U1/U4）**：气相纸色由暖白 `#f4f2ea` 改为冷云白 `#eef4f8`（暖白读成黄，与固相砂岩金混淆）；等离子高光由 `#ffe9a8`（黄）改为冷紫白 `#f2e4ff`——**黄色只属于固相**，任何其他相不允许出现黄色系高光。等离子图标 = 折线 `∿`（§3.3 契约），不是闪电。

- 背景幕布：深夜靛 `#1a1b2e`；塔身锁链金 `#ffd166`；无相区灰白 `#cfcfd4`（饱和度 0 的反相标志）
- **饱和度铁律**：只有"可交互的当前相"允许高饱和；幽灵层强制降低 40% 饱和度 + 15% alpha——颜色即触达性

### 3.3 相位图标语言（HUD 用）
- 固 = 方（石阶）· 液 = 圆环（流）· 气 = 三点（飘）· 等离子 = 折线（爆冲）——形状编码，不依赖颜色（色弱可玩）

### 3.4 toon 技术契约（详见 TDD §5）

| 项 | 规格 |
|---|---|
| 材质 | `MeshToonMaterial` + 4 阶 gradientMap（每相 1 张，canvas 程序化生成） |
| 轮廓 | 倒置壳（BackSide 放大 1.03，相位墨线色）；不叠加后处理描边（省一层 pass） |
| 光照 | 1 个主方向光（幕布灯，塔外 45°）+ 1 环境（相位色 tint）+ 0 点光（v0.1） |
| 硬投影 | 主光 castShadow，2048 PCF，投影不软（皮影 = 硬影） |
| 纸纹 | canvas 生成 128px 噪声贴图，`map` 叠加混合（subtle 4% 不透明度） |
| 幽灵层 | 15% alpha + 饱和度 −40% + 相对当前层 0.15m 视差偏移（纸叠的"厚度"） |
| 轮廓优先级 | 当前相墨线 > 幽灵相淡墨线（alpha 0.25）> 背景无轮廓 |
| 后处理 | 仅 vignette（0.3）；**不做 bloom**（皮影不发光，靠高光色） |

### 3.5 反模式（forbidden list）
- ❌ 实时反射/折射（非 PBR 路线；皮影纸不反光）
- ❌ 半透明渐变虚影（幽灵层 = 纸，不是鬼；无 blur）
- ❌ 屏幕空间描边（Sobel）作主轮廓（倒置壳即可，Sobel 只留作 debug 工具）
- ❌ 相位色交叉使用（每相只用自己的纸色家族——颜色混淆 = 机制死亡）

## 4. 风格验证门

- 截图测试：4 层同时渲染时，随机 10 名测试者 5 秒内指对"当前实心层"（≥9/10）
- 色弱模拟（灰度模式）下 4 相形状图标仍可区分
- F5 极致 case 截图中"4 张纸的叠放厚度"肉眼可辨
