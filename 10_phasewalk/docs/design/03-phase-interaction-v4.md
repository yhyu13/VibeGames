# 03-phase-interaction-v4 — 四相交互重做（v4）

> 动机（用户 2026-08-14）：除固相平台跳跃外，液/气/焰全是"自动寻路"（骑管/乘风/沿电线），零选择零手感。本轮推翻 v3 的管/线/风井，重做四相为**独立（垂直）又互补**的交互，并加入**子弹事件** + **Tab 圆圈 UI**。
>
> 从 v0.1 冻结的"无敌人"解冻：引入**相灵弹**（bullet）——世界观里四相灵（石翁/流姬/息童/焰司）本就有敌人定位（`02-story-world.md`），子弹是其投射物。这不再是纯平台解谜。

## 1. 四相 = 物质态：一个移动动词 + 一个物质动词

每相有**两套独立能力**，都是技能型（无自动寻路）：

| 相 | 移动动词（垂直） | 物质动词（非移动身份） | 子弹交互 |
|---|---|---|---|
| **固 solid** | 跳（精准平台跳跃，基线） | **固化造路**——把「相液池」（默认无形）冻结成可踩平台 | 被子弹硬打 → 死亡（被吃相） |
| **液 liquid** | 泳（自由浮力控制：按住=上浮，WASD=三维转向，松=缓沉） | **分离**——流体可挤过窄缝/栅栏（固相过不去） | 被子弹**打散** → 溅开重组（软惩罚：逼回固相 + 清动量，不死） |
| **气 gas** | 飘（极轻 + 强横向漂移 + 按住=悬浮，无跳） | **穿过**——无形，可过栅栏/铁栏 | 子弹**直接穿过**（免疫） |
| **焰 plasma** | 爆（无跳，按跳=向输入方向/上方的能量爆冲，重力 0.9 回落） | **吸收反弹**——吸收子弹并**反射回发射器** | 吸收子弹 → 反射（反击） |

**互补链**：液流进模具 → 固冻结成桥 → 气穿栅绕障碍 → 焰反射子弹拆发射器。四相各回答一个不同问题（造路 / 穿缝 / 绕行 / 战斗），不是"怎么往上走"的四次重复。

## 2. 子弹系统（相灵弹）

- **发射器 Emitter**：固定「相灵眼」，周期发射慢速子弹（可躲）。
- **交互按玩家当前相**（碰撞判定）：
  - 固 = 命中死亡（deaths++ 回出生点，与无相区同款被吃相）。
  - 液 = 命中**打散**：强制切回固相 + 速度清零（软惩罚，不死）。
  - 气 = 无碰撞（子弹穿过，气态无形）。
  - 焰 = **吸收 + 反射**：子弹掉头飞回发射器，命中即摧毁发射器。
- **用途**：气=安全穿行相、焰=进攻拆塔相、固/液=危险但能造路/游泳。摧毁全部发射器 = 打开某条路/金门额外条件。

## 3. 输入：Tab + 圆圈 UI

- **按住 Tab** → 圆形四象限菜单淡入；**WASD/方向键**指向某象限高亮；**松开 Tab** → 切到高亮相。
- **快切**：Tab+方向连击 = 近瞬切（不驻留菜单），保住**相弹**（空中切相动量守恒）的手速。
- 象限映射：↑=气（升）· ↓=固（沉）· ←=液（流）· →=焰（燃）。删除 1/2/3/4 数字键。

## 4. 移动常量（冻结表，替换原管/线/风井）

| 相 | 重力 | 移动速度 | 垂直机制 |
|---|---|---|---|
| 固 | 1.0 | 5.5 | 跳 11（无变化） |
| 液 | 0.6 | 6 | 泳：按住上浮（→5 m/s 封顶），无跳 |
| 气 | 0.18 | 6.5 | 飘：按住悬浮（→4 m/s），无跳 |
| 焰 | 0.9 | 8 | 爆冲：12 m/s，落地/冷却后可再爆 |

删除：`PIPE_*` / `VENT_*` / `WIRE_*`（自动寻路全部移除）。
