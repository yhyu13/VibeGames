# JOURNEY — 股神模拟器 · Intro Scene 是怎么做出来的

> 一句话: 这是一个"投胎 + 掷骰 + 模拟盘 + AI 教练复盘"的校园人生投资模拟器,intro scene(17 周开学日历)就是它的**全部 ship 范围**。当前 v2.8,所有验证门全绿。
>
> 本文档回答三个问题:**这游戏是什么 / 不是什么**(概念)、**内部怎么组织**(逻辑脉络:主干→分支→树叶)、**我们做了什么、没做什么、各自结出什么果**(行动项)。末尾附**核心功能清单**供 review,以及**已知 drift**供校对。

---

## 一、概念

### 是什么(What it IS)

- **一句话 pitch**(GDD §1 原文):"A Monopoly-style life-and-investing sim where **who you're born as** (origin × era) silently gates which board cells you can even see." —— 一个类大富翁的"人生 + 投资"模拟器,**你出生是谁,就悄悄决定了你在地图上能看到哪些格子**。
- **核心命题(thesis,原文)**:"投胎差距 (birth-lottery gap) isn't a bug, it's the feature —— the game wants you to *feel* it mechanically, not just be told it." 出身差距不是 bug,是卖点;游戏要你**用机制感受到**它,而不是被文字告知。
- **那个"哇"瞬间**: 三个金融格子(私董会 / PE 圈 / 投行内推)就贴在你身边,**永久灰着**,因为你的父母是谁。
- **玩家**: 默认出身**小镇做题家**(生活费 ¥1,000,"被本能使唤");通关后解锁可重开的**金融世家**(¥300,000)。
- **时间线**: 主角 1995 年生 → 2014 年(19 岁)进大学 → 2015 年新学期开学。Ship 范围 = **17 周开学日历**(v2.2):13 周校园学期 + 3 周寒假 + 新学期开学。
- **核心循环(每周 5 步)**: ① 看地图选目的地 → ② 掷骰子(`2d6 + 出身修正 + 时代修正 + 状态修正 + 事件修正` → 5 档) → ③ 抽事件(机会/中立/陷阱,2 选 1) → ④ 模拟盘买卖 7 种真实资产 → ⑤ AI 教练(班主任)复盘这一手是"出身/时代/认知/情绪"哪个维度在主导。

### 不是什么(What it is NOT)

**冻结的 ship 范围(GDD §2)**: intro scene **就是这个仓库的全部交付范围**。没有更大的实现可以"顺手扩展"。

**数据冻结(类型存在,本范围不可达)**:
- 另外 2 个出身(城市中产 / 海外精英)、另外 3 个时代(后移动 / AI 年 / 下一代)、城市 / 海外 / 特殊区域。
- 真实行情 API、实时 LLM 教练、微觉醒以外的觉醒层级、赛季 / 排行榜、DLC。

**M2+ 路线(完全不建模)**:
- Ch07 贵人系统、Ch09 投资策略库、真实券商接入(**源文档明确禁止 —— "绝对不接真实券商账户"**)、金融世家真盘模式、多人 / 排行榜。

**AGENTS.md 三条红线(原文)**:
1. "Do not wire a real market-data API —— investing is intentionally mocked(`assets.ts`,七条确定性 17-tick 学期曲线)。"
2. "Do not wire a real LLM call for the AI coach —— `coachLines.ts` 是脚本模板,只有班主任一个人设。"
3. "Do not add the other 2 unplayable origins / 3 eras / 3 zones without first writing a new plan doc."

**已知简化(AGENTS.md §5)**:
- `eraMod` 冻结为 0;AI 教练归因是确定性简化,不是推理;`awaken`(≥13)档只是事件结果,真正的觉醒/解锁必须靠 `mentor_hit`;1995→2015 时间线**只是展示语境**(从不影响 tick / 头条 / 时代修正 / 建议);v2.7 起**涨跌停是教学说明、不机械绑定**(周频 mock 无法自然绑定 A 股日频 ±10%)。

## 二、逻辑脉络

### 主干(Trunk)—— 状态机 + 单回合管道 + 分层架构

**七相状态机**(`TurnPhase`):
```
choose_destination → walking → dice → event → invest → results → summary
       ↑                                              │
       └──────────────────────────────────────────────┘
              (summary 当 turn+1 > 17)
```

**单回合管道**(`Simulation.ts`,每个动作对应一个纯函数):
1. `chooseDestination(state, cellId)` — 关卡校验(锁定/离校园格拒绝;贵人要认知解锁)。
2. `arrive(state, rand)` — 按优先级抽事件:季节事件 → 强制剧情 beat(开户/发现贵人/选方向/办健身卡,0 rand 消耗)→ 关系线 → 爱情线 → 投资引导(v2.8 导师/损友/骗子,0 rand 消耗)→ 普通加权地点抽卡;再掷特殊事件、注入 v2.7 换向。
3. `roll(state, rand)` → `advanceToEvent` — 掷骰(主 + 平行命运),定格 `pendingDice` + `pendingAltFate`。
4. `chooseEvent(state, choiceId, rand)` — 结算事件选择,`event → invest`(开户 beat 直跳 `results`)。
5. `makeInvestment(state, assetId, side, amount)` — `resolveOrder` 对主/平行两个模拟盘账户下单,`invest → results`。
6. `finishCoach(state, rand)` — 微觉醒、复盘、贵人认可、觉醒判定、写日志、结算,`results → choose_destination`(或 `summary`)。

**C.A.T 三层架构**:
- `core/`(**平台纯净**,零 React/DOM):`types.ts`(冻结契约)、`constants.ts`(冻结数值表)、`data/`(cells/coachLines/assets/specialEvents/seasonEvents/timeline/locationEvents/marketNews)、`simulation/`(dice/events/invest/attribution/Simulation reducer)。
- `engine/`(平台适配):**只有** `rng.ts` —— `mulberry32(seed)` 种子随机,**全项目唯一** `Math.random` 等价物;每个模拟函数都把 `rand: () => number` 当参数传入,保持纯净可替换。
- `store.ts`(zustand 包装)+ `components/`(React 视图)。

**种子确定性是硬契约**: 每一处随机抽取的顺序都写入文档(失真抽 → 新闻抽 → 建议抽;强制剧情 beat 消耗 0 rand),保证 `rand` 流可复现、可回放。

## 五、技术栈与架构(how it's made)

- **栈(锁定)**: Vite 6 + React 19 + TypeScript(strict)+ zustand 5。**无 Three.js / WebGL**(2D 卡片 UI,CSS grid + DOM 是正确选择)。无 Tailwind(纯 CSS)。无测试框架 —— 验证门 = `tsc -b --noEmit` + 浏览器回放。无资源文件(全 CSS/emoji/程序化);零网络调用(行情与教练均 mock)。
- **dev server**: 端口 **5185**(`npm run dev`,strictPort);`npm run build` = `tsc -b && vite build`。
- **C.A.T 分层**: `core/` 平台纯净 / `engine/rng.ts` 唯一随机源 / `store.ts` + `components/` 视图。
- **`altPlayer` 住在 `GameState` 里**(不是独立 store),所以平行命运在决策瞬间用同一套 reducer 读同一物理骰/事件/tick —— "same luck, different origin"。
- **数据契约**: `GameState` 有 **37 个字段,全部非可选**(新增字段必须进 `createInitialState`)。事件是模块级常量 → 换向必须浅拷贝 `{...event, choices:[...]}` 而非原地 `push`。

## 七、如何继续 polish(无尽循环)

观察 → 找问题(视觉/手感/性能)→ 改 → 验证(§三的 6 道门)→ 再观察。**停止条件 = 用户说停**,无内置自动停止。3 件套 doc(设计 GDD + `docs/design/`、美术 `01-art-direction.md` + `styles.css`、代码 TDD.md + `intro_scene.md`)与代码**同 commit**,无 drift 窗口。
