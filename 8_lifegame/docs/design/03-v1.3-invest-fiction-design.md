## 2. Decisions (user-approved)

| # | Critique | Decision |
|---|---|---|
| 1 | 投资第一天就开着，没有叙事原因 | **第1回合固定剧情**: turn 1 无论去哪栋楼,都强制抽到开户事件(每栋楼有自己的见证文案);两个选项都解锁模拟盘(无软锁);第 1 回合跳过投资阶段,事件→结算直通 |
| 2 | 数字走势看不懂,要 K 线 | **K 线蜡烛图**(SVG, 红涨绿跌 A股惯例),由确定性 tick 曲线合成(基准 ¥100),**只画历史** —— 修掉了 v1.2 把全部 8 个 tick(含未来)都亮出来的剧透;情绪失真只弯最近 3 根(认知 ≥60 → 1 根),深度历史永远诚实 |
| 3 | 模拟盘要有热点新闻 | **每资产每回合一条头条**,80% 忠实于它*先于*发生的那个 tick 的方向(新闻早于走势 = 有噪声的信号,不是作弊码;"消息≠信号"本身就是课程);情绪不改标题,改解读 —— 以 spin 副线呈现(悲观读利空/亢奋读利好/理性无) |
| 4 | 金融世家应直接操盘真盘 | **留给 M2+ 可玩出身**(用户拍板): 只进 GDD §2 M2+ 路线,不动平行命运孪生机制 |

## 3. Contract changes (mirrored in TDD.md §3)

- `Candle { open, close, high, low }` — synthesized from tick history, base ¥100, past turns only
- `MarketNews { headline, spin: 'bearish'|'neutral'|'bullish' }`
- `GameState.investUnlocked: boolean`(初始 false,开户事件结算后 true)
- `GameState.pendingMarketNews: Record<string, MarketNews> | null`(与蜡烛同生命周期)
- `pendingAssetPreviews: Record<string, number[]>` → `Record<string, Candle[]>`
- `TurnResult.investment: InvestmentResult` → `InvestmentResult | null`(开户回合无交易)
- 新文件 `core/data/marketNews.ts`(3 资产 × 8 回合 × 涨跌双版本 = 48 条头条)
- `invest.ts`: `buildAssetPreviews`/`distortTicks` 退役 → `buildCandles`/`distortCandles`/`pickNews`/`buildMarketView`
- `locationEvents.ts`: `ACCOUNT_OPENING_EVENT`(weight 0, 不进任何表)+ `ACCOUNT_OPENING_FLAVOR`(按楼换文案)

## 4. Draw-order contract (seeded determinism)

- turn 1 强制开户**不消耗** rand —— 特殊事件 shock roll 保持在原来的位置
- `buildMarketView` 每资产(ASSETS 顺序): 先失真 draw(仅非理性档),后新闻忠实度 draw(1 次)
- 理性档失真不消耗 rand(v1.2 契约延续)
