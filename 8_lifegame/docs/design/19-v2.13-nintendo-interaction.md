# 19 — v2.13 任天堂式交互手感 (Nintendo-style interaction polish)

## 1. 一句话 + Why

把任天堂"按钮要有反馈、要活"的交互语言,套到整个 intro scene 的每一个可点元素上:按下瞬间回弹、
悬停浮起、实体按键"沉下去"、描边按钮"填满"。目标不是加动画,而是让每次点击都有一记清晰的
**物理反馈** —— 玩家每按一下都知道"我按到了",这是任天堂 UI 的"vivid"感。

## 2. 现状问题

v2.12 前,按钮只有最基础的状态:`.btn:hover` 仅 `filter: brightness(1.05)`(无位移、无缩放)、
无 `:active` 按压态、无弹簧回弹;`.building` 是静态卡片,点击前后零形变;`.btn-choice` /
`.invest-row` / 分段控件(日K/周K 周期、买卖方向、快捷百分比)全部无按压反馈。整体手感"软"——
点击没有确认感,悬停没有层级感。

## 3. 设计决策

| 决策 | 取舍 |
|---|---|
| **统一弹簧缓动 token** | `:root` 新增 `--spring: cubic-bezier(0.34, 1.56, 0.64, 1)`(back-out 回弹过冲)——"按下去、弹回来"的任天堂手感 |
| **瞬间按压 + 弹簧释放** | 按压态 `transition-duration: 60ms`(秒按),释放回弹走基态 160/200ms 的 `--spring`(弹回) |
| **`.btn` 三态** | hover 浮起 `translateY(-2px) scale(1.02)` + `brightness(1.05)`;active 下沉 `translateY(1px) scale(0.94)` + `brightness(0.96)` |
| **`.building` 实体按键** | 基态底座阴影 `0 7px 0` 按压时压成 `0 2px 0`(像键帽下沉),`translateY` 从 hover `-4px` 到 active `+3px` + `scale(0.96)` |
| **`.btn-choice` 浮起/按压** | hover 浮起 `translateY(-2px)` + 填白 + 阴影;active 下沉 `translateY(1px) scale(0.97)` |
| **描边按钮 hover 填满** | `.add-draft-button` hover 由描边变实心 accent(白底 → accent 底白字) |
| **`.invest-row` + 分段控件** | 轻微浮起 `translateY(-1px)` + 按压 `scale(0.92~0.985)` |
| **`:focus-visible` 统一轮廓** | 所有可点元素 `outline: 2px accent`(键盘可达性不因手感改造而回退) |
| **`prefers-reduced-motion`** | 减少动态偏好下,把上述所有弹簧 transition 置 `none`(只保留颜色/描边瞬时切换) |
| **不新增随机源** | 纯 CSS,零 JS 逻辑改动,`rand` 流顺序、种子确定性完全不变 |

## 4. 关键实现

- `styles.css`(唯一改动源文件):
  - `:root` 新增 `--spring` token;
  - `.btn` / `.btn:hover` / `.btn:active` / `.building:not(:disabled):hover` /
    `.building:not(:disabled):active` / `.btn-choice:hover` / `.btn-choice:active` /
    `.invest-row:hover` / `.invest-row:active` / `.chart-frame-button, .trade-mode-button,
    .quick-pct-button` / `.add-draft-button` 三态;
  - `@media (prefers-reduced-motion: reduce)` 扩展为 null 掉所有弹簧 transition。
- `scripts/interaction-probe.mjs`(新):用 computed style 断言手感真的上了线,不看像素 ——
  `--spring` token 存在;`.btn` / `.building` / `.btn-choice` 的 hover 与 active transform
  各自不同(按压是一个区别于悬停的独立状态,`:active` 会把 `transition-duration` 翻到 `60ms`);
  全程 0 console errors。按压用 `mouse.down` 按住后移到 (0,0) 再 `mouse.up` 释放,永不触发点击。

## 5. 交互语言一览

| 元素 | hover | active(按压) | 释放回弹 |
|---|---|---|---|
| `.btn`(主按钮/继续/确认) | 浮起 2px + 放大 + 提亮 | 下沉 1px + 缩小 0.94 + 变暗 | 160ms 弹簧 |
| `.building`(校园建筑) | 浮起 4px + 底座阴影变深 | 下沉 3px + 底座阴影压成 2px + 缩小 0.96 | 200ms 弹簧 |
| `.btn-choice`(事件抉择) | 浮起 2px + 填白 + 阴影 | 下沉 1px + 缩小 0.97 | 160ms 弹簧 |
| `.add-draft-button`(加入委托) | 描边 → 实心 accent | (继承按压) | — |
| `.invest-row` / 分段控件 | 浮起 1px / 边框高亮 | 缩小 0.92~0.985 | 120~150ms 弹簧 |
