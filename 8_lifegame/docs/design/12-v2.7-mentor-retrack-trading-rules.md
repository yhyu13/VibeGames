# 12 · v2.7 — 贵人换向 + 真实交易规则 + 新手教学

> 一句话: 选错方向不必死心 —— 贵人指点后给你一次"改押 AI"的翻盘机会;模拟盘从"能买卖"升级为"懂规则" —— 每类资产有真实的 T+1/涨跌停/最小单位/佣金,面板上的「?」手册、属性卡与市场温度一步步把金融新手领进门。

---

## 1. Why

上一版(v2.6)已经把"贫困逻辑 + 认知引擎 + 贵人女儿"落地,但三处粗糙:

1. **方向锁死**: `track` 只设一次、永不再变。选非 AI 方向就永久拿不到"对口信任"(`mentorTrustedFor = track==='ai' && cognition>=60` → 90% 命中)。玩家没有"后悔药",一次选错等于放弃贵人线。
2. **交易像玩具**: 模拟盘能买卖 7 种资产、也收万三佣金,但没有把**真实市场的规则与限制**讲给玩家 —— 没有 T+1、没有涨跌停概念、没有最小交易单位,更没有"这个品种跟那个品种有什么区别"的教学。
3. **新手没人带**: 没有「?」帮助、没有产品属性、没有市场温度。金融新手面对 7 个品种一脸懵,只能靠 AI 教练的结算复盘被动学习。

本轮把这三处补成"真实 + 教学",同时落地一批上轮审计已确认的 polish 项(见 §5 Step 0)。

---

## 2. 用户指令(逐条)

1. **贵人换向** — "if choosing not AI, then there is a chance to change major after 贵人guidance"。
2. **真实交易规则** — "模拟盘需要能够交易所有种类,必须要付出佣金,并且我们要给出真实的交易规则和限制,在问号内金融新手玩家解读"。
3. **新手教学** — "一步一步,随着事件和盘面的变化吸引玩家进一步了解金融产品的属性、区别和市场的温度"。

拍板方案(AskUserQuestion):
- **Q1 换向** = "贵人指点后解锁一次换向"(非 AI 方向在第一次得到贵人指点后,解锁一次改押 AI)。
- **Q2 规则** = "分资产类别完整规则"(T+1 / 涨跌停 / 万三佣金 / 最小交易单位)。
- **Q3 帮助** = "?手册 + 属性卡 + 渐进提示 + 市场温度"。

## 3. 已核实代码事实(Explore 结论)

- **track 变更单点**: `Simulation.ts` `chooseEvent` 里 `choiceId.slice('track_'.length) as TrackId` → 写回;初始 `null`;唯一强制触发 `TRACK_CHOICE_EVENT` 于 `arrive()`(`cellId==='lecture' && state.track===null`)。
- **贵人 hit 判定**: `drawLocationEvent` 返回 `{ event, mentorRoll, mentorTrusted }`,hit/miss 编码在 choice id `'mentor_hit'`/`'mentor_miss'`;`mentorHitFromChoiceId(choiceId)` 已存在(`events.ts`)。
- **⚠ 事件是模块级常量**(`locationEvents.ts` 的 `MENTOR_EVENTS`/`MENTOR_EVENTS_BY_TRACK`/`TRACK_CHOICE_EVENT`)—— 换向绝不能原地 `choices.push`,必须 `{...event, choices:[...event.choices, retrackChoice]}` 浅拷贝。
- **`GameState` 无任何可选字段** —— 新增字段必须在 `createInitialState` 初始化。
- **交易**: `PaperAccount = { cash, positions, realizedPnl, initialCapital }`;`resolveOrder` 有 `turn1Based`, `executeOrder` 无;佣金 `TRADE_FEE_RATE=0.0003` 双向已在 `executeOrder`;`Asset` 无规则字段;无 T+1/涨跌停/最小单位。
- **帮助/温度现状**: 无「?」按钮、无帮助面板、无温度/regime 概念;`BeatOverlay` 是唯一居中 overlay 壳。

---

## 4. 设计决策(关键取舍)

- **涨跌停是"说明性规则"而非机械绑定**: 市场是周频确定性 mock(每周 tick 已冻结),A股单日 ±10% 在周频无法自然绑定。故 `T+1`、`最小单位`、`佣金` **机械执行**,`涨跌停` 进「?」手册 + 属性卡做**教学说明**。
- **市场温度从确定性数据派生**(不引入新随机源,保种子确定): `marketTemperatureFor(assets, turn1Based)` = 当前周全资产平均 tick → 低迷(<−1%) / 震荡(±1%) / 亢奋(>+1%),纯函数,在 InvestPanel 直接算,不加 `GameState` 字段。
- **换向用 mentor hit 卡上的第二个 choice**(复用 `.btn-choice` 渲染),不新增独立 beat —— 叙事"贵人点破 AI 是下一波"。
- **换向一次机会的消费语义**: `retrackDone` 在「选了 `retrack_ai`」或「仍处 eligible(track≠null、≠ai、!retrackDone)却选了普通 `mentor_hit`」时置 true —— 机会无论接受还是放弃都用掉;track 仍为 null 时(从未 offer 过)不消费。
- **`mentorHitFromChoiceId` 必须认 `retrack_ai` 为 hit**: 否则选"改押人工智能"会静默丢掉本应随贵人指点一起给的觉醒/教练/金融世家解锁。

## 8. 风险 / 边界

- **周频 mock**: 涨跌停只说明不绑定(已记录为设计决策)。
- **`boughtTurn` 旧存档兼容**: 默认 `undefined` = 可卖(向后兼容)。
- **换向/温度/提示不引入新随机源**,保 `rand` 流顺序(种子确定性契约)。
- **事件常量不可原地改**: 换向必须浅拷贝 choices(见 §3)。
