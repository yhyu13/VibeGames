## 4. 设计（intro scene 范围）

### A. 真实度自选（新手 / 真实 2 档）

- `GameState.tradingRealism: 'novice' | 'real'`，默认 `'real'`（现状）。InvestPanel 顶部加一个「真实度：新手 / 真实」分段开关，可随时切（纸盘练习，低风险）。
- 接缝：`GameState.tradingRealism` 是玩家设置的唯一来源；store 的 `makeInvestment` 把它作为**可选参数（默认 `'real'`）** 传给 `resolveOrders`/`executeOrder` —— 纯函数按它门控费率/T+1/策略。**`PaperAccount` 不背 realism，`createPaperAccount` 保持单参数**（不破 `Simulation.ts` init 与现有探针的单参调用）。
- **新手档（novice）**：免佣金（fee = 0）、免 T+1（当日买当日可卖）、不出策略选择（只有买入持有）。属性卡/「?」手册简化（标注「新手模式：无摩擦」）。纯在 7 条确定性曲线上低买高卖 —— 最简单最好玩。
- **真实档（real）**：现状 + 本 Ch09 的策略层（B）+ 分品种费率（C）。
- 平衡注记：新手档免摩擦会让翻盘目标略易，但目标是同一个 ¥100k→¥200k；纸盘无真实输赢，自选真实度是练习自由度，不影响觉醒/解锁主线。实现上是「真实档为超集，新手档关闭若干规则」，不是两套并行逻辑。

### B. 策略层（买入持有 vs 均线择时，真实档开放）

每笔委托单加 `strategy: 'buy_hold' | 'ma_timing'`（默认 `buy_hold`），InvestPanel 每行一个「持有 / 择时」分段选择：

- **买入持有（默认）**：现状不变 —— 买入后持仓跨周，跟随该品种当周 tick。
- **均线择时（均线/MACD）**：当周内「开盘价买 + 收盘价卖」的择时波段，在 `resolveOrders` 内**当场闭合**（买入 → 按择时收盘价卖出 → 收益直接实现到现金；从不持仓跨周、不碰 `PaperPosition`，避免与同资产的买入持有持仓混淆 —— 持仓是按 assetId 键控的）。
  - **趋势信号**（确定性，0 新随机源）：当周开盘价 vs 该品种近 4 周收盘均线（MA4 of the `priceAt` 收盘序列；turn<4 时并入 `preHistory` 凑足）。开盘价 > MA4 = 上行，否则下行。
  - **择时规则**：信号**下行** → 该买单被拦（「均线之下不接刀 · 等趋势转上」，择时空仓）；信号**上行** → 买入，当周实现收益 = `amount × tick × MA_TIMING_FACTOR`（**统一放大器 1.3**）。
  - **假信号损失**：上行信号但当周 tick 为负（趋势破了）→ 同一个 1.3 放大器把亏损也放大（比买入持有亏得更多）。这就是「中风险」：择对多赚、择错多亏。择时成功 = 上行 + tick 正 → 放大收益（对齐 PDF「+5~+30%」）。
  - 解锁：PDF 说均线/MACD 基础课解锁 —— 复用认知门槛 `COGNITION_INFO_THRESHOLD=60`（认知 < 60 择时禁用 + 提示）。
  - 接缝：`DraftOrder.strategy`；`resolveOrders` 内对 `ma_timing` 买单当场结算（含双边费），不落持仓。

### C. 分品种费率（真实档）

- `TRADING_RULES` 加 `feeRate` 字段；invest.ts 买卖改读 `rules.feeRate`（替换全局 `TRADE_FEE_RATE` 一刀切）。初值（可调，原则「不同品种不一样」）：money_fund/bond 0.01%（货币/债券基金低费率）/ index_fund 0.05%（指数申购）/ gold 0.02% / a_index 0.03%（股票佣金万三）/ hk_index 0.05%（港股含杂费）/ btc 0.1%（crypto 交易所费）。
- 结算窗口：保留现有 T+0(BTC)/T+1(其他) 差异，属性卡 + 手册把「到手时间」讲清楚（T+1 = 今天买明天才能卖；BTC 随时）。不新增 T+2（加复杂）。
- 手册 + 属性卡：佣金改读每品种费率。

## 6. 成功标准

1. 真实度自选：新手档免佣金 + 免 T+1 + 无策略选择；真实档 = 现状 + 策略 + 分品种费率。两档 sim 可测、UI 可切。
2. 策略层：真实档每笔委托可选 持有/择时；择时单在 `resolveOrders` 内当场闭合（不持仓跨周），上行信号 × 统一放大器 1.3（择对多赚、假信号多亏），下行信号拦单空仓；认知 < 60 择时禁用。
3. 分品种费率：真实档每品种费率不同（买卖按 `rules.feeRate`）；属性卡/手册显示每品种费率 + 到手时间。
4. 不新增随机源（趋势信号由 ticks 历史确定性算 MA4）。
5. 全门绿：tsc 0 + build + 现有探针不回归 + 浏览器 0 console error。
6. 每条机制锚定 PDF 行（§1）。
7. **文档同步（改代码必带 doc 同 commit）**：分品种费率落地后，以下「佣金万三」表述要同步为分品种 —— `TradingHelpPanel.tsx:19-20`、`InvestPanel.tsx:378`、`GDD.md`、`playability.md`、`playthrough/README.md`。
8. **PDF 锚点澄清**：ch04-ch05:397「开盘价买入+收盘价卖出」在 PDF 里是所有策略的结算方式；本仓只把它实现为均线择时（买入持有仍持仓跨周）。
