# 18 — v2.12 两步走强制 (two-step trade confirmation)

## 1. 一句话 + Why

模拟盘交易从"单笔快速路径 + 委托篮并存"收敛为"所有交易都走两步:加入委托(提交)→ 确认下单(生效)"。
v2.11 委托篮已支持多笔下单,但主按钮仍保留"篮空时直接成交单笔"的快速路径 —— 玩家看不到「加入委托」,
点主按钮只成交一笔,于是误以为"模拟盘还是只能买卖一次"。v2.12 移除该快速路径,把两步走变成唯一通道。

## 2. 现状问题

v2.11 的 `.invest-actions` 主按钮有一个 fallback:`basketEntries.length === 0` 时,点击 = 直接
`invest([{assetId, side, amount}])` 成交一笔(标签 `确认买入/卖出 品种 ¥金额`),绕过了委托篮。
后果:① 单笔交易一步到位、零确认;② 玩家永远发现不了"可多笔"的委托篮;③ 与"提交 → 中间可改 → 确认后生效"
的两步走诉求相悖。

## 3. 设计决策

| 决策 | 取舍 |
|---|---|
| **移除单笔快速路径** | 主按钮不再 `invest([单笔])`;它永远是"确认 N 笔下单"这一步骤 2 |
| **篮空 = 主按钮禁用** | `disabled={basketEntries.length === 0}`,label「先加入委托,再确认」,把玩家导向步骤 1 |
| **两步走提示** | 篮空时渲染「①② 两步走:先加入委托 → 确认下单」`role="note"` 提示,直到第一笔入篮 |
| **加入委托升级为步骤 1 视觉** | `.add-draft-button` 描边 accent(白底 + accent 边框/文字),与实心主按钮形成"提交(描边)→ 确认(实心)"的层级 |
| **委托篮不变** | add/update/✕/清空 逻辑零改动;只是不再可被绕过 |
| **不新增随机源** | 纯 UI 交互,不碰 resolveOrders/executeOrder,种子确定性不变 |

## 4. 关键实现

- `InvestPanel.tsx`:主按钮 `onClick={confirmOrders}`、`disabled={basketEntries.length === 0}`;篮空时在
  `.invest-actions` 上方渲染 `.two-step-hint`。
- `styles.css`:`.add-draft-button` 改描边 accent;新增 `.two-step-hint`。
- 探针:showcase.mjs / showcase-dynasty.mjs / marathon-probe.mjs 的每周买入,从
  `点 50% → 点主按钮` 改为 `点 50% → 点 .add-draft-button → 点主按钮`。

## 5. 委托篮 UI(现状)

- 步骤 1「加入委托」:选中品种 + 方向 + 金额 → 点描边 accent 按钮,订单入篮(同品种再点 = 更新)。
- 步骤 2「确认 N 笔下单」:篮非空时主按钮可用;篮空时禁用 + 提示。`.no-invest-button` 一键不操作。
