# v1.9 — D13 金融世家：关系不是资产

Date: 2026-08-10. Status: implementation contract.
Changelog row: TDD.md v1.9. Decision trace: D13.

## 1. Product contract

- 小镇做题家的贵人命中是 intro scene 的胜利条件。选择 `mentor_hit` 后，当前人物觉醒，并永久解锁本次会话中的「金融世家」开局。
- 骰子的 `awaken` 档仍表示一次极佳的事件结果，但不再直接改变 `PlayerState.awakened`；觉醒只来自贵人认可。
- 总结页在解锁后提供「以金融世家重开」；普通重开仍回到小镇做题家。金融世家开局拥有更高财富与身心资源，但较低的自主认知起点。
- 金融世家专属隐藏线「关系不是资产」按阶段出现。它不得覆盖开户、发现贵人、方向选择、健身房发现等强制教学节拍。
- 专属关系节拍自第 3/7/11 周起等待注入；若同周触发教学节拍，则教学优先，关系节拍顺延到下一次普通到达；但第 13 周若第三阶段仍未发生，最终关系节拍优先于尚未触发的可选教学节拍，确保故事在学期总结前闭合。完成第三阶段后停止。最终选择坦白则 `relationshipResolved=true`，离开则关闭但不修复。

## 2. Typed relationship effects

关系效果和事件选项共同定义在 `relationshipEvents.ts`，以 choice id 索引：

```ts
interface RelationshipEffect {
  trustDelta: number
  resolves?: boolean
}
```

Simulation 不解析 `rel_*` 魔法字符串，也不维护 choice-id 三元表达式。`applyRelationshipChoice()` 是唯一的关系推进入口，并将信任夹在 `[0,100]`。

## 3. Origin-aware run contract

`createInitialState(origin, financeDynastyUnlocked)` 建立指定出身的运行：

- 小镇做题家：沿用冻结的基础数值。
- 金融世家：财富 ¥300,000、认知 45、体力 75、心态 75；关系信任 50。
- 平行命运始终选择玩家的相反出身，因此金融世家运行会对照小镇做题家。

Zustand 的 `restart(origin?)` 只允许已解锁的金融世家；否则安全回退到小镇做题家。

## 4. Deterministic verification

DEV verification must pin:
