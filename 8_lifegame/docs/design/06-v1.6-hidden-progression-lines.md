## 2. Decisions

| # | Directive | Decision |
|---|---|---|
| 1 | 不可能一开始就拥有预判能力 | 建议 fidelity 从"认知直接分档"改为**已复盘交易数**驱动: 0 笔 = 全员「看不懂」(0 rand 抽),第 2 回合首笔交易必然盲选 = 试错。v1.5 的 `COGNITION_ADVICE_BLIND/SHARP` 当日退役 |
| 2 | 提高认知 → 获得复盘能力 | **复盘能力 = 认知 ≥ 60**(复用冻结阈值,不造新数字)。认知不够的交易在教练卡明说「认知不足,这笔交易没有复盘 —— 建议不会变准」 |
| 3 | 模拟盘试错 → 复盘得到建议 | 每笔**真实交易**(仓位 > 0)在回合结束复盘 +1 `reviewCredits`;档位 1/2/3+ → 模糊 70% / 较准 85% / 精准 95%(`REVIEW_BAND_CREDITS`)。0% 仓位不算交易,无可复盘 |
| 4 | 贵人信任: 有能力 + 对口,对口 = 基于预判的选择 | 开户后首次进**教学楼**触发「职业规划课」4 选 1(金融/传统行业/人工智能/读研,0 抽签无数值)。**对口 = 人工智能** —— 2013 年金融是显学不需要预判,AI 才是预判;贵人(骑过上一波的投资前辈)只信任看见下一波的人。trusted = track=ai × 认知≥60 → 命中率 10%→90%(`MENTOR_TRUST_HIT_PROB`),事件卡浮现金色「同道中人」行。孪生按自己的认知判定 —— 信任是挣来的,不随出身继承 |
| 5 | 隐藏线的"隐藏" | 从不进教学楼 = 选方向/信任整局隐形(同图书馆发现贵人的逻辑);盲 tag 区分「不会复盘 · 看不懂」(认知<60)与「未复盘 · 看不懂」(0 心得),tooltip 指路 —— 门禁即教学 |
