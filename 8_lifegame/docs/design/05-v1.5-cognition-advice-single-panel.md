# v1.5 — Cognition-Gated Advice + Single-Panel Invest UI

Date: 2026-08-10. Status: implemented + verified (tsc/build green, showcase playthrough green).
Changelog row: TDD.md v1.5. Decision trace: docs/levels/intro_scene.md §8 D10.

## 1. User critique (verbatim)

> 虚拟盘投资建议需要根据认知来走,事宜投资 不适投资等。虚拟盘需要更加简洁面板 所有投资类型在一个面板里,减少按钮和切换

(事宜 = 适宜 typo. Two asks: (a) advice must scale with cognition — 适宜投资/不适宜投资 etc.;
(b) ONE simpler panel — all asset types visible at once, fewer buttons, no switching.)

## 2. Decisions

| # | Critique | Decision |
|---|---|---|
| 1 | 建议根据认知来走 | **认知 → 建议可信度分档**: `<40` blind(「认知不足 · 看不懂」, 0 rand draws) / `40–59` noisy(70% faithful) / `60–79` clear(85%) / `≥80` sharp(95%)。清晰档边界**复用冻结的 `COGNITION_INFO_THRESHOLD=60`**,只新增 `COGNITION_ADVICE_BLIND=40` / `COGNITION_ADVICE_SHARP=80`。忠实标签锚定即将到来的 tick 桶: ≥+2 → 适宜投资, ≤−2 → 不适宜投资, 其余 → 谨慎参与; 不忠实则反转。分工: **心态扭曲你看到的盘面(K线), 认知决定你得到的判断(建议)** —— 低认知档直接显示「看不懂」,门禁本身就是教学(去图书馆涨认知 → 建议变准) |
| 2 | 一个面板,减少按钮和切换 | **三资产同屏行式布局**: 每行 = 名称+建议标签 / 迷你K线(44px) / 新闻条,点行即选中(radio 语义,高亮边框),底部一个仓位滑杆 + 一个「确认交易」。旧的 3 按钮 `.btn-asset` 切换条退役 —— 按钮数 3→0(行本身是可点卡片),切换动作消失,三条行情+三条新闻+三条建议同屏可比 |

## 3. Contract changes

- `types.ts`: `AdviceLabel` + `InvestAdvice { band, label, faithful }`;`GameState.pendingMarketAdvices: Record<string, InvestAdvice> | null`(与 candles/news 同生命周期 —— 进 invest 阶段构建,交易/回合结束清空)
- `constants.ts`: `COGNITION_ADVICE_BLIND=40`, `COGNITION_ADVICE_SHARP=80`
- `invest.ts`: `investAdvice(asset, turn1Based, cognition, rand)`;`buildMarketView` 返回值 +`advices`。**抽签顺序(每资产, ASSETS 序)**: 扭曲抽(非理性才抽) → 新闻忠实度 1 抽 → 建议 1 抽(blind 档 0 抽)—— 追加在末尾,不回溯改变既有抽签位置
- `InvestPanel.tsx` 重写;`CandleChart` 增加 `mini` 变体(44px);`.invest-assets`/`.btn-asset*` 样式删除,新增 `.invest-row*`/`.advice-*`/`.candle-chart-mini`
- `__sim.checks` += `investAdvice`, `ASSETS`;showcase §9 +9 条断言(四档边界、忠实/反转标签、blind 0 抽)

## 4. Color-language note (art doc §1)

建议标签用 P&L 语义(绿=适宜/红=不适宜),K线保持红涨绿跌 —— 同一面板两套颜色语言是有意的: 一个说价格方向,一个说值不值得买。
