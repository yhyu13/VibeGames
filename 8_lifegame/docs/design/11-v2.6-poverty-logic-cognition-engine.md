# v2.6 — 贫困逻辑 + 认知引擎 + 贵人女儿

Date: 2026-08-14. Status: implementation contract.
Changelog row: TDD.md v2.6. Decision trace: D22.

## 1. Product intent (user critique)

玩家一句"怎么可能有 10w 起始?"打穿了 v2.5 的账本混乱:小镇做题家的生活财富被
写成了 ¥100,000 —— 一个县城穷学生根本不该有这么多钱。玩家的 canonical 弧线:

> 起始 1k 块最多了,模拟盘 10w,从来没见过大钱,被本能使唤,一开始各种投资常见
> 初级错误和认知偏差,但是遇到了投资宝典,心理学书籍和爱人(还不是当时)的接住
> 感情,所以认知提升很快。模拟盘亏到 5w,再翻盘到 20w,遇到贵人,发现爱人是
> 贵人女儿。

v2.6 把这条弧线变成机制:

1. **双账本分离**: 生活费 ¥1,000(小镇)与模拟盘 ¥100,000 是两个 ledger,
   `PAPER_INITIAL_CAPITAL` 显式独立(顺带修掉了一个潜伏 bug:模拟盘初始资金
   之前派生自生活财富)。
2. **第一桶金 = 模拟盘翻盘**: `paperGoal` 小镇 ¥200,000(亏到 5 万再翻盘的 20 万)/
   世家 ¥500,000(证明你自己)。
3. **认知引擎**: 投资宝典(图书馆发现拍)、心理学书(期中爱情拍)、爱人接住情绪
   (爱情三拍)→ 认知涨得快的"逻辑"被叙事化、被保证化。
4. **贵人女儿 twist**: 爱情线走到 `close`,第 17 周贵人办公室揭晓 —— "我女儿说,
   迎新晚会上认识了个挺有意思的人"。纯叙事回报,认可概率(信任 90%)不动。

## 2. 双账本契约 (v2.6a)

- `START_WEALTH = 1_000`(小镇生活财富,注释:生活费;世家保持 ¥300,000)。
- `PAPER_INITIAL_CAPITAL = { town: 100_000, dynasty: 300_000 }`(模拟盘试炼场初始
  资金,与生活费无关;alt 平行命运 twin 用自己出身的模拟盘初始资金)。
- 修复的潜伏 bug: v2.4 的 `paper: createPaperAccount(start.wealth)` 让模拟盘初始
  资金跟随生活财富 —— v2.6 之前若改 START_WEALTH 会连带把模拟盘缩成 ¥1,000。
- 生活财富的展示: HUD 💰 chip 标题改为"生活费 —— 你从家里带来的全部家当"。

## 3. 财富目标 = 模拟盘翻盘 (v2.6b)

- `GameState.paperGoal` 取代 `lifeGoalWealth`: 小镇 ¥200,000 / 世家 ¥500,000。
- HUD 🎯 chip 与总结 verdict 读 `accountValue(paper)`: 达成 = `paperValue ≥ paperGoal`;
  进度 = `paperGoalProgressFor(origin, paperValue)`(净模拟盘初始资金,clamp 0..100;
  深坑 5 万 clamp 到 0% —— 回撤在进度条上读作地板)。
- 总结复制: "已翻盘 ¥X / ¥100,000 (Y%)。大多数人先亏到 5 万再学乖——翻盘,还差一点。"
  达成: "模拟盘翻到了 ¥200,000 —— 你从 ¥1,000 的生活费开始,在模拟盘上挣出了人生第一桶金。"
- 生活费仍是独立 stat(总结页 🏠 行: 起点 ¥1,000 / ¥300,000)。

## 4. 小镇小钱 = flat 金额 (v2.6c)

- `SpecialEvent.wealthFlat?: number` + `SpecialEventChoice.wealthFlat?: number`;
  `wealthAbs = round(wealth × pct/100) + (flat ?? 0)`(arrive 与 chooseSpecialChoice 同式)。
- 一等奖学金 ¥2,000 / 彩票 ¥50(存 50/请客 30)/ 装修款 −¥500/−¥250。
- 拆迁(family money)改为纯心态+认知: 爸妈的钱不是你的钱 —— 出身 gating 主题。

## 5. 认知引擎 (v2.6d)

- 投资宝典: 图书馆发现拍正文+"你花三块钱淘到 1996 年的《投资学入门》",两选项认知
  +8/+6(原 +6/+4)。
- 心理学书: 期中爱情拍文本换《心理学与生活》,`love_second_share` 认知 +3→+4。
- 本能警告: 复盘未解锁时交易面板提示 "你的手比你的脑快——追涨、杀跌、满仓,
  初学者的钱都是这么亏的"。
- 开场故事第三拍: "一笔 ¥100,000 的模拟资金。你从来没见过这么大的数字——
  本能告诉你:all in。"

## 6. 贵人女儿 (v2.6e)

- 第 17 周贵人遭遇(mentorUnlocked)且 `loveStage === 'close'` 时,事件正文追加:
  "散场时,他忽然叫住你:'对了——我女儿说,迎新晚会上认识了个挺有意思的人。'
  你愣在原地。原来这一路接住你情绪的人,是贵人的女儿。"
- 纯叙事: 命中概率(信任 90% / 好感加成)不动;爱情仍不进觉醒计算。
