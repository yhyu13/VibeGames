# 02 · v1.2 Campus World — Design Spec (2026-08-10, review rev. 4)

Status: **user-approved** in brainstorm session 2026-08-10. Extends v1.1; does not touch the 1×1×1 scope (1 origin × 1 era × 1 zone), no market API, no LLM. Rev. 2/3/4 address review rounds 1–3 (10 → 9 → 5 findings, converged).

## 0. Scope decision (explicit)

v1.2 is a **documented expansion** beyond the intro-scene-only discipline (AGENTS.md §2): movement becomes player-chosen, location event tables and mood→info distortion are new mechanics. GDD.md §2, TDD.md (v1.2 + changelog), AGENTS.md §1–2, `docs/design/01-art-direction.md` §3–4, and `docs/levels/intro_scene.md` §8 (new decisions D4/D5/D6) are updated in the same milestone — the expansion is recorded, not smuggled.

## 1. A — World + Beat Overlay layout

Two layers, always:

- **World layer**: top HUD → full-bleed campus map → conditional ⚡ shock banner. Always visible; shows cause→effect (token walks, HUD ticks).
- **Beat overlay layer**: exactly one center card at a time; world dims to ~45% behind it. The v1.1 bottom swap-band is **deleted**.

Beat sequence per turn (enter motion: scale 0.96→1 + fade, 300ms): **dice → event → invest → results (wide card: coach left, 平行命运 right)** → dismiss → world shows consequences → next turn. SummaryScreen stays a full-screen takeover (finale, not a beat). Pure presentation change: `src/core/` untouched by this section.

## 2. B — Real campus map

- Top-down stylized campus, **pure CSS/SVG** (repo zero-asset convention), warm-paper palette from 01-art-direction §1.
- The 6 locations become **geographically sited buildings**: 宿舍 south (start/home), 图书馆 center-north, 教学楼 east, 食堂 west, 社团中心 northwest, 贵人办公室 northeast. Paths connect them; distances are visual only.
- **Free movement**: player clicks a building → token walks the path (300ms/hop), input locked during the walk. Exactly 1 destination per turn; clicking the building you're already on = "stay", allowed, and draws a fresh event (time passes).
- Locked city cells become a **grey skyline beyond the north gate**: 🔒, cold palette, tooltip "出身差看不见 · 未解锁", not clickable. Warm/cold visibility thesis survives, now geographic.

## 3. C — Location event tables

- Each location gets a **weighted event table** (`core/data/locationEvents.ts`), drawn once per arrival via the seeded turn rand stream. Each table has ≥1 opportunity, ≥1 neutral, ≥1 trap; weights documented in the data file.
- **Event + choice shapes** (choices become *data*, not closures — tier scaling needs the raw delta):
  ```ts
  type LocationEvent = {
    id: string; cellType: CellType; kind: 'opportunity' | 'neutral' | 'trap';
    weight: number; eventMod: number;            // eventMod of the DRAWN event feeds the dice formula
    scaledStats: NumericStat[];                  // which deltas the tier factor multiplies
    title: string; text: string;
    choices: LocationEventChoice[];
  }
  type LocationEventChoice = {
    id: string; label: string; description: string;
    delta: StatDelta;                            // base deltas (pre-coefficient, pre-tier)
    coefficient: 'learn' | 'work' | 'rest' | null; // which origin multiplier applies (null = flat)
    coefficientStats: NumericStat[];             // WHICH stats the coefficient multiplies (v1.1: primary only)
  }
  ```
- **Resolution pipeline** (exact order, both trajectories): for each stat in the choice's `delta` — `scaled = base × (stat ∈ coefficientStats ? ORIGIN_*[origin] : 1) × (stat ∈ scaledStats ? tierFactor : 1)` → round → add to current → clamp. Clamps: cognition/stamina/mood to [0,100]; wealth unclamped. Side-effect stats (not in `scaledStats`) are never tier-scaled; non-`coefficientStats` are never origin-scaled (v1.1 parity: learn scales cognition only, stamina stays flat −8; work scales wealth only; rest scales stamina recovery only, mood stays flat).
- **Rest-base encoding**: rest stamina bases store v1.1's reciprocal divisors as fractions (club_activity stamina base `0.5`, stay_in `1.0`), so `base × ORIGIN_REST_RECOVERY[origin]` reproduces v1.1's `round(RECOVERY ÷ divisor)` exactly (10×0.5=5; 30×0.5=15). The post-multiply `round` makes fractional bases safe.
- **Origin divergence (corrected, = v1.1 exactly)**: `coefficient: 'learn'` → `ORIGIN_LEARN_MULTIPLIER`; `'work'` → `ORIGIN_WORK_MULTIPLIER`; `'rest'` → `ORIGIN_REST_RECOVERY`; `null` → flat — each applied to `coefficientStats` only. The 金融世家 twin diverges on learn/rest/work precisely as v1.1.
- **Alt-trajectory tier factor**: the twin's deltas scale by the **alt tier** (from `rollAltDice` — same physical dice, different total → possibly different tier). The parallel-fate card displays the alt tier next to these deltas, so the twin's outcome must be scaled by the tier the player sees there. §9(a) expected values use the alt tier's factor.
- **Tier scales the outcome** (replaces what tiers did for movement, §7.1):
  | tier | opportunity/neutral (boon) | trap |
  |---|---|---|
  | big_fail | ×0 (fumbled) | ×1.5 |
  | fail | ×0.5 | ×1 |
  | success | ×1 | ×0.5 |
  | big_success | ×1.5 | ×0.25 |
  | awaken | ×2 | ×0 (dodged) |
- **Mentor office exception**: 贵人办公室 does NOT use weighted draw. Arrival triggers the v1.1 mentor roll (`ORIGIN_MENTOR_FREE_HIT_PROB`, per origin, seeded); hit/miss are its two entries (贵人指点 / 贵人不在) with v1.1 MENTOR_BASE deltas, then tier-scaled like any event. **Both mentor entries carry `eventMod: +1`** (preserves v1.1's 贵人+1 under the new destination-event rule, §7.2). Shape conformance: hit = `{ kind: 'opportunity', scaledStats: ['cognition','mood'], weight: 0 }`, miss = `{ kind: 'neutral', scaledStats: ['cognition'], weight: 0 }`, both choices `coefficient: null` (v1.1 mentor gains are flat; origin scales the hit *probability*, not the payload). `computeAltMentorHit` unchanged.
- ⚡特殊事件 remain **world-level** shocks (cell-independent, 无预兆), drawn together with the location event at arrival and **applied immediately, before the dice roll** (post-shock mood feeds that turn's stateMod, as v1.1); the banner flashes on the world layer BEFORE the dice overlay opens. Location events are local (card). Two distinct layers.

## 4. D — Mood → information quality

Reuse the existing 30/60 mood bands (already load-bearing for stateMod — no new thresholds to learn):

| mood | state | invest preview |
|---|---|---|
| < 30 | 情绪化 (pessimism) | degraded: last-3 curve ticks hidden behind seeded noise, risk framing exaggerated |
| 30–60 | 理性 | full honest preview (= v1.1 behavior) |
| > 60 | 亢奋 (overconfidence) | inflated: upside among last-3 ticks highlighted, downside muted ("这次稳了") |

- **Assets never change** — the deterministic 8-tick curves stay frozen; only the *information shown* is distorted. Distortion applies to the **last 3 ticks** (the far future is what you misjudge); noise is drawn from the turn's seeded rand stream (determinism convention holds). Investing under distortion **is** the gamble; 稳健理财 remains the always-available rational out.
- The invest panel labels the current info state (理性/情绪化/亢奋) so the player learns to distrust their own preview.
- **Cognition folds in** (E3): cognition ≥ `COGNITION_INFO_THRESHOLD = 60` sets `narrowed: true` — distortion shrinks from last-3 ticks to last-1. Learning literally improves information.
  ```ts
  infoQuality(player) → { quality: 'pessimistic' | 'rational' | 'overconfident'; narrowed: boolean }
  ```
- **Sweet spot (intended, documented)**: mood exactly 60 is rational per the bands above yet still earns the frozen +1 stateMod — lucky AND clear-headed, the investor's razor edge.
- Intended tension: mood > 60 grants +1 dice while corrupting judgment — feeling good is exactly when you misread the market. Rejected alternative: a separate "rationality" stat (5th stat, collides with cognition).

## 5. E — Folded-in improvements

- **Coach hint** (E2): coach line gains a one-line "下次试试…" forward-looking hint, templated per dominant attribution dimension (cognition/origin/emotion — era is unreachable as dominant, so 3 templates suffice).
- Deferred (recorded, not in v1.2): E1 failure texture, E4 interactive parallel fate, E5 replay/daily-seed.

## 6. Turn state machine (v1.2)

`TurnPhase = 'choose_destination' | 'walking' | 'dice' | 'event' | 'invest' | 'results' | 'summary'`

- **Turn 1**: the 出身定型 opening beat plays first (game-opening only; not in any table) and does NOT consume a turn — the player then chooses a destination as normal.
- `choose_destination`: buildings clickable (current building = stay, allowed, redraws). → `walking`: input locked, token walks 300ms/hop. → arrival (instant, inside the walking→dice transition): seeded draw (weighted table; mentor office → mentor roll instead) + ⚡ shock roll; shock applies immediately; banner flashes if triggered. → `dice`: overlay, 掷骰子 manual (ritual preserved); the formula's eventMod term = the drawn event's (player sees the number before seeing the event). → `event`: overlay, card revealed, tier-scaled choice per §3. → `invest`: overlay, §4 preview. → `results`: wide overlay (coach | 平行命运). → world applies consequences → `choose_destination` again.
- 宿舍's events carry `cellType: 'rest'` (rest-flavored table) even though the Cell record keeps legacy type `'start'`; **attribution keys off the event's cellType**, so 宿舍 turns attribute to 情绪.
- `INTRO_TURN_LIMIT = 8` unchanged.

## 7. TDD frozen-contract amendment (what v1.2 rewrites)

1. **Movement**: `movePlayer(diceTotal)` → `movePlayerTo(cellId)` (player-chosen). `DiceRollResult.cellsToMove` is **retired**; tier consequences are re-homed to the §3 tier-factor table (awaken's post-awaken +1 stateMod flag untouched).
2. **eventMod**: now a property of the **drawn destination event**, replacing v1.1's departure-cell `eventModForCell`; cells no longer carry eventMod.
3. `core/data/locationEvents.ts` (new, 6 tables); `coachLines.ts` gains `NEXT_TRY_HINT` (3 templates).
4. `core/simulation/events.ts`: new `drawLocationEvent(cellId, rand)`; `resolveEventChoice` reimplemented on the §3 pipeline (data choices, no closures); mentor path preserved (§3 exception).
5. `core/simulation/invest.ts`: new `infoQuality(player)` + seeded distortion-preview builder; underlying curves untouched.
6. **Types**: add `LocationEvent`, `LocationEventChoice`, `InfoQuality`, `COGNITION_INFO_THRESHOLD = 60`; `TurnPhase` union replaced per §6 ('map'→'choose_destination', 'coach'→'results', +'walking'); `EventOffer` is **redefined** as `{ event: LocationEvent; mentorRoll?: number }` (v1.1's duplicated cellId/cellType/choices fields retire — everything reads through `event.*`); v1.1 closure-style `EventChoice.apply` retired in favor of data `delta`+`coefficient`+`coefficientStats`; `TurnResult` gains the drawn `locationEvent`; attribution consumes `LocationEvent.cellType`, not the Cell's type; canonical clamps (cognition/stamina/mood [0,100], wealth unclamped) now uniform.
7. DEV builds expose `window.__sim` (Simulation handle, repo convention) for scripted checks.
8. **Unchanged**: dice terms (originMod/eraMod/stateMod stacking thresholds), tier ladder boundaries, ⚡ shock params, 平行命运 same-location/same-event/same-dice rule, attribution incl. extremeState override, INTRO_TURN_LIMIT.

## 8. Out of scope (unchanged boundaries)

No real market-data API; no live LLM; no additional origins/eras/zones.
