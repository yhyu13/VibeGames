# 02 · v1.2 Campus World — Design Spec (2026-08-10)

Status: **user-approved** in brainstorm session 2026-08-10. Extends v1.1; does not touch the 1×1×1 scope (1 origin × 1 era × 1 zone), no market API, no LLM.

## 0. Scope decision (explicit)

v1.2 is a **documented expansion** beyond the intro-scene-only discipline (AGENTS.md §2): movement becomes player-chosen, location event tables and mood→info distortion are new mechanics. GDD.md §2, TDD.md (v1.2 + changelog), AGENTS.md §1–2, `docs/design/01-art-direction.md` §3–4, and `docs/levels/intro_scene.md` §8 (new decisions D4/D5/D6) are updated in the same milestone — the expansion is recorded, not smuggled.

## 1. A — World + Beat Overlay layout

Two layers, always:

- **World layer**: top HUD → full-bleed campus map → conditional ⚡ shock banner. Always visible; shows cause→effect (token walks, HUD ticks).
- **Beat overlay layer**: exactly one center card at a time; world dims to ~45% behind it. The v1.1 bottom swap-band is **deleted**.

Beat sequence per turn (enter motion: scale 0.96→1 + fade, 300ms):

1. **Dice** — big animated dice + term-by-term formula; `掷骰子` lives here.
2. **Event** — location event card; choices as 2–3 large cards when present.
3. **Invest** — v1.1 panel content + §4 distortion treatment.
4. **Results (wide card)** — AI coach left (typewriter + 4D attribution bar + hint, §5), 平行命运 right.
5. Dismiss → world shows consequences → next turn.

SummaryScreen stays a full-screen takeover (finale, not a beat). Pure presentation change: `src/core/` untouched by this section.

## 2. B — Real campus map

- Top-down stylized campus, **pure CSS/SVG** (repo zero-asset convention), warm-paper palette from 01-art-direction §1.
- The 6 locations become **geographically sited buildings**: 宿舍 south (start/home), 图书馆 center-north, 教学楼 east, 食堂 west, 社团中心 northwest, 贵人办公室 northeast. Paths connect them; distances are visual only.
- **Free movement**: player clicks a building → token walks the path (300ms/hop retained). Exactly 1 destination per turn. **Dice no longer move the token** — dice resolve *what happens there* (formula/tiers/stateMod/eventMod intact).
- Locked city cells become a **grey skyline beyond the north gate**: 🔒, cold palette, tooltip "出身差看不见 · 未解锁". The warm/cold visibility thesis survives, now geographic.

## 3. C — Location event tables

- Each of the 6 locations gets a small **weighted event table** (seeded-rng draw on arrival): a mix of **opportunity / neutral / trap**, all true to the cell's type. Example (图书馆): "学长笔记" (opportunity, +cognition), plain study (neutral), "占座大战" (trap, −stamina).
- Dice role is unchanged: the drawn event's outcome resolves through the existing tier ladder (big_fail…awaken) with the frozen formula.
- ⚡特殊事件 remain **world-level** shocks (banner, cell-independent, 无预兆); location events are **local**. Two distinct layers, two distinct visuals.
- 平行命运 contract survives free movement: the 金融世家 twin visits the **same location, same event, same dice** — different origin coefficients, exactly as v1.1.

## 4. D — Mood → information quality

Reuse the existing 30/60 mood bands (already load-bearing for stateMod — no new thresholds to learn):

| mood | state | invest preview |
|---|---|---|
| < 30 | 情绪化 (pessimism) | degraded: some curve ticks hidden/noisy, risk framing exaggerated |
| 30–60 | 理性 | full honest preview (= v1.1 behavior) |
| > 60 | 亢奋 (overconfidence) | inflated: upside ticks highlighted, downside muted ("这次稳了") |

- **Assets never change** — the deterministic 8-tick curves stay frozen; only the *information shown* is distorted. Investing under distortion **is** the gamble; 稳健理财 remains the always-available rational out.
- The invest panel labels the current info state (理性/情绪化/亢奋) so the player learns to distrust their own preview.
- **Cognition folds in** (critique E3): cognition ≥ 60 narrows any distortion one step (partial tick recovery) — learning literally improves information.
- Documented tension (intended): mood ≥ 60 grants **+1 dice** (luck up) while corrupting judgment — feeling good is exactly when you misread the market.
- Rejected alternative: a separate "rationality" stat — 5th stat, collides with cognition; mood-as-distortion is simpler and thematically true.

## 5. E — Folded-in improvements

- **Coach hint** (critique E2): coach line gains a one-line "下次试试…" forward-looking hint, templated per dominant attribution dimension (cognition/origin/emotion).
- Deferred (recorded, not in v1.2): E1 failure texture (bust/burnout), E4 interactive parallel fate, E5 replay/daily-seed.

## 6. Turn flow contract (v1.2)

**choose destination (world layer)** → token walks → **dice overlay** → **event overlay** → **invest overlay (distorted preview)** → **wide results overlay** → world shows consequences. Turn still caps at `INTRO_TURN_LIMIT = 8`.

## 7. TDD frozen-contract amendment (what v1.2 rewrites)

- **Movement**: `movePlayer(diceTotal)` → `movePlayerTo(cellId)` (player-chosen); `TurnResult` gains the drawn `locationEvent`. Dice terms (originMod/eraMod/stateMod/eventMod), tiers, stacking thresholds — **unchanged**.
- `core/data/`: new `locationEvents.ts` (6 tables); `coachLines.ts` gains `NEXT_TRY_HINT` per dominant dimension.
- `core/simulation/events.ts`: new `drawLocationEvent(cellId, rand)` (seeded, weighted).
- `core/simulation/invest.ts`: new `infoQuality(player) → 'rational' | 'pessimistic' | 'overconfident'` + preview-distortion builder; underlying curves untouched.
- Types: `LocationEvent`, `InfoQuality`, `COGNITION_INFO_THRESHOLD = 60`.
- stateMod, ⚡ shock, 平行命运 (same-location rule), attribution (incl. extremeState override), INTRO_TURN_LIMIT — all unchanged.

## 8. Out of scope (unchanged boundaries)

No real market-data API; no live LLM; no additional origins/eras/zones; no new zones beyond the campus map reskin.

`npx tsc -b --noEmit` (0 errors) → `npm run build` (green) → `scripts/showcase.mjs` updated for click-to-move (click building → beats) → 8-turn playthrough, 0 console errors, screenshots in `8_lifegame/showcase/`.
