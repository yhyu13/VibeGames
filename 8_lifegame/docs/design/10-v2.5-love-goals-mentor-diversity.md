# v2.5 — 人生目标 + 爱情线前移 + 贵人多元化 + 世家事件池

Date: 2026-08-13. Status: implementation contract.
Changelog row: TDD.md v2.5. Decision trace: D20/D21.

## 1. Product intent

Intro scene 的四条用户指令在同一次 pass 落地:

1. **judge finish** — intro scene 判定为"机制完成,叙事待补":17 周日历、模拟盘、平行命运、
   觉醒诊断都已收尾,但前 5 分钟缺少开场戏剧,爱情线直到第 14 周才出现,贵人是单一
   人格,金融世家运行套用小镇生活池。
2. **完成金融世家玩法** — 世家运行获得自己的事件池(家族汇报会/信托分红/董事会交锋/
   继承人之争/名媛圈),替换掉小镇的"全村的目光/家里的装修款/老房拆迁"等错位事件。
3. **小镇做题家戏剧化 + 视觉** — 开场升级为两幕电影式卡片(出身故事 → 人生目标),
   校园地图加 CSS 装饰(云/树/花),爱情线在第 2 周(迎新晚会)就开始。
4. **贵人多元化 + 爱情系统** — 贵人办公室按"方向"拥有 4 种人格(技术前辈/券商经理/
   厂长/老教授);新增"贵人好感"(mentorFavor)通道;爱情线前移为学期三拍
   (2/6/10 周)+ 圣诞重逢,开局即立下财富 + 爱情双重人生目标。

## 2. 爱情线契约 (v2.5)

- **学期三拍**: `LOVE_FIRST_TURN=2`(迎新晚会 · 初次相遇)/ `LOVE_SECOND_TURN=6`(期中 ·
  图书馆偶遇)/ `LOVE_THIRD_TURN=10`(期末 · 跨年邀约)。
- **注入语义与世家关系线一致**(design 08 §1):教学节拍(开户/发现贵人/选方向/办卡)
  与季节节拍优先,爱情拍顺延到下一次普通到达;`loveStage` 在 `none → met → knowing →
  close` 间推进(第三拍拒绝 `love_third_raincheck` 不进阶)。
- 优先级: `seasonal > 第13周关系收尾 > teaching > 世家关系线 > 爱情线 > 普通抽卡`。
- **印象**: 每拍用当前状态(认知 ≥ 60 且身心健康 ≥ 70)给 `loveImpression`;已 good 不降级。
- **圣诞(第14周)**: 按 `loveStage` 换标题/文本(初遇/再遇/熟稔/一起跨年);寒假第 16 周
  `shouldReunite(loveImpression, loveStage)` —— good 印象或 close 阶段都触发重逢,否则反思。
- **铁律不变**: 爱情永不进入贵人信任、觉醒或解锁计算。
- 第一拍强制在第 2 周后的第一次到达注入——除非教学节拍占位(图书馆发现等)。

## 3. 人生目标契约 (v2.5)

- 开场卡第二幕立下双重目标: 财富目标 `TOWN_LIFE_GOAL_WEALTH=150_000` /
  `DYNASTY_LIFE_GOAL_WEALTH=400_000`(≈ 出身初始财富 +50%);爱情目标为阶段推导
  (`loveStage === 'close' || loveReunion` 视为达成)。
- `GameState.lifeGoalWealth` 在 `createInitialState(origin)` 建立;HUD 显示 🎯 进度 chip;
  总结页渲染两条目标 verdict(达成/进行中/未开始)+ 进度条。
- 目标只读状态,不改任何数值/概率;展示层(IntroScene/SummaryScreen)专属。
- **进度口径(自我批判修正)**: 进度条按**净挣得**计算(`lifeGoalProgressFor`: 出身起点
  小镇 ¥100k / 世家 ¥300k,目标增量小镇 ¥50k / 世家 ¥100k)—— 开局 0%,而不是继承起点
  即 67% 的误导读数。"第一桶金" = 挣出来的,不是领的;达成判定仍是绝对阈值
  `wealth ≥ lifeGoalWealth`。

## 4. 贵人多元化契约 (v2.5)

- **4 人格**: `MENTOR_EVENTS_BY_TRACK` 按选方向换人 —— ai=码农出身的技术前辈 /
  finance=券商营业部经理 / industry=制造业厂长 / academia=退休经济学教授;未选方向
  回退通用 `MENTOR_EVENTS`。机制完全一致(hit/miss id、eventMod +1、信任开关),
  只换 voice(标题+正文)。
- **贵人好感**: `SpecialEvent.mentorFavor?: number`;命中后
  `mentorFavor = clamp(0..MENTOR_FAVOR_MAX=4)`。办公室命中概率
  `mentorHitProbFor(origin, trusted, favor)`:
  `trusted → 0.9`(铁律不变);否则 `min(0.9, ORIGIN_MENTOR_FREE_HIT_PROB + 0.12 × favor)`。
  小镇池新增 3 个好感事件(图书馆的老教授/学长的内推/物理老师的孩子 + 世界级公开课 +
  大厂面试通知各 +1 好感)。平行命运 twin 恒用 favor 0(好感是"你的故事挣来的",不继承)。
- **好感通道 vs 信任开关**: 信任(有能力 × 对口 = 90%)仍是主导杠杆;好感是
  "有人推了你一把"的多样性通道,把小镇 10% 的裸命中率推到最高 58%。

## 5. 世家事件池契约 (v2.5)

- `specialEventsFor(origin)`: 小镇 = 原 49+ 事件池;世家 = 市场(11)+ 朋友(7)+ 健康(6)
  + 16 个世家生活事件(家族季度汇报会/父亲的电话/母亲的电话/家族信托分红/私人银行/
  董事会交锋/名媛圈/好胎闲话/海归交换生/慈善晚宴/父亲住院/第一笔自己挣的钱/
  继承人之争短信/私募酒会/校门口的车/老宅照片)。宿舍对谁都一样,所以朋友与健康共享。
- 两个池都保留 `assetShock` / `choices` 机制;触发概率仍 55%。

## 6. Deterministic verification

DEV/showcase 必须固定验证:

1. love 三拍注入阈值(1<2, 5<6, 10)、阶段推进、raincheck 不进阶、close 停止;
2. 第 2 周到达强制 `love_first_encounter`;爱情选择后 `loveStage='met'` 且不觉醒;
3. `shouldReunite` 的 close/good 开关;`christmasContext` 随阶段变化;
4. 好感概率表(0/2/max/trusted/dynasty base)与上限;
5. 4 人格标题 + 回退通用 + hit/miss id 不变;
6. 人生目标数值(小镇 150k/世家 400k),总结页达成与进行中两种 verdict;
7. 世家池 ≥30 事件、含 `dy_*` 与"信托"、共享市场冲击;小镇池 ≥49、含好感事件;
8. 第 13 周关系收尾优先级不回归;完整 17 周浏览器 playthrough 0 console errors。
