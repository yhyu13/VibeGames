### 审计发现补录（2026-08-31 code audit）

> 审计结论：0 个 crash/数据丢失级正确性 bug（clamps / 双账本 / 确定性 / 取整护栏全部干净）。以下是错误行为与 polish 发现，已并入上面各档；此块单列以便溯源。

**错误行为（进 P1）**
- **HUD 翻盘进度滞后一周** — `IntroScene.tsx:111` 用 `allPrices(player.turn)`（周开盘价），结果相位滞后于刚结算的周收盘价。改用结果相位的 `pendingInvestment.totalValue`。
- **冬季 beat 的 fiction 前缀** — `EventModal.tsx:16-22` 的 `LOVE_BADGE` 漏掉 `winter_growth`/`winter_reflection`，这两个 beat 仍带地点前缀（与 v2.5 自爱线 beat 去掉地点前缀的约定矛盾）。
- **twin 贵人信任用了玩家的 track** — `Simulation.ts:444/478` twin 的信任判定用了玩家的 `state.track` + twin 自己的认知 —— 「对口」那一半被继承了（注释说信任是挣来的）。`ParallelState` 无 track 字段。
- **卖出取整的 dust-value 漏洞** — `invest.ts:99` 卖出 `roundUnits` 四舍五入（买入侧有 v2.10 floor 护栏，卖出侧没有），0.00015 BTC 四舍五入到 0.0002 > 持仓 → soldFraction>1 凭空造现金。卖出侧补 floor。
- **side 'mixed' 从 fills+blocked 派生** — `invest.ts:263-269` 一个被拦的 buy + 一个成交的 sell 会报 mixed，与类型注释（「buy+sell 都成交」）矛盾。
- **真实度开关无门** — `store.ts:108` `setTradingRealism` 任何相位都能切，篮内委托中途切换残留旧金额预期。

**polish / 死代码（进 P2）**
- 死代码导出：`allCampusCells`(Simulation.ts:701) / `roundUnits`(invest.ts:28) / `computeScaledDelta`(events.ts:97) / `dominantDimension`(attribution.ts:39) 无 importer。
- 死 CSS 类：`EventModal.tsx:94` 输出的 `event-kind-*`/`event-panel` 无对应 CSS 规则。
- BeatOverlay 所有 beat 同 `aria-label="游戏事件"`（屏幕阅读器无法区分掷骰/事件/交易/结算）。
- 锁定建筑 `tabIndex={-1}` 不可键盘聚焦（解锁提示键盘不可达）。
- BTC 成交 `toLocaleString()` 默认 ≤3 位小数 → 0.0001 份打印成「0 份」。
- `useCountUp.ts:10-24` 中途值变化从过期 prevRef 起跳（快速数值摆动时可见跳变）。
