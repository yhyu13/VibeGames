# 8_lifegame — 100 项增强路线图 (P0 / P1 / P2)

> 与 `roadmap-100.md`（正确性/可玩性单点任务）不同，本清单聚焦 **把冻结的 intro scene 变成完整可玩的游戏**：解锁 17 周以后的回合、真实输赢/破产、给文本/DOM UI 加手感（行情图、ticker、sparkline、事件弹窗）、存档读档、实时行情 + 分支结局/多出身/移动端/音频/可及性。每条给「做什么 + payoff」，方案细节各写 plan。

**优先级定义**
- **P0**：不做就不是「可玩的游戏」——把冻结演示跑成完整一局 + 让文本 UI 有游戏感 + 最基础的输赢/存档/可及性。
- **P1**：深化现有核心循环的乐趣与可读性（分支、关系、庆祝、速度、移动端、a11y 细节）。
- **P2**：扩范围或锦上添花（新时代/区域/模式/商用），需新 plan doc。

---

## P0 — 把冻结演示跑成完整可玩一局 + 文本 UI 游戏感 + 基础输赢/存档/可及性

- [P0] 解锁 17 周之后的完整学期 — 现在 `INTRO_TURN_LIMIT=17`（types.ts:421）一到就 `summary`（Simulation.ts:660），把 demo 变成真正跑完的一局。
- [P0] 真实胜利条件（模拟盘翻盘达标） — 以 `paperGoal`（constants.ts TOWN/DYNASTY_PAPER_GOAL）+ `paperGoalProgressFor` 达成判定「赢」，而不是只看只读总结。
- [P0] 破产/清零的失败条件 — 模拟盘净值归零或生活费跌破阈值即游戏结束，给玩家真实风险与止损动机。
- [P0] 存档/读档 — `store.ts` 的 `GameState + rand + runId` 持久化到 localStorage，刷新可继续；种子可复现。
- [P0] 实时行情回放 — 每回合把该周 7 资产的 `ticks`/`daily` 逐帧播放出来，数字会动，市场「活」起来。
- [P0] 每资产 canvas/SVG sparkline — 收窄到单资产的迷你价格曲线（allPrices/priceAt 已有数据），一屏读懂走势。
- [P0] 全局行情 ticker 动画 — HUD 上滚动字幕条：资产名 + 涨跌幅 + 涨跌箭头，滚动的市场感。
- [P0] 事件弹窗动画 — `EventModal`/`BeatOverlay` 加滑入+缩放+淡入，替换当前硬切。
- [P0] K 线图实时渲染 — `InvestPanel` 用真实 `Candle[]` 画可动 K 线（当前蜡烛为静态表示），收盘价跳动。
- [P0] 成交反馈 — 买入/卖出/成交时数字闪动+音效，单子「落地」有手感。
- [P0] 硬币/打字/行情 Beep 音效 — Web Audio 合成零资产 sfx，给事件文本、金币、涨跌配音。
- [P0] 字体大小控制 — 文本游戏核心可读性：字号滑块（目前固定）。
- [P0] WCAG AA 对比度 — HUD 深底浅字与面板色阶过键盘探针/人工对比度审计。
- [P0] 屏幕阅读器事件标签 — `BeatOverlay` 每个 beat 现在同 `aria-label="游戏事件"`（roadmap audit 已标记），按 phase 区分掷骰/事件/交易/结算。
- [P0] 净值增长计数动画 — HUD/周结算用 `useCountUp`（组件已存在）让财富/模拟盘数字一路涨到目标。
- [P0] 骰子掷出表现 — `DiceRoller` 加翻滚/落定/力度展现，手动掷骰仪式更有张力。
- [P0] 学期末里程碑时刻 — 第 13 周/圣诞节/新学期加入高亮庆祝 Beat，转折点可感知。
- [P0] 打破 PDF 依赖 — 从 `ch04-ch05.pdf` 抽取的核心数值表（constants.ts 已转录）整理成结构化 JSON schema，不再依赖源 PDF。
- [P0] 可分享种子 + 种子展示 — 显示当前 run 的 seed，玩家可复现/他人可分享同一局。
- [P0] 生活账本 vs 模拟盘双账可视化 — 把生活费与模拟盘两套数字在 HUD/总结上用不同颜色与区块区分（`SpecialEvent`/`PaperAccount` 双数值易混）。
- [P0] 结算相位 P&L 快照卡 — results 相位单独展示本周末平仓/浮动盈亏，非只读数字。
- [P0] 教练台词打字机 — `AICoachPanel` 的 line 逐字打出，文本叙事有节奏。
- [P0] 建筑间移动示意 — 从一栋到另一栋的 walking 转场（当前直接切位置）。
- [P0] 总结屏胜负判定可读 — `SummaryScreen` 明确「赢/输/破产/仍冻结中」大字结论。
- [P0] 回合历史日志面板 — 可滚动/过滤的 `TurnResult[]` 历史，回看每回合掷骰/事件/交易。

## P1 — 深化核心循环的乐趣与可读性

- [P1] 一局可选多出身（城市中产/海外精英） — `Origin` 类型全存（types.ts:5），补 event pool + 开局差异化骰子手感。
- [P1] 按出身切换 3 类教练人格 — 班主任/家族朋友型/同辈学霸型，台词随 origin 变。
- [P1] 分支结局 — 按财富目标达成/爱情 stage/觉醒层级组合出多段式结局，而非单一总结。
- [P1] 师徒/爱情关系后果事件 — mentor 信任与 love line 后续有触发后果的分支（现在多为单点）。
- [P1] 出身专属里程碑庆祝 — 小镇/世家的不同 semester 庆祝彩蛋。
- [P1] 移动端/平板响应式布局 — 校园地图 + 面板在窄屏重排/折叠（目前桌面单列）。
- [P1] 速度控制/倍速 — 1x/2x 快进动画与回合推进，长局不拖沓。
- [P1] 自动结算回合开关 — 一键自动掷骰+选事件+hold，跳过长重复操作。
- [P1] 事件历史日志筛选 — 按地点/类型/数值筛历史，回看决策。
- [P1] 多局元进度 — 通读一次解锁新出身，形成成长感（`financeDynastyUnlocked` 已有先例）。
- [P1] 环境音 + 音量面板 — 校园环境底噪与音量集中设置面板。
- [P1] reduced-motion 开关 — 尊重 `prefers-reduced-motion`，动画降级。
- [P1] 色弱友好涨跌色 — 上行/下行不只靠红绿（a11y 1.4.1），加形状/文字第二线索。
- [P1] 设置持久化面板 — 音量/倍速/字号/动画集中管理并持久化。
- [P1] 教练建议内容复盘 — mentor 命中时给与当前持仓相关的具体建议（现在偏泛）。
- [P1] 爱情线分支（分手/追求/错过） — love line 不止 close/reunion，加入放弃与错过的子结局。
- [P1] 人生目标多样化 — 除财富/爱情外，加入认知/觉醒层级的替代目标选择。
- [P1] 周目标/小任务 — 每学期定的迷你目标（去一次健身房/见一次贵人），增加指引。
- [P1] 资产相关性提示 — 同涨同跌品种（A股/港股/指数）的自相关与分散化提示。
- [P1] 组合仓位上限警告 — 单资产/总仓位超阈值时提示（与策略分级联动）。
- [P1] 回撤/波动率仪表 — 跟踪模拟盘回撤与波动率，让风险可感知。
- [P1] 教练归因可视化 — `buildCoachOutput` 的 dominant dimension 用雷达/占比条呈现。
- [P1] 平行命运差异可视化 — twin 与玩家资产曲线并列展示（现在只有对照卡）。
- [P1] 觉醒揭示时刻 — 中/大觉醒加金光/震动全屏瞬间（roadmap audit：现在只是一个 note）。
- [P1] 回合转场摘要条 — 每回合转场顶部一条本周核心事件摘要。
- [P1] 风险偏好问卷 → 建议策略 — 开局测评给新手/真实档与持仓风格建议。
- [P1] 交易术语词汇表/提示 — T+1/涨跌停/最小单位/手续费等用 tooltip 讲清（`TRADING_RULES` 已有数据）。
