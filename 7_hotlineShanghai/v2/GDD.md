## 0. 系统性研究(Systemic Research)

### 0.1 名字解构:为什么叫 "Hotline Shanghai"

- **"Hotline"**:直接对位 *Hotline Miami*(2012, Dennaton Games)— 顶视角 + 一击必杀 + 节奏 + 面具 = indie 复古暴力美学的范式。参照资料(百度百科 / vg247 / primagames):HM 核心 = 快节奏、高死亡率、试错重开、动物面具改变玩法。
- **"Shanghai"**:1937 年 8 月 13 日淞沪会战爆发、11 月中国军队撤离上海,公共租界 / 法租界进入"孤岛"期(1937.11 - 1941.12)— 灯红酒绿 + 暗杀 + 地下抵抗 + 物资走私。**题材与"血战上海滩"(2003 欢乐数码)同源**:同样是抗日背景、同样是 1937 上海,但我们是顶视角像素暗战,不是第一人称光枪正面战场。
- **合成含义**:"Hotline Shanghai" = 一条打进来的电话(像 Hotline Miami 那种匿名指令),让你去暗杀孤岛里某个穿军装 / 制服的人 — 复古 8-bit 美学 + 真实光影 + 反法西斯题材。

> **风险声明**:经 2026-08-08 网络检索(Steam / itch.io / 163 / 百度 / Google),"Hotline Shanghai" 暂无同名游戏发布,可安全用作 vibe game 项目名。如未来发现重名,优先级 = 本文档(原创) > 第三方同名作品。

### 0.2 参考作品矩阵(Reference Matrix)

| 维度 | 参考 | 借鉴点 | 警惕点 |
|------|------|--------|--------|

| **操作模式** | Hotline Miami(F 近战/远程切换、攻击键、3 拾取/投掷、右摇杆瞄准) | **F 切换近战/远程 + 单键攻击 + E 拾取/投掷 + 鼠标瞄准** 对齐为键鼠版 | 键鼠 ≠ 手柄,右摇杆 → 鼠标 |
| **武器系统** | Hotline Miami(35 种:小刀/棒球棍近战 + 手枪/霰弹/冲锋枪远程 + 投掷) | 武器分近战 / 远程 / 投掷三类;**v1 锁 8 件、里程碑铺到 35** | 每件必须有显著手感差异,拒绝数值堆砌 |

| **历史题材** | 血战上海滩(2003)+ 八百(2020)+ 战上海 | 1937 上海抗日做背景(淞沪会战 / 四行仓库 / 苏州河 / 外滩) | 我们做顶视角孤岛暗战,不做光枪正面战场;历史敏感度见 §2.4 |
| **像素美学** | Hotline Miami 8-bit 风(其实是非纯像素,而是 neon flat) | 高对比 + 配色强 + 像素粒度 + 顶部俯瞰 | 我们用 16×16 像素 sprite,房间 tile-based |
| **顶视角射击** | Enter the Gungeon / Nuclear Throne | 走位 + 翻滚 + 房间刷怪 | 武器 / 弹道丰富度要够;不做 Roguelike 永久死亡 |
| **音频合成** | Hotline Miami 电子 synth 风格 + Web Audio 程序化 | 80s 复古电子 + 程序化合成;HM 的"电话 + 打字机"叙事音 | 中文配音成本高,我们用打字机文本 + 短合成音 |

| **架构** | C.A.T(4_chunbai / 5_gamejam_1 / 6_patapong3D 验证) | core 平台纯净 / engine 平台适配 | RC 管线放 engine,不放 core(core 不知道 WebGL) |

- ❌ "Hotline Miami"(Dennaton Games)— 单词不同,不易混淆
- ❌ "Hotline Miami 2: Wrong Number"(Dennaton Games)— 同上
- ❌ "血战上海滩"(欢乐数码, 2003)— 题材相关但完全不同的游戏(光枪 / 第一人称 / 正面战场)
- ❌ "Hotline Shanghai"(2026-08-08 网络检索)— **未注册**,安全
- ✅ "Hotline Shanghai / 热线上海" = 可安全用作 vibe game 项目名

### 0.4 设计决策的"为什么"摘要(Why This Design)

| 决策 | 替代方案 | 取舍 | 理由 |
|------|----------|------|------|
| **2D 像素 + 真 RC 光影** | 3D 写实 / 2D 纯贴图 / 2D 假 additive light | ✅ 取 | RC 是 2D 像素氛围的天花板;假光会毁了 1937 弄堂的"灯下黑"质感 |
| **任务式(电话指令)** | Roguelike / 沙盒 | ✅ 取 | Hotline Miami 范式;玩家 30-60s 一局,适合 vibe game 体量 |

| **零资产文件**(程序化 sprite + Web Audio) | 资产商店买 / 委托美术 | ✅ 取 | 沿用项目惯例;v1 体量买不起定制美术 |
| **6 面具 → 铺 25** | v1 就做 25 个 | ✅ 取 | v1 范围控制;每个面具效果必须显著,25 个走里程碑 |
| **8 武器 → 铺 35** | v1 就做 35 个 | ✅ 取 | 同上;先做 4 远程 + 2 近战 + 2 投掷 |
| **C.A.T 架构** | 单文件 mvp | ✅ 取 | RC 管线太重,必须分模块;沿用 4_chunbai 验证 |
| **淞沪会战 + 孤岛暗战** | 纯孤岛期(1937.11 后) | ✅ 取 | 任务 1-3 在孤岛期;隐藏任务 4 放"淞沪会战尾声"做背景高潮 |

## 1. 高概念(High Concept)

- **Genre**:顶视角动作射击 / 任务式 / 一击必杀 / 复古 8-bit 像素
- **Tension 轴**:**不是"打不打得过",而是"每开一枪之后,整个世界会怎么亮起来"** — 枪火点亮整个弄堂、暴露你、逼你换位置、霓虹招牌在远处渗光、油灯投出软阴影
- **Tone**:1937 上海抗日 + 复古电子 + 暗战紧张 — "你是电话那头的影子"
- **玩家扮演**:上海地下抵抗组织的一名"线人",没有名字,只有代号
- **一句话**:Hotline Miami 手感,1937 上海,2D RC 让每颗子弹都点一盏灯。

## 2. 世界设定(World Setting)

### 2.1 时代:1937 年 8 月 13 日淞沪会战 → 11 月孤岛期(1937.11 - 1941.12)

- **1937.8.13** 淞沪会战爆发,八一三事变;中国军队在闸北 / 罗店 / 四行仓库浴血 — 我们的背景起点。
- **1937.10 底 - 11** 四行仓库八百壮士、苏州河畔灯火围观;11 月中国军队撤离上海,公共租界(虹口 / 杨树浦)被占领军接管,法租界成为"孤岛"。
- **孤岛期**:法租界 / 华界边缘的弄堂 / 茶馆 / 舞厅 / 小报馆 / 私人诊所,物资紧张、特务横行、电话线繁忙。
- **活动范围**:法租界 / 华界边缘的弄堂、茶馆、舞厅、小报馆、私人诊所、黄浦江渡船、屋顶。

### 2.2 主要场景类型(Scene Archetypes)

| 类型 | 例子 | 光源特征 | 节奏 |
|------|------|----------|------|
| **弄堂** | 窄巷 + 二层窗 + 晾衣杆 | 油灯 + 窗内灯光(暖)+ 巷口霓虹(冷) | 逼仄、突袭 |
| **茶馆** | 方桌 + 屏风 + 后厨 | 中央吊灯 + 柜台灯 + 油灯(暖光满) | 隐蔽、易混战 |
| **舞厅** | 圆形舞池 + 吧台 + 乐队台 | 霓虹旋转灯 + 探照灯 + 蜡烛 | 浮夸、声东击西 |
| **码头 / 仓库** | 仓库 + 起重机 + 货箱 | 探照灯 + 桅灯 + 枪火 | 开阔、远距 |
| **私人诊所** | 病床 + 药柜 + 手术灯 | 单盏强光(手术灯)+ 油灯 | 暗杀、密闭 |
| **四行仓库残垣** | 弹孔墙 + 沙包 + 断梁 | 月光 + 燃烧余烬(唯一半开放场景) | 战地、隐藏任务 |

### 2.3 势力(Factions)

| 势力 | 角色 | 视觉 |
|------|------|------|
| **占领军** | 主要敌对 | 军装、步枪、左臂袖章 |
| **伪警** | 次要敌对 | 黑色制服、警棍 / 手枪 |
| **租界巡捕** | 敌对(中立偏恶) | 深蓝制服、左轮 |
| **帮派** | 视任务可敌可友 | 唐装 / 短打、斧头 / 匕首 |
| **特务机关** | 隐藏 BOSS(每任务 1) | 西装、礼帽、毒刃 / 短枪 |
| **平民** | 中立 | 长衫 / 旗袍 / 黄包车夫 |
| **我方(玩家)** | 地下抵抗线人 | 黑风衣 + 礼帽 + 蒙面 |

### 2.4 历史敏感度处理(冻结原则)

- 所有敌对 NPC 按**职能**区分(占领军 / 伪警 / 特务 / 帮派),不写"某族人"加负面刻板。
- 民间人士(帮派 / 平民)中性化、可合作;任务文本避免污名化。
- 背景是**反侵略叙事**:淞沪会战 / 四行仓库 / 孤岛抵抗都是中国近代史的正面记忆;BOSS 文案用"占领军长官 / 巡捕长"等可识别称谓。
- 美术评审前先文字评审(沿用 v1 §10 风险表)。

## 3. 核心循环(Core Loop)

```
Title → Mission Select (4 任务)
  ↓
Phone Ring → Mission Brief (电话亭 / 打字机文本)
  ↓
Room 1 (小空间,2-3 敌,教学)
  ↓ clear
Room 2 (中等,3-5 敌,出现新武器)
  ↓ clear
Room 3 (大空间,5-7 敌,出现 BOSS)
  ↓ BOSS kill
Mission End (Mask 解锁 + 评分)
  ↓
Mask Select (选战利品面具)
  ↓
回到 Mission Select
```

- **单任务时长**:3-5 分钟(每房间 60-90s)
- **房间时长分布**:Room 1 = 60s 教学 / Room 2 = 90s 节奏建立 / Room 3 = 90-120s 高潮
- **游戏不暂停** — Hotline Miami 范式,死了从 Room 1 重来(死亡 → 1.2s → 重开,快速回到战斗)

### 3.1 房间内循环(Room Loop)

```
Enter Room (从门进入)
  ↓
Observe (RC 灯光先开,玩家看清房间)
  ↓
Engage (枪火 / 冷兵器 / 投掷)
  ↓
Search (捡武器 / 拾面具)
  ↓
Exit (从门出去)
```

## 4. 核心机制(Core Mechanics)

### 4.1 移动 / 战斗(基础)— v2 按 Hotline Miami 操作对齐

| 输入(键鼠版) | 作用 | HM 原版对应 |
|------|------|------|
| **WASD / 方向键** | 八向移动(加速 60 u/s²,目标速度 8 u/s) | 左摇杆 |
| **鼠标** | 瞄准方向 | 右摇杆 |
| **F** | **切换近战 / 远程模式**(有 0.15s 收放武器硬直,拔刀有音效) | F |
| **LMB(攻击键)** | 按当前模式攻击:近战 = 挥击;远程 = 开火;空手时投掷 | + 键 |
| **E** | 拾取武器 / 拾面具 / 开门;**长按可把当前武器扔掉(投掷)** | 3 键 |
| **Shift** | 冲刺(短距 0.2s,冷却 1s) | — |
| **R** | 换弹(远程武器) | — |
| **Space** | 翻滚(无敌 0.4s,冷却 1.5s) | — |
| **Tab** | 暂停 / 任务简报 | Esc(原版) |
| **Esc** | 退出到标题 | — |

> 对齐理由:HM 的 "F + 攻击键" 是节奏核心 — 近战拔刀和远程开枪共用一根攻击手指,逼迫玩家在"近身一刀"和"远距一枪"之间快速决策;E 长按投掷复刻 HM 的 "3 键丢武器" 玩法(丢出去的武器 = 现场的一次性远程攻击 + 敌人可捡)。

### 4.2 一击必杀(One-Hit-Kill)

- 玩家所有武器对敌人 = **一击毙命**
- 玩家被敌人命中 = **一击毙命**
- 例外:任务 BOSS 3 击(头 / 胸 / 腿);投掷物不杀 BOSS
- 死亡:从当前 Room 1 重来,任务进度 / 拾取保留

### 4.3 武器系统(v1 锁 8 件,里程碑铺 35)

**v1 锁 8 件**(近战 2 / 远程 4 / 投掷 2):

| # | 武器 | 类型 | 弹药 | 伤害 | 特殊 | 弹道 |
|---|------|------|------|------|------|------|
| 1 | **小刀** | 近战 | ∞ | 1 击 | 攻速快(0.2s 一刀) | — |
| 2 | **棒球棍** | 近战 | ∞ | 1 击 | 范围大(45°) | — |
| 3 | **毛瑟 C96** | 远程 | 10 | 1 击 | 单发,中等后坐 | 直线 |
| 4 | **盒子炮**(驳壳枪) | 远程 | 20 | 1 击 | 10 连发,后坐大 | 直线 |
| 5 | **汤普森** | 远程 | 50 | 1 击 | 持续射,弹鼓 | 直线 + 散布 |
| 6 | **莫辛纳甘** | 远程 | 5 | 1 击 | 单发,长距,高精度 | 直线 |
| 7 | **手雷** | 投掷 | 3 | 1 击 + 范围 | 半径 4u,点燃光源 | 抛物线 |
| 8 | **飞刀** | 投掷 | 5 | 1 击(背刺 2 击) | 静默 | 抛物线 |

**M2 后铺武器(对标 HM 35 种,每里程碑 +N)**:
- 近战补:**斧头**(慢但范围 2.4u)、**短刀**(极快 0.12s)、**刺刀**(冲刺攻击)、**双截棍**(连续两段)
- 远程补:**霰弹枪**(扇形 3 弹)、**左轮**(6 发高伤)、**勃朗宁**(中速)、**狙击步枪**(超长距)、**信号枪**(照明 + 点燃)
- 投掷补:**燃烧瓶**(持续火场 + 光源)、**菜刀**(抛物线、可回收)、**砖头**(极速短距、捡拾物)
- 全 35 件 = M4 之后的 Stretch;每件必须差异手感,禁止纯数值换皮

### 4.4 面具系统(v1 锁 6 个,里程碑铺 25)

**v1 锁 6 个**:

| # | 面具 | 效果 |
|---|------|------|
| 1 | **戏子** | 进入房间后 0.5s 内,所有敌人攻击延迟(0.3s 慢动作) |
| 2 | **帮工** | 拾取武器时直接满弹 |
| 3 | **蒙面义士** | 一击必杀范围 +0.5u(刀光增大) |
| 4 | **舞女** | 翻滚冷却 -50%(更频繁) |
| 5 | **茶馆跑堂** | 房间内所有油灯 / 霓虹对你的感知范围 -30% |
| 6 | **军爷** | 持枪时移动速度 +20%(0.5s 加速) |

**M2 后铺面具(对标 HM 25 个,每个都改变玩法钩子)**:
- **虎头**(对标 HM Tiger):处决 / 击杀后 0.5s 内移动 +40%
- **猪头**(对标 HM Pig):枪械掉落率 +50%(敌人掉更多子弹)
- **猫头鹰**(对标 HM Owl):隐藏密道 / 收集品可见性 +1 层(暗处物品发光)
- **狐狸**:枪声传播半径 -50%(潜行)
- **狼头**:敌人视野 +50% 但敌人仇恨锁定你(挑战型)
- **马面**:翻滚后 0.3s 内下一击必杀(处决链)
- 全 25 个 = Stretch;v1 只做 6 个并预留 `MaskEffect` 类型扩展

### 4.5 视野 / 敌人 AI

- 敌人视野:**8u 锥形**(60° 锥角)
- 敌人听觉:**4u 半径**(枪声 / 脚步声;飞刀静默不触发)
- 玩家可见性:**油灯下高 / 暗处低**(RC 阴影区 = 隐身区)
- 状态机:**巡逻 → 怀疑(转头)→ 警觉(举枪)→ 追击(开火)**

### 5.2 RC 管线(v2,按 radiance-cascades-demo 真实算法)

> v2 把 v1 的"管线示意图"换成 demo 的**真实 pass 结构与 probe 数学**,实现时必须对齐 `C:\Git-repo-3rd\Radiance_Cascade_repos\radiance-cascades-demo\res\shaders\`(rc.frag / prepscene.frag / prepjfa.frag / jfa.frag / distfield.frag / gi.frag / final.frag)。

```
Frame N:
  ┌─────────────────────────────────────────────────────────────┐
  │ 1. prepscene pass(1 个 FB)                                  │
  │    读 scene 的 occlusion(墙/地板) + emission(光源色)        │
  │    输出 "seed 纹理":occlusion 墙 → 空(alpha 0),地板 →      │
  │    编码纹理坐标(seed);emission 光源像素 → 光色(alpha 1)    │
  ├─────────────────────────────────────────────────────────────┤
  │ 2. prepjfa(种子编码)→ JFA × log2(min(W,H)) passes           │
  │    jump flood:每 pass 跳距减半(n/2, n/4, ..., 1),9 邻域     │
  │    收敛后每像素 RG = 最近 seed 的纹理坐标,B = 距离          │
  ├─────────────────────────────────────────────────────────────┤
  │ 3. distfield:从 JFA 结果提取距离场 texture(每像素→最近墙距离)│
  ├─────────────────────────────────────────────────────────────┤
  │ 4. rc × N cascades(默认 3,ping-pong FB)                     │
  │    probe 数学(demo 原式):                                   │
  │      probeAmount = pow(baseRayCount, index)                 │
  │      spacing = sqrt(probeAmount)(每维 probe 数)             │
  │      rayCount = pow(baseRayCount, index+1)(角度分辨率)      │
  │      interval = baseInterval_px * pow(baseRayCount, index)  │
  │        (起点).. *(index+1)(终点),归一化到屏幕短边           │
  │    每 ray:radiance_interval(uv, dir, a, b) = 用距离场步进   │
  │      MAX_RAY_STEPS=128,命中表面 → 采样 scene 色 + 上一级    │
  │      cascade 合并;未命中 → 从 uLastPass 取上级 probe 合并   │
  ├─────────────────────────────────────────────────────────────┤
  │ 5. final pass:scene + radiance + dither(4×4 Bayer)→ 屏幕   │
  │    (demo 的 final.frag 是直通,我们把 dither 加在这一层)     │
  └─────────────────────────────────────────────────────────────┘
```

**v2 关键改动**(对比 v1):
- JFA pass 数从固定 5 改为 `log2(min(W,H))`(demo 原式),预算按 1080p = 10-11 pass 重估。
- cascade 0 的 rayCount = baseRayCount × 2 级合并链;`RC_BASE_RAY_COUNT=4` → cascade 0:4 条 ray / cascade 1:16 / cascade 2:64(角度分辨率指数增长,与 v1 一致)。
- `uPropagationRate` / `uMixFactor`(demo: lighting 传播率与 scene/上一帧混合比)纳入调参面板。

详细管线见 `docs/design/04-radiance-cascades-pipeline.md`(v2 需按 demo 更新)。

### 5.3 像素颗粒回压(Dither Re-Press)

> 关键约束:RC 输出是连续渐变(soft shadow),会"吃掉" 16×16 像素粒度。
> 解法:final 阶段用一个 4×4 Bayer matrix 把 RC 输出 dither 回像素。

```
RC output (continuous 0..1) →
  threshold with Bayer[4×4] →
  quantized 0/1 →
  blend with original pixel color
```

效果:暗部仍保持 RC 的软阴影感,但每 4 像素有一个量化点,保留 pixel art 颗粒。

### 5.4 性能预算(Performance Budget)

| 指标 | 预算 | 硬上限 |
|------|------|--------|
| RC 全管线(1080p) | ≤ 6ms | 10ms |
| JFA(log2 短边 pass 数) | ≤ 2.5ms | 4ms |
| Cascade pass 单次 | ≤ 1.5ms | 2.5ms |
| final composite + dither | ≤ 1ms | 2ms |
| RC 中间 framebuffer | 3 个 RGBA8 1080p | — |
| 活动光源 | ≤ 16 个 | 32 |

> 降级路径(autopilot):连续 3 帧 RC > 8ms → cascade 数 3 → 2;再超 → half-res(540p)渲染 RC;仍超 → RC 关,回退纯 base color。恢复:连续 120 帧 < 10ms。
