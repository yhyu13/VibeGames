## 核心命题

1937 孤岛期,法租界边上的"春申茶馆"是线人的情报交换点。占领军稽查队已进驻:柜台明灯
供电阁楼哨位,堂内三路护院交错巡场。玩家经后门潜入 → 摸到账台拆灯 → 阁楼哨失明 →
清场 → 从前门霓虹招牌下撤离。

**与 m1 的结构差异(避免"换皮"裁定)**:
1. **账房隔断**(西侧纵墙):把灯位围成半封闭隔间,拆灯路径必须走单口,近战收益/风险都高于 m1 的贴墙灯。
2. **堂心双柱**(中央 ## 墩):东西巡逻线绕柱交错,玩家过堂必被横扫——逼迫用屏风(X)做节奏遮蔽。
3. 霓虹招牌 `N` 是撤离点旁的可见地标(纯装饰光,m1 的 N 在角落没有叙事功能)。

## 玩法规则

1. `#` 砖墙 / `X` 屏风桌椅同 m1:挡移动、子弹、视线;声音只被 `#` 挡。
2. 拆灯 → 阁楼探照灯断电 → 哨位半盲可近身(机制 = m1,难度来自隔断单口)。
3. 巡逻车道不穿墙;两条横向线在堂心形成约 2.5s 交叠窗口(过堂时机题)。
4. 四敌全清 → 前门撤离;灯亮时撤离门前横向线是最大暴露风险。
