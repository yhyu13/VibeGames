# 17 — 历史敏感度人审 checklist（1937 孤岛期）

> **本文档角色**：所有玩家可见内容（任务文案 / NPC 命名 / 美术元素 / 截图标题 / 简报与结算文本）入库前的**统一人审门**。
> **权威来源**：红线定义 = [`GDD.md`](../../GDD.md) §2.4；美术侧细则 = [`02-art-direction.md`](02-art-direction.md) 历史敏感度节。
> **使用方式**：每批新内容 PR 描述里附本 checklist 逐条勾选结果；任一条不过 = 内容打回，不得"先合再改"。
> **状态**：2026-08-30 由空壳落地（M2.0 债务清偿，GAME-SOP §3 敏感度红线执行件）。

## 1. 敌对 NPC 命名（每条必查）

- [ ] 按职能命名：占领军 / 伪警 / 特务 / 帮派——不出现现实部队番号、真实人物姓名。
- [ ] 不写"日本兵"等直接族群指称 + 负面刻板的组合；制服可识别、标签职能化。
- [ ] 民间人士（茶馆掌柜 / 报童 / 舞女 / 船夫）中性化处理，不承担道德标签。
- [ ] 玩家方 = 无名线人（只有代号），不出现真实抵抗组织名称。

## 2. 叙事与文案（每批抽 3 条可追溯）

- [ ] 每段文本能回答：谁、在 1937 孤岛期的哪里、为什么是电话指令（GAME-SOP §3 定义）。
- [ ] 不出现已砍任务名（夜航船 / 墨水账），不复活被 GDD §0.5 否决的内容。
- [ ] 暴力表现对齐 HM 范式但不附加族群 / 身份羞辱性描写。
- [ ] 无现实政治口号、无当代政治影射；时代限定 1937.8–11 淞沪→孤岛期。

## 3. 美术元素（新 sprite / 截图必查）

- [ ] 旗帜 / 臂章 / 制服用"可识别职能"的抽象符号，不用历史实物复刻。
- [ ] 场景道具（招牌 / 报纸 / 海报）文字不出现真实媒体名与政治标语。
- [ ] 调色板只从 `src/core/data/palette.ts` 取色（B21 教训：新色先进调色板）。

## 4. 截图 / 展示文本（发布面必查）

- [ ] `smoke/*.png` 命名与任何 README / JOURNEY 引用不含族群 / 政治词汇。
- [ ] 对外展示文案称"1937 上海孤岛时期的虚构暗战故事"，不称历史还原。

## 5. 流程约定

- [ ] PR 描述列出新旧文本对照（GAME-SOP §3 文本出口规则）。
- [ ] 审查人：作者自审 + 另一并行会话交叉审（并行会话 ack 走 11 号 §3.2 精神）。
- [ ] 打回项登记到 PR 描述，不进 BUGS（非代码缺陷）。
