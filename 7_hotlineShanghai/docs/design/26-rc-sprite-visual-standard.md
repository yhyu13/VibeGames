# 26 — RC × Sprite 视觉标准(v3.4 定稿)

> 用户指令(2026-08-10):"we need come up with visual standard while working together with RC"。
> 本文是 RcPresenter / SceneManager / intro 精灵三方协作的**绑定标准**:任何新光照体、新遮挡体、新精灵进 intro 场景前,按此对表。改数值前先读本文件,再改代码注释里引用的 v3.x 条目。

## 0. 总原则

RC(radiance cascades)是**唯一的光场真相**。2D canvas 只负责画"物体长什么样";所有"光怎么走、影怎么落"由 RC 的 occlusion / emission 两张平面决定。两边一旦各画各的光,就会出现 v3.2 之前的光环盒、双锥、洗白灰场等伪影。

**SDF 以视觉足迹为准**:遮挡体大于视觉 → 多吞光(黑窟窿);小于视觉 → 漏光(光穿过物体)。两者不可兼得时,宁小勿大(漏光比黑窟窿更不刺眼)。

## 1. 遮挡(occlusion)绑定表

| 场景元素 | SDF 遮挡体 | 依据 |
|---|---|---|
| 墙 `#` | 整格黑块 `scale×scale` | 墙是房间边界,满格遮挡 |
| 掩体 `X`(沙袋) | **视觉足迹** `0.88×0.72u`,居中于格心(偏移 +0.06/+0.14) | 与 `SceneManager.drawSandbag` 的绘制矩形逐像素对齐 |
| 玩家 / 巡逻兵 | **脚底接触影圆盘 r = 0.22u**,锚点在精灵脚底(position) | v3.4 取代 0.32×0.68u 竖胶囊:俯视精灵的"高度"是站立表现,不是体块;胶囊会在脚下画出违和竖长黑块 |
| 油灯(活) | 圆盘 r = max(2px, 0.13u) | 灯座玻璃罩的实际占地面积 |
| 房间外虚空 | 全黑 | 静态缓存先填黑再开白房间矩形,防止光锥溢出房外 |

房间拓扑(`room.id + 尺寸 + tiles`)做 key 缓存静态层;动态层(灯座、角色)每帧叠加在缓存副本上。

## 2. 发射(emission)绑定表

| 光源 | 形状 | 增益 | 备注 |
|---|---|---|---|
| 油灯 | 圆盘 r = max(3px, 0.2u) | pulse × **0.95** | ambient 降到 0.06 后,灯周围明暗差由灯本体承担(e2e 视觉门:intact−broken 亮度差 > 10) |
| 角色可读性底光 | 玩家 r=0.3u rgb(26,21,15);敌 r=0.28u rgb(24,22,18) | 固定 | 极暗暖盘,保证黑场中角色可辨;不参与 sim 光照判定 |
| 手电锥 | 实心扇形,弧 = `FLASHLIGHT_CONE_ARC_DEG`(50°),长 = 5u | **状态色**:巡逻绿 rgb(34,64,40) / 警觉黄 rgb(70,58,22) / 发现红 rgb(76,26,22) | 裁剪到房间内界;灯碎后继续扫射;远/近色带分界 = `VISION_NEAR_DISTANCE`(2.5u) |
| 近战挥击闪光 | 圆盘 r=0.4u,PAL_MUZZLE 色 | 0.35 + 0.65×(ttl/DURATION) | 随挥击 ttl 衰减 |

## 3. 曝光标准(修"enemy sight 过曝")

- **环境光** `RC_AMBIENT_INTENSITY = 0.06`(constants.ts)。旧值 0.18 × 3 cascade pass × lightScale 1.35 ≈ +0.24 平光,把房间洗成灰。showcase 参考值为 0.02;0.06 是"地板可读 + 阴影留得住"的折中。
- **手电锥实心扫描填充**(v3.5):逐像素 dot/perp 判定 + hypot 距离(无逐像素三角函数),取代距离环描线——环描在斜角下格点剪切留针孔,合成后读作抖动纹。
- **手电锥近场渐入**:`ramp = max(1, length × 0.16)`,增益 `min(1, distance / ramp)` —— 全增益发射从源头 1px 起跳会在敌人头部叠成过曝亮斑;渐入后头部只留可读性底光。
- **远/近色带**(v3.5):`distance ≤ VISION_NEAR_DISTANCE` 近带 ×0.7(= 必死区,柔),以外满功率(远带亮)——色带阶跃让玩家直接读出"多远会被秒发现"。
- **加法合成**(final.frag):`lit = base × mix(0.58, 1.0, illumination) + radiance × uLightScale`,`uLightScale = 1.35`。radiance 只携带光贡献;dither 只作用于光贡献。
- 每 cascade pass 的 ambient = `RC_AMBIENT_INTENSITY / RC_CASCADE_COUNT`(RcPipeline 每 pass 累加一次,不均摊就过曝)。

## 4. 2D / RC 分工(谁画什么)

| 内容 | 2D canvas | RC |
|---|---|---|
| 墙/地/家具/精灵本体 | ✅ | ❌ |
| 手电锥 telegraph | ❌(RC 激活时 `scene.rcActive=true` 让位) | ✅ emission 锥 |
| 光池、光晕、影 | ❌(v3.2 删除手绘光圈/霓虹光晕盒) | ✅ |
| 挥击扇形提示(楔形渐隐) | ✅ 玩法 telegraph,不是光 | 挥击闪光另算 ✅ |
| 警觉标记 ?/! | ✅ UI 叠加(头顶 −1.8u,深色描边)——**不是光**,且偏移必须按精灵实际高度算(v3.5 教训:−0.65u 是占位矩形时代的值,会画进 v2 精灵躯干里) | ❌ |
| 噪音扩散环(枪声/砸灯/呼叫/脚步/落地) | ✅ 玩法提示(听觉广播可视化):ttl 0.3s 扩张渐隐描边环,按 kind 分色——**不是光**,不进 emission(机制见 doc-27) | ❌ |
| 角色接触影 | ❌ | ✅ r0.22u 遮挡盘 |

判定口诀:**"光是 RC 的,形是 2D 的,玩法提示是 2D 的"**。

## 5. 新元素入场检查单

1. 它的视觉 footprint 是多少像素/u?→ SDF 遮挡体逐像素对齐(宁小勿大)。
2. 它发不发光?→ 发光则登记 emission(形状/增益/是否 pulse),并把同区域 2D 手绘光效删掉。
3. 它在不在房间内?→ 发射/遮挡都必须裁剪到房间内界。
4. 近场会不会糊脸?→ 锥形/长条形发射必须加距离渐入 ramp。
5. 跑 `npm run intro-polish:check` + `npm run e2e:playtest`(视觉门:油灯 intact−broken 亮度差 > 10)。
6. 抓三帧核对:全房 / 掩体特写 / 敌人+锥特写(参考 `smoke/rc-std-*.png` 抓法)。
