## 0. 系统性研究(Systemic Research)

### 0.1 名字解构:为什么叫 "Hotline Shanghai"

- **"Hotline"**:直接对位 *Hotline Miami*(2012, Dennaton Games)— 顶视角 + 一击必杀 + 节奏 + 面具 = indie 复古暴力美学的范式。
- **"Shanghai"**:1937 年 8 月 13 日淞沪会战爆发、11 月中国军队撤离上海,公共租界 / 法租界进入"孤岛"期(1937.11 - 1941.12)— 灯红酒绿 + 暗杀 + 地下抵抗 + 物资走私。**题材与"血战上海滩"(2003 欢乐数码)同源**:同为抗日背景、同为 1937 上海,但我们是顶视角像素暗战,不是第一人称光枪正面战场。
- **合成含义**:"Hotline Shanghai" = 一条打进来的电话(像 Hotline Miami 那种匿名指令),让你去暗杀孤岛里某个穿军装 / 制服的人 — 复古 8-bit 美学 + 真实光影 + 反法西斯题材。

> **风险声明**:经 2026-08-08 网络检索(Steam / itch.io / 163 / 百度 / Google),"Hotline Shanghai" 暂无同名游戏发布,可安全用作 vibe game 项目名。如未来发现重名,优先级 = 本文档(原创) > 第三方同名作品。

### 0.2 参考作品矩阵(Reference Matrix)

| 维度 | 参考 | 借鉴点 | 警惕点 |
|------|------|--------|--------|
| **核心循环** | Hotline Miami 1/2(2012/2015) | 顶视角 + 一击必杀 + 节奏 + 任务式(电话指令)+ 面具 + **死后快速重开** | 不要做"难度峰值"设计,我们要"快感和漂亮" |
| **操作模式** | Hotline Miami(F 近战/远程切换、攻击键、3 拾取/投掷、右摇杆瞄准) | **F 切换近战/远程 + 单键攻击 + E 拾取/投掷 + 鼠标瞄准** 对齐为键鼠版 | 键鼠 ≠ 手柄,右摇杆 → 鼠标 |
| **武器系统** | Hotline Miami(35 种:小刀/棒球棍近战 + 手枪/霰弹/冲锋枪远程 + 投掷) | 武器分近战 / 远程 / 投掷三类;**v1 锁 8 件、里程碑铺到 35** | 每件必须有显著手感差异,拒绝数值堆砌 |
| **面具系统** | Hotline Miami(25 种动物面具,如虎头加速处决、猪增加枪械) | 面具 = 永久战利品 + 改变玩法风格;**v1 锁 6 个、里程碑铺到 25** | 我们用 1937 孤岛意象(戏子 / 帮派 / 帮工 / 茶馆 / 蒙面义士 / 舞女)替代动物 |
| **历史题材** | 血战上海滩(2003)+ 八百(2020)+ 战上海 | 1937 上海抗日做背景(淞沪会战 / 四行仓库 / 苏州河 / 外滩) | 我们做顶视角孤岛暗战,不做光枪正面战场;历史敏感度见 §2.4 |
| **像素美学** | Hotline Miami 8-bit 风(其实是非纯像素,而是 neon flat) | 高对比 + 配色强 + 像素粒度 + 顶部俯瞰 | 我们用 16×16 像素 sprite,房间 tile-based |
| **顶视角射击** | Enter the Gungeon / Nuclear Throne | 走位 + 翻滚 + 房间刷怪 | 武器 / 弹道丰富度要够;不做 Roguelike 永久死亡 |
| **音频合成** | Hotline Miami 电子 synth 风格 + Web Audio 程序化 | 80s 复古电子 + 程序化合成;HM 的"电话 + 打字机"叙事音 | 中文配音成本高,我们用打字机文本 + 短合成音 |
| **光影算法** | 2D Radiance Cascades(`radiance-cascades-demo` C++/Raylib) | 真 2D GI + 软阴影 + 光线级联 = 顶视角氛围的天花板;**probe 结构 / JFA / cascade merging 全部按 demo 实现** | RC 是新算法,WebGL2 移植门槛高;必须给 RC 加 dither 回压 |
| **架构** | C.A.T(4_chunbai / 5_gamejam_1 / 6_patapong3D 验证) | core 平台纯净 / engine 平台适配 | RC 管线放 engine,不放 core(core 不知道 WebGL) |

### 0.3 同名风险扫描(Naming Risk Scan)

- ❌ "Hotline Miami"(Dennaton Games)— 单词不同,不易混淆
- ❌ "Hotline Miami 2: Wrong Number"(Dennaton Games)— 同上
- ❌ "血战上海滩"(欢乐数码, 2003)— 题材相关但完全不同的游戏(光枪 / 第一人称 / 正面战场)
- ❌ "Hotline Shanghai"(2026-08-08 网络检索)— **未注册**,安全
- ✅ "Hotline Shanghai / 热线上海" = 可安全用作 vibe game 项目名

### 0.4 设计决策的"为什么"摘要(Why This Design)

| 决策 | 替代方案 | 取舍 | 理由 |
|------|----------|------|------|
| **2D 像素 + 真 RC 光影** | 3D 写实 / 2D 纯贴图 / 2D 假 additive light | ✅ 取 | RC 是 2D 像素氛围的天花板;假光会毁了 1937 弄堂的"灯下黑"质感 |
| **任务式(电话指令)** | Roguelike / 沙盒 | ✅ 取 | Hotline Miami 范式;玩家 30-60s 一局,适合 vibe game 体量 |
| **一击必杀** | 血量系统 / 难度梯度 | ✅ 取 | Hotline Miami DNA;节奏感全靠一击 |
| **F 切换近战/远程** | 单独近战键(RMB)+ 单独远程键(LMB) | ✅ 取 | HM 原版操作 = F 切换 + 单攻击键;切换制造"拔刀/拔枪"节奏张力(v3:硬直 0s,节奏靠音效不靠硬直) |
| **空手 = 拳头,投掷仅 E 长按** | 空手 LMB 也投掷 / 双入口并存 | ✅ 取 | HM 空手攻击键是拳头;投掷唯一入口 = E 长按 0.25s,输入系统少一条分支、好教 |
| **程序化资产 + intro curated PNG 例外** | 全量外部资产 | ✅ 取 | 用户明确批准仅 intro 精选 PNG；批准 manifest/hash + 确定性处理脚本限制范围，音频/地图仍程序化 |
| **6 面具 → 铺 25** | v1 就做 25 个 | ✅ 取 | v1 范围控制;每个面具效果必须显著,25 个走里程碑 |
| **8 武器 → 铺 35** | v1 就做 35 个 | ✅ 取 | 同上;先做 4 远程 + 2 近战 + 2 投掷 |
| **C.A.T 架构** | 单文件 mvp | ✅ 取 | RC 管线太重,必须分模块;沿用 4_chunbai 验证 |
| **淞沪会战 + 孤岛暗战** | 纯孤岛期(1937.11 后) | ✅ 取 | 任务 1-3 在孤岛期;隐藏任务 4 放"淞沪会战尾声"做背景高潮 |
| **历史敏感度:反法西斯,不写特定族群刻板** | 简单阵营化 | ✅ 取 | 主题"反侵略"而不是"反某族" — 把日军写成"穿军装占领军",不写负面刻板 |

## 0.5 v3 Reset Acknowledgement(2026-08-09)

> **触发**:2026-08-09 用户判决"视觉 clunky + 移动失效",关卡 / 场景 / 移动整体移除并归档(B33)。
> 评审结论:这是**设计判决** —— 代码只是忠实实现了有问题的设计;v2 文档不能假装设计还活着。

### 0.5.1 v2 错在哪(命名,不回避)

1. **viewport 单位错了**:32u×18u = 假设屏幕恒为 1920×1080;13" 本 / 1440p / 4K / 浏览器缩放时画面跳变,小房间大量 void(B11)。
2. **输入手感预算错了**:M1.1 用 2-3 天做"移动 + F 切换硬直",而 HM 的手感是以年计的;首次有人真正摸到枪要等到 M1 末,这是坠崖式排期。
3. **RC 当装饰用**:B24/B27/B28 的"过曝 ↔ 全黑"参数震荡和 addLampGlow 假光是同一件事 —— RC 没有承担机制职责,团队在用手调常量补视觉,而常量补不了设计。
4. **范围超卖 3-5×**:4 周单人非 jam 排 4 任务 + 8 武器 + 6 面具 + 评分 + BOSS + RC 全管线,是幻想。

## 1. 高概念(High Concept)

- **Genre**:顶视角动作射击 / 任务式 / 一击必杀 / 复古 8-bit 像素
- **Tension 轴**:**不是"打不打得过",而是"每开一枪之后,整个世界会怎么亮起来"** — 枪火点亮整个弄堂、暴露你、逼你换位置、霓虹招牌在远处渗光、油灯投出软阴影(v3:光同时是机制 —— 灯下无敌 / 暗处可杀,RC 从"会亮起来"变成"敢不敢亮起来")
- **Tone**:1937 上海抗日 + 复古电子 + 暗战紧张 — "你是电话那头的影子"
- **玩家扮演**:上海地下抵抗组织的一名"线人",没有名字,只有代号
- **一句话**:Hotline Miami 手感,1937 上海,**2D RC 让每颗子弹都点一盏灯 —— 也是敌方的护甲**(v3 整合,详见 [docs/design/09-blindside-integration.md](docs/design/09-blindside-integration.md))。

## 2. 世界设定(World Setting)

### 2.1 时代:1937 年 8 月 13 日淞沪会战 → 11 月孤岛期(1937.11 - 1941.12)

- **1937.8.13** 淞沪会战爆发,八一三事变;中国军队在闸北 / 罗店 / 四行仓库浴血 — 我们的背景起点。
- **1937.10 底 - 11** 四行仓库八百壮士、苏州河畔灯火围观;11 月中国军队撤离上海,公共租界(虹口 / 杨树浦)被占领军接管,法租界成为"孤岛"。
- **孤岛期**:法租界 / 华界边缘的弄堂 / 茶馆 / 舞厅 / 小报馆 / 私人诊所,物资紧张、特务横行、电话线繁忙。
- **活动范围**:法租界 / 华界边缘的弄堂、茶馆、舞厅、小报馆、私人诊所、黄浦江渡船、屋顶。

### 2.2 主要场景类型(Scene Archetypes)

| 类型 | 例子 | 光源特征 | 节奏 |

### 2.4 历史敏感度处理(冻结原则)

- 所有敌对 NPC 按**职能**区分(占领军 / 伪警 / 特务 / 帮派),不写"某族人"加负面刻板。
- 民间人士(帮派 / 平民)中性化、可合作;任务文本避免污名化。
- 背景是**反侵略叙事**:淞沪会战 / 四行仓库 / 孤岛抵抗都是中国近代史的正面记忆;BOSS 文案用"占领军长官 / 巡捕长"等可识别称谓。
- 美术评审前先文字评审;image_gen 参考图必须过 `07-sprite-gen-tasks.md §6` 的敏感度 checklist + Mavis 签核(v3,V8)。

## 3. 核心循环(Core Loop)

> **关键流程调整(v1.1,对照 HM 真机)**:HM 范式是 **"mask 选 → mission intro 大字显示 → 立即 play"**,**没有独立"任务简报"**环节。我们沿用这个范式,把 mask 选择和任务简报合并。
>
> **v3(2026-08-09)**:M1 无选任务 / 选面具屏 —— Title → 直接进单房间(B15);下面流程是 M2+ 形态,任务卡片从 4 张改为 2 张。

```
Title → Mission Select (4 任务卡片)
  ↓
  click 任务
  ↓
Mask Intro(左侧大角色立绘 + 右侧任务小预览 + 中间打字机 brief)
  - 持续 3-4s
  - 屏幕下方 "PRESS SPACE TO START" 闪烁
  ↓ Space
Room 1 (2-3 敌,教学) → clear → Room 2 (3-4 敌,新武器) → clear → Room 3 (4-5 敌,BOSS)
  ↓ BOSS kill
Score (S/A/B/C) → 评价大字 → 1.5s → Mission Select
```

- **单任务时长**:3-5 分钟(每房间 60-120s)
- **房间时长分布**:Room 1 = 60s 教学 / Room 2 = 90s 节奏 / Room 3 = 90-120s 高潮
- **游戏不暂停** — Hotline Miami 范式,死了从 Room 1 重来
- **任务间无 mask 选择**(HM 范式)— mask 是任务奖励,不是任务前选;不过我们允许在 mask intro 之前选一个**起始 mask**(默认"蒙面义士"),影响整个任务的玩法(死亡 → 1.2s → 重开,快速回到战斗)

### 3.1 房间内循环(Room Loop)

```
Enter Room (从门进入)
  ↓
Observe (RC 灯光先开,玩家看清房间)
  ↓
Engage (枪火 / 冷兵器 / 投掷)
  ↓
Search (捡武器 / 拾面具)
  ↓
Exit (从门出去)
```

## 4. 核心机制(Core Mechanics)

### 4.1 移动 / 战斗(基础)— 按 Hotline Miami 操作对齐

## 5. "RC 光影" — 本项目唯一独特性(The RC Layer)

> **v3 关键转向(2026-08-09 整合)**:RC 不再仅是"光照氛围"的视觉层 —— **RC 是 *机制警觉***。
> Hotline Miami 让你 *嗨*;Hotline Shanghai 让你 *听见* 1937 上海弄堂里每颗子弹点亮一盏油灯的声音 — 用真 2D Radiance Cascades。
> **而那盏油灯,是敌方的眼睛**(灯亮=警觉、灯灭=半盲可杀,详见 §12 + [09](docs/design/09-blindside-integration.md))。
>
> 所有 RC 灯光**必须**在 game state 变化(开火 / 油灯 / 爆炸 / 拆灯)的同一帧触发,且**全部在 TDD §3.5 性能预算内**(v3 加 0.2ms 给 `glReadPixels` 8×8 downsample 读,新总预算 9.7ms / 硬上限 15ms)。

### 5.1 RC 光源清单(Light Sources)

8 类光源(颜色 / 强度 / 半径 / TTL 全部冻结在 **TDD §4.4.7**,本表不重复):

| 光源 | 触发 | 角色 |
|------|------|------|
| **枪火** | 远程开火瞬间 | 瞬时暖橙,点亮局部 |
| **爆炸** | 手雷爆炸 | 瞬时强光 |
| **油灯** | 静态道具 | 暖黄常亮,弄堂底色 |
| **霓虹招牌** | 静态道具 | 冷青脉动,远距渗光 |
| **探照灯** | 码头 / 屋顶 | 冷白旋转 |
| **手术灯** | 诊所 | 单盏冷白强光 |
| **舞厅旋转灯** | 舞厅 | 紫红 ↔ 青绿脉动 |
| **血溅** | 击杀瞬间 | 暗红,0.5s 淡出 |

### 5.2 RC 管线(按 radiance-cascades-demo 真实算法)

> **实现契约 = TDD §15**(6 阶段、probe 数学、uniforms、shader 清单,全部以 TDD 为准,按 demo 原式,不是示意)。

```
Frame N:
  1. prepscene  — 场景 occlusion + emission → seed 纹理
  2. prepjfa    — 种子编码
  3. JFA        — × log2(min(W,H)) passes(跳距减半,9 邻域)→ 最近 seed 距离
  4. distfield  — 距离场提取
  5. cascade × N(默认 3,ping-pong FB)— probe 采样 + 上级级联合并
  6. final      — scene + radiance + dither(4×4 Bayer)→ 屏幕
```

**关键点**:JFA pass 数 = `log2(min(W,H))`(1080p ≈ 10-11,不是固定 5);probe 数学(spacing / rayCount / interval 幂级数)与 `uPropagationRate` / `uMixFactor` 调参见 TDD §15。

### 5.3 像素颗粒回压(Dither Re-Press)

> 关键约束:RC 输出是连续渐变(soft shadow),会"吃掉" 16×16 像素粒度。
> 解法:final 阶段用 4×4 Bayer matrix 把 RC 输出 dither 回像素。

```
RC output (continuous 0..1) →
  threshold with Bayer[4×4] →
  quantized 0/1 →
  blend with original pixel color
```

效果:暗部仍保持 RC 的软阴影感,但每 4 像素有一个量化点,保留 pixel art 颗粒。

### 5.4 性能预算(Performance Budget)

- **完整预算表(冻结)= TDD §3.5**(RC 全管线 ≈9.5ms / 硬上限 15ms @1080p,§3.5 分项之和)。
- **降级路径(autopilot,冻结)= TDD §3.6**:连续超帧 → cascade 3→2 → half-res(540p)→ gi.frag 单 pass → RC_OFF 回退 base color;连续 120 帧达标自动恢复。

## 12. 光暗反制 — v3 整合核心层(The Light/Shadow Layer,2026-08-15 修正)

> **本章是 v3 的机制宣言**。一句话:**光=警觉开关,不是护甲。灯亮=敌人警觉开枪,灯灭=敌人半盲可安静击杀,亮处击杀=警报刷增援。**
> 本章是 GDD 层的摘要;**完整规范 = [docs/design/09-blindside-integration.md](docs/design/09-blindside-integration.md)**(包括 7 个 BLINDSIDE 子机制 / 脸谱重排 / RC 调整 / D1-D8 决策点)。本节改 = 必须同步改 09,反之亦然。
> **2026-08-15 机制修正**:推翻 v3.1 "光下无敌/暗中可杀"(光=护甲),改为"光=警觉开关"。旧判定(`ENEMY_INVULN_WHILE_LIT` / `LIGHT_SHIELD_THRESHOLD` / `canNeutralize` 光甲)已删除。

### 12.1 机制(Mechanic)

| 条件 | 玩家 | 敌人 |
|------|------|------|
| 灯 **亮**(`isAmbientDark() === false`) | 暴露(敌人看见即开枪) | 警觉:0.4s 瞄准电报 → 敌弹 OHK(可闪避/移动躲) |
| 灯 **灭**(拆灯,`isAmbientDark() === true`) | 可近身安静击杀 | 半盲:视锥/锁定 ×0.5,不再开枪 |
| **亮处击杀**(灯亮时击杀) | 触发警报 | 刷增援(`REINFORCEMENT_WAVE_SIZE=2` / 上限 `REINFORCEMENT_CAP=10`) |
| **暗处击杀**(灯灭时击杀) | 安静,不触发 | 无增援 |

### 12.2 玩家动词(verbs,无新键)

| 动作 | 输入 | 触发 |
|------|------|------|
| 拆灯 `lightSmash` | LMB(若最近可交互目标 = 灯,优先打灯) | `BREAKABLE_LIGHT_HP=2` 扣 1 |
| 拆灯(终) `lightDestroy` | LMB 续击 | 灯移除,`invalidateLight`,RC 下一帧重算 |
| 投灯 `throwAtLight` | E 长按 0.25s + 鼠标指向灯 | 投出当前武器,落地为临时光源 1.5s |
| 闪灯 `flash` | 空手 LMB 双击(仅 `lampmaker` 面具) | 脚下生 0.4u 光池 0.5s |
| 按灯 `hold` | Shift + 朝灯 0.4s(仅 `lampmaker`) | 灯切换闪烁模式(强度减半) |

> **LMB 优先打灯**:`aimTarget` 距离 ≤ 2.0u 且 aimTarget 是灯 → `lightSmash`;否则按玩家模式打敌(沿用 v2 LMB 行为)。**不引入新键**。

### 12.4 RC 调整(delta on v2 §15)

- 新增 2 个 uniform:`uLightShieldThreshold=0.30` / `uLightExposedThreshold=0.10`

- 性能降级新硬底:cascade=0 时 *屏蔽* lightSmash 机制 + 0.3s "停电" 动画 + HUD 提示(详见 TDD §3.6 v3)

### 12.5 v3 决策要点(决策 C1-C8,详见 09-§1)

- **C1**(最重要):RC = 机制护甲,不是装饰
- **C2**:敌人视野 = `lightAt()` 物理查询,不是 8u 60° 几何(基础敌人 8u 60° 沿用,但 *是否看得见* 受光影响)
- **C3**:武器表不变,语义加"全部武器可拆灯"
- **C4**:灯是可破坏道具,`BREAKABLE_LIGHT_HP=2`(印刷间硬灯 = 3)
- **C5**:面具 6 → 9,新增 `lampmaker` / `darkwatch` / `fortuneteller`(见 §4.4 + 09-§6)
- **C6**:F 切换硬直 0s(沿用 §0.5 V5)
- **C7**:评分 S-rank 加成 = 全拆灯(见 §4.6 v3)
- **C8**:RC 降级到 0 级 → 屏蔽 lightSmash 机制 + 停电动画
