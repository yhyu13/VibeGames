# Intro Scene Usability Fix Plan

> 日期:2026-08-10
> 来源:玩家实机反馈。移动与攻击通过；敌人视野、侦测、油灯识别和关卡闭环失败。

## 1. 问题与根因

| 玩家反馈 | 根因 | 修复目标 |
|---|---|---|
| 视野旋转太快 | 0.6Hz 配合 ±135° 摆幅,峰值约 509°/s | 改为可读的物理巡逻 + 慢速停顿扫描,峰值 ≤90°/s |
| 敌人看见玩家却不侦测 | 光锥掠过约 0.1s,警告要求连续 0.4s且离开即归零 | 增加发现记忆,短暂离开光锥不清零；正常固定位置可触发警告/死亡 |
| 灯和“鱼竿”奇怪 | 超大斜向晾衣杆与油灯/手电在同一焦点区 | 移除本场景斜杆 overlay；放大并描边油灯,加世界空间目标环与箭头 |
| 不知道如何关灯 | 近距、瞄准、两击合同只写在角落 HUD,miss 无反馈 | 进入范围显示“瞄准油灯 · LMB ×2”；首击改为“再击一次”；miss/命中反馈分离 |
| 关卡机制不工作 | 敌人不走、`D` 出口无效、测试依赖内部传送 | 敌人沿固定两点巡逻；拆灯→暗杀→到绿色出口才结算；E2E 只用键鼠 |

## 2. 冻结玩法流程

1. 出生后 1.0s 安全观察。
2. 巡逻兵沿 `(4,4) ↔ (7,4)` 往返移动；端点停顿并缓慢扫描。
3. 玩家进入手电锥后开始 0.55s 警告；离开后保留 0.25s 发现记忆再衰减。
4. 灯亮时攻击巡逻兵会被格挡。
5. 靠近油灯 2u 内并瞄准时出现世界提示；两次 LMB 摧毁油灯。
6. 灯灭后巡逻兵失去护盾；一刀击杀。
7. 击杀后不立即结算；绿色出口 tile 激活。
8. 玩家走到出口后进入结算画面。

## 3. 视觉修复

- 删除会被误认为鱼竿的 `laundry` 斜杆 overlay。
- 油灯显示尺寸提高到约 1.25 tile；加入暖黄色脉冲目标环。
- 油灯上方显示两格耐久标记；首击后变为一格。
- 出口未激活时保持暗红；击杀后变为绿色并显示“撤离”。
- 手电锥边缘降低噪声、增加稳定核心区；警告时由黄转红。
- HUD 只显示当前步骤,不一次塞入完整攻略。

## 4. 代码修改

- `Simulation.ts`:确定性双点巡逻、端点扫描、发现记忆、出口结算、目标派生位置。
- `types.ts`:增加当前目标/交互提示所需的最小 snapshot 字段。
- `SceneManager.ts`:删除斜杆、目标环、油灯耐久、出口状态、警告锥。
- `HUD.tsx`:按状态显示“找灯 / 再击一次 / 暗杀 / 撤离”。
- `combat-loop-check.mjs`:验证最大扫描速度、固定位置侦测、无提前结算、出口结算。
- `hotline-e2e.spec.js`:禁止修改 `window.__sim` 内部坐标,仅使用键盘和鼠标完成成功/失败路线。

## 5. 验收门

- 视野最大角速度 ≤90°/s；端点扫描停留 ≥0.8s。
- 玩家固定站在核心光锥内时,≤1.2s 出现警告,继续停留后死亡。
- 短暂离锥 ≤0.25s 不会清空警告。
- 油灯在 1280×720 截图中宽高均 ≥36px,且不与非交互装饰重叠。
- 两次正常鼠标点击完成 `HP 2→1→0`;首击后世界提示更新。
- 杀敌后 phase 仍为 `MISSION_PLAY`;到出口后才进入 `SCORE`。
- E2E 成功路线和死亡/重试路线只使用公开键鼠输入,零 console error。
- `npm run intro-usability:check`, `npm run intro-polish:check`, `npm run e2e:playtest` 全绿。

## 6. 非目标

- 不增加第二个敌人、武器或房间。
- 不恢复旧版多任务/面具/拾取系统。
- 不重做 RC 算法；本轮只修光锥表现和玩法权威状态。

## 7. 后续视野层设计

两区视野的冻结设计见 `docs/superpowers/specs/2026-08-10-commandos-two-zone-vision-design.md`。本轮加入 Shift sprint、远区疑心 `?`、近区发现 `!`、敌人 residual facing 与快慢移动分层；灯光仍只负责战斗护盾，不被 RC 反向驱动。
