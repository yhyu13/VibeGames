# 03 — FERRO (铁磁滴)

> **One line**: 你不是在走路——你是一滴被磁力弯曲的液态金属，把磁极钉在墙上，让自己沿着磁场线飞过去。

## 1. 命题证明 (thesis)

**"移动 = 塑形场"**。平台游戏的角色移动是输入→速度；这个游戏是输入→**场的拓扑**：你放下 N/S 磁极，磁场线实时重排，你的身体（一滴铁磁液）沿场线滑行。路不是地图给的，是你画的场。你可以**裂成两滴**分别走两条场线，再合并。

## 2. Intro Scene 规格

- **场景**: 一个 25m × 25m 的磁阱房间（四面墙是可钉磁极的金属板），中央横着一条 8m 宽的虚空裂缝（无地板）。
- **极致 case**: 裂缝上方唯一的通路 = 玩家在两侧各钉一个 N 极、房间顶一个 S 极，形成一条拱形磁弧——**身体拉成一条 6m 长的金属丝贴着磁弧荡过去**，身后留一串铁磁毛刺。
- **教学节奏 (≤60s)**: 地面滑行（场线直行）→ 钉第一个磁极（场线弯曲，身体跟着弯）→ 裂缝前学会"钉极-拉丝-荡过去"→ 过关。

## 3. 核心机制 (verbs + frozen numbers)

| Verb | 输入 | 行为 |
|---|---|---|
| 放磁极 | LMB (N) / RMB (S) | 把磁极钉在 8m 内任意表面（上限 3 个并存） |
| 滑行 | 被动 | 身体沿场线以 6-14 m/s 滑行（随场强） |
| 分身 | F | 裂成两滴（质量各半，独立受场），30s 内可合并 |
| 收回磁极 | Q | 逐根收回，场线重排 |

- 场强公式: `B = Σ k·pole/(r²)`（冻结）；身体是 1.2m 长的可拉长椭球（最细 0.1m 穿缝）。
- 危险: 场线交叉点 = 身体打结 = 死亡（解谜核心）。

## 4. 范围三分法

| 类别 | 内容 |
|---|---|
| **ship 范围** | 1 个 intro scene（磁阱房间）+ 放磁极 + 分身 + 2 个 seed 布局 |
| **数据冻结** | 磁极增强类型（超强极/时变极）、磁敌（铁屑兽） |
| **M2+ 路线** | 多房间、磁极商店、铁屑兽 AI、三滴分身 |

## 5. 美术资产 4 tier

- **Tier 1 MUST**: 磁阱房间、磁极钉（N 红 / S 蓝）、铁磁滴（变形椭球 + 毛刺）、场线可视化
- **Tier 2 juice**: 钉极冲击波、拉丝变形、分身粒子、合并回弹
- **Tier 3 装饰**: 房间外的深空、金属板接缝、低鸣环境音
- **Tier 4 可选**: 场强 HUD 矢量场小窗

## 6. Three.js 技术计划（零 Tripo，全程序化）

- 几何: 全部程序化（房间 = box，磁极 = 锥体，铁磁滴 = `SphereGeometry` 顶点置换出毛刺）。
- **场 sim**: core 纯函数 `fieldAt(pos)`（解析场叠加，确定性）；身体 = 沿场线的质点积分 + 拉长（弹簧模型，8 个节点）。零物理引擎。
- **RT 收益 ★★**: 液态金属是 Tier 2 的真镜面——毛刺身体反射整个房间。
- 预算: 60fps / ≤ 20 draw calls / 场线渲染 = 单条 TSL line（≤ 8 条）。

## 7. P0–P7（MGP ≈ 5.5–6 天）

P0 解析场 + 场线积分 → P1 磁阱房间 → P2 沿场线滑行 → P3 钉极 + 场线重排 → P4 分身/合并 + 拉丝变形 → P5 打结死亡 + 重生 → P6 渲染（毛刺位移 + RT 金属反射）→ P7 HUD（磁极数/场强）+ playtest。

## 8. "完美"定义（4 维）

- **视觉**: 第一次拉丝荡过裂缝时"哇"；毛刺尖端有金属高光；场线如丝带呼吸。
- **手感**: 钉极响应 <50ms；场线滑行有惯性但可预测；打结死亡前有 0.3s 预警（场线变红）。
- **性能**: 60 FPS @1080p；场积分 ≤ 1ms/frame；启动 ≤ 1s。
- **可重玩**: 2 个 seed 均过；最少磁极数通关 = 分数。

## 9. 风险 + 先例

- **最接近的先例**: Gravity Ghost（2D 引力拖拽）、Teslagrad（2D 磁极）——差异：3D、液态身体变形、分身、场线即路径。
- **风险**: 场线积分在磁极附近发散（r→0 奇异）→ 缓解：r < 0.5m 内场强 clamp + 防打结软碰撞。
