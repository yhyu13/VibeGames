# 09 — JENGA REACH (拆塔攀)

> **One line**: 你困在一座 40 层的积木塔底，塔顶才是出口——而你的唯一工具是一根意念钩：抽塔。每抽一块，塔就倾斜一分；你踩着塔的废墟向上爬，直到你亲手拆掉自己脚下的世界。

## 1. 命题证明 (thesis)

**"破坏即建造"**。Noita 的物理是"烧穿地形的工具"；这个游戏把物理作为**垂直叙事**：塔的结构强度 = 你的攀爬路线。抽掉塔底的块，上层会倾斜 15°、形成斜坡；抽错一块，塔腰塌方，把出口埋掉。**你在和物理谈判**——每抽一块都是"这一块塌下来能送我上几层？"的赌局。

## 2. Intro Scene 规格

- **场景**: 一座 40 层 × 12m 见方的积木塔（每层 3 块砖错缝叠放），出口在塔顶的平台，玩家在塔底。
- **极致 case**: 教学后的关键一跃——抽掉第 3 层的支撑砖，**塔身整体倾斜 15°，一整面墙变成 45° 斜坡**，玩家踩着正在下滑的砖块向上狂奔 3 秒，在塔彻底散架前跳上第 8 层的悬挑。身后 20 块砖轰然落地。
- **教学节奏 (≤60s)**: 学抽块（塔身轻晃）→ 抽支撑砖（塔倾斜，理解因果）→ 踩倾斜面借力 → 在倒塌的倒计时里上攀。

## 3. 核心机制 (verbs + frozen numbers)

| Verb | 输入 | 行为 |
|---|---|---|
| 抽块 | 准星 + LMB | 意念钩抽出一块砖（0.3s 蓄力），砖块成自由刚体 |
| 走/跳 | WASD / Space | 8 m/s，跳 11 m/s；倾斜面上跑会滑（摩擦 0.6） |
| 借力 | 被动 | 抽块时站在相邻砖上 = 被轻微抛起（+1.5 m/s 反冲） |
| 稳定度 | 塔结构条 | 抽错块 → 塔塌方（区域性），塌方 3 次 = 塔全毁 = 死亡 |

- 物理: 120 块砖的刚体堆叠（冻结砖数）；每块砖 = 0.5m³ 箱体，重 10kg。

## 4. 范围三分法

| 类别 | 内容 |
|---|---|
| **ship 范围** | 1 个 intro scene（40 层塔）+ 抽块 + 借力 + 1 个 seed（固定错缝砖序） |
| **数据冻结** | 塔型变体（金字塔塔/斜塔）、异形砖（球砖/冰砖） |
| **M2+ 路线** | 多塔、物理弹射器、Boss = 会自己抽块的塔 |

## 5. 美术资产 4 tier

- **Tier 1 MUST**: 积木塔（120 砖 `RoundedBoxGeometry`）、意念钩准星、玩家剪影、塔顶出口
- **Tier 2 juice**: 抽块尘雾、倾斜吱嘎声、塌方砖雨、借力弹跳
- **Tier 3 装饰**: 塔外云海、风从砖缝穿过的声音
- **Tier 4 可选**: 塔结构条 HUD、砖块计数

## 6. Three.js 技术计划（零 Tripo，全程序化）

- 几何: 全部程序化（120 × `RoundedBoxGeometry` 砖，InstancedMesh + 刚体位姿流）。
- 物理: **自研轻量刚体堆叠**（核心：静态摩擦 + 重力 + 砖间 4 点接触约束，120 体确定性模拟 @60Hz）——不引入 Rapier，保持 core 纯；若抖动超预算，降级为"抽砖 → 预烘焙倾角动画"（Plan B，冻结在 TDD 风险节）。
- **RT 收益 ★☆**: 塔顶出口的灯火在砖面反射。
- 预算: 60fps / 120 刚体 ≤ 2ms / ≤ 15k tris。

## 7. P0–P7（MGP ≈ 5.5–6 天）

P0 刚体堆叠 sim（120 砖稳定）→ P1 40 层塔 + 出口 → P2 走/跳 + 倾斜面滑行 → P3 抽块 + 反冲借力 → P4 塌方连锁 + 稳定度 → P5 全毁死亡 + 重生 → P6 渲染 + 尘雾粒子 → P7 HUD + playtest。

## 8. "完美"定义（4 维）

- **视觉**: 第一次塔身倾斜 15° 的"活建筑"震撼；塌方砖雨有重量感。
- **手感**: 抽块蓄力 <0.3s；借力弹跳可预测；塌方前 1s 有砖缝挤压预警声。
- **性能**: 60 FPS @1080p（120 刚体稳定）；无穿模可见；启动 ≤ 1s。
- **可重玩**: 最少抽块数登顶 = 分数；塔倒计时速通。

## 9. 风险 + 先例

- **最接近的先例**: Noita（2D 像素物理破坏）、Besiege（物理造物）——差异：3D 平台攀爬 + 结构稳定度资源 + 破坏即造路。
- **风险**: 刚体堆叠抖动/穿模 → 缓解：4 点接触约束 + 1/60 固定步 + Plan B（预烘焙倾角动画）。
