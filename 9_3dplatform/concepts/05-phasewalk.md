# 05 — PHASEWALK (四相行者)

> **One line**: 世界有 4 层重叠——固/液/气/等离子四相同时存在于同一个空间，半透明地叠在你眼前；你只能踩与你同相的那一层，在空中换相就是换关卡。

## 1. 命题证明 (thesis)

**"4 个世界同时可见"**。Quantum Conundrum 的维度切换是"换屏"；这个游戏不同在于：**4 层永远同时渲染**（3 层幽灵态 15% alpha 叠加在实心层上）。玩家看到的是 4 份关卡的重影——解谜不是猜，是**对比 4 层找通路**。切相 = 脚下的实体切换，但视觉从不黑屏。

## 2. Intro Scene 规格

- **场景**: 一座 20m 高的四相塔（每层 5m），塔身是 4 层几何的叠加：固相石阶、液相管道、气相风洞、等离子电线。
- **极致 case**: 塔中层的一段**无石阶断口**——4 层同时显示时，画面 80% 是幽灵半透明几何：石阶断了，但液相管道穿过、气相风洞吹过、电线横跨。玩家要在坠落中连切 3 相：固（跳）→ 液（穿管）→ 气（乘风）→ 等离子（沿电线）一气呵成。
- **教学节奏 (≤60s)**: 出生在固相（3 层幽灵可见）→ 学会切相（站上液相关卡）→ 4 连切过断口 → 登顶。

## 3. 核心机制 (verbs + frozen numbers)

| Verb | 输入 | 行为 |
|---|---|---|
| 切相 | 1/2/3/4 键 | 无冷却；固=走石阶 / 液=穿栅栏+随管流 / 气=被风洞吹起 / 等离子=沿电线滑行 |
| 走/跳 | WASD / Space | 8 m/s；液相重力 ×0.6，气相 ×0.3 |
| 相弹 | 空中切相 | 切相瞬间动量守恒但重力换档——"相弹"是核心技巧（气→固 = 空中急坠） |

- 规则: 只有同相物体与你碰撞；不同相的敌人看不见你（但你看得见它的幽灵）。

## 4. 范围三分法

| 类别 | 内容 |
|---|---|
| **ship 范围** | 1 个 intro scene（四相塔）+ 4 相切换 + 相弹 + 1 个 seed |
| **数据冻结** | 相位敌人（固相卫兵/等离子火花）、相位叠加机关 |
| **M2+ 路线** | 多塔、相位商店、双相实体（半固半液）谜题 |

## 5. 美术资产 4 tier

- **Tier 1 MUST**: 四相塔（4 层几何 × 4 材质）、切相环 HUD、玩家剪影、4 相配色（固=砂岩金/液=蓝/气=白/等离子=紫）
- **Tier 2 juice**: 切相波纹（以玩家为圆心扩散）、相弹拖尾、幽灵层淡入淡出
- **Tier 3 装饰**: 塔外星空、相色氛围光
- **Tier 4 可选**: 相位罗盘、四相图鉴卡

## 6. Three.js 技术计划（零 Tripo，全程序化）

- 几何: 全部程序化（塔 = `RoundedBoxGeometry` 组合，管道 = `TubeGeometry`，电线 = `CatmullRomCurve3` 管）。
- 4 层渲染: 4 组 `Group`，非当前相 `material.opacity = 0.15`（depthWrite 关）——零 shader 成本；sim 只对当前相做碰撞。
- **RT 收益 ★☆**: 幽灵层在 Tier 2 里互反射（半透明 + 折射近似）。
- 预算: 60fps / 4 层 ≤ 30 draw calls / 每层 ≤ 8k tris。

## 7. P0–P7（MGP ≈ 5.5–6 天）

P0 4 层碰撞组 + 切换 → P1 四相塔场景 → P2 走/跳 + 固相 → P3 液/气/等离子 3 相行为 → P4 相弹 + 动量守恒 → P5 相位敌人占位 + 重生 → P6 幽灵层渲染 + 后处理 → P7 HUD（切相环）+ playtest。

## 8. "完美"定义（4 维）

- **视觉**: 进塔 10 秒内看懂"4 层重影"；相弹有明确的拖尾语言；幽灵层不干扰实体读图。
- **手感**: 切相 <50ms；相弹可预测（动量守恒直觉）；坠落重生 2s 内。
- **性能**: 60 FPS @1080p；4 层渲染稳定；启动 ≤ 1s。
- **可重玩**: 最少切相数通关 = 分数；相弹连击记录。

## 9. 风险 + 先例

- **最接近的先例**: Quantum Conundrum（切换维度换物理）——差异：4 层**同时可见**、空中切相、相弹。
- **风险**: 幽灵层视觉噪音 → 缓解：非当前相 alpha ≤ 0.15 + 只对玩家 6m 内渲染幽灵细节。
