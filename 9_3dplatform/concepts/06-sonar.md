# 06 — SONAR (声呐)

> **One line**: 世界是纯黑的，你是盲的——但你会发声。每一次 ping 是一圈声波涟漪，擦过墙壁的轮廓、平台的边缘，把你 2 秒的世界点亮给你看，然后重归黑暗。

## 1. 命题证明 (thesis)

**"可见度是资源"**。平台游戏把"看得见"当默认值；这个游戏把它变成弹药：高频 ping 短促清晰（8m，轮廓锐利），低频 ping 深远模糊（30m，一片灰雾）。**路线规划发生在黑暗里**——你记住 ping 过的地形，在黑暗中完成跳跃。恐怖 + 平台跳跃的杂交。

## 2. Intro Scene 规格

- **场景**: 一条 40m 长的深渊洞穴，出口在尽头的天光里（唯一可见的远景）。
- **极致 case**: 屏幕 **98% 像素纯黑**；每 2.5s 一次 ping 波纹，把洞穴照亮 2 秒——玩家在"看见→记住→盲跳"的循环里前进。最后一段 8m 深渊：ping 一次看清对面平台，然后闭眼跳。
- **教学节奏 (≤60s)**: 全黑（恐惧）→ 第一次 ping（轮廓显现，立刻理解机制）→ 学会"ping-记-跳"循环 → 盲跳过渊 → 天光出口。

## 3. 核心机制 (verbs + frozen numbers)

| Verb | 输入 | 行为 |
|---|---|---|
| ping | 空格（短按/长按） | 短按=高频（8m 锐利）/ 长按=低频（30m 模糊）；冷却 2.5s |
| 走/跳 | WASD / 空格组合 | 8 m/s，跳 11 m/s——跳跃必须凭记忆执行 |
| 回声记忆 | 被动 | 已 ping 过的区域保留 15% 亮度残影 8s |

- 无 HUD 地图——所有空间信息都在 ping 里。
- 敌人（数据冻结）: 声呐盲点怪——静止时隐形，移动时被你的 ping 波纹映出。

## 4. 范围三分法

| 类别 | 内容 |
|---|---|
| **ship 范围** | 1 个 intro scene（深渊洞穴）+ ping 双频 + 回声记忆 + 1 个 seed |
| **数据冻结** | 声呐盲点怪、回声陷阱（假回波） |
| **M2+ 路线** | 多洞窟、ping 升级（多频扫射）、敌人 AI |

## 5. 美术资产 4 tier

- **Tier 1 MUST**: 洞穴几何（无光照贴图——全靠 ping 波纹渲染）、玩家剪影（微光轮廓）、出口天光
- **Tier 2 juice**: ping 波纹（TSL 环形）、轮廓高亮擦边、盲跳成功音、黑暗回响音
- **Tier 3 装饰**: 水滴声、远处风声、低频环境嗡鸣
- **Tier 4 可选**: ping 冷却环 HUD、震动反馈

## 6. Three.js 技术计划（零 Tripo，全程序化）

- 几何: 全部程序化（洞穴 = 管状 `CatmullRomCurve3` + 噪声位移；钟乳石 = 锥体）。
- **ping 渲染 = TSL 环形 raymarch**: 从 ping 原点向全方向发射球面波（TSL compute，把距离场写进 visibility texture）——擦边越近越亮；**这本身就是一次轻量光线追踪**（球面射线 vs 场景 BVH，复用 `raycastBvh`）。raster 层降级 = 阴影贴图式球形投射。
- 预算: 60fps / ping 波纹 = 1 个 fullscreen pass / 洞穴 ≤ 20k tris。

## 7. P0–P7（MGP ≈ 5.5–6 天）

P0 球面 visibility 场（CPU 版）→ P1 洞穴场景 → P2 走/跳（盲操作手感）→ P3 ping 波纹 + 轮廓 → P4 双频 + 回声记忆残影 → P5 掉落深渊 + 重生 → P6 TSL ping 接线 + 后处理（极暗）→ P7 HUD（冷却环）+ 盲跳 playtest。

## 8. "完美"定义（4 维）

- **视觉**: 第一次 ping 让洞穴在 2 秒内显形 = 屏息时刻；盲跳成功的"凭记忆命中"爽感。
- **手感**: ping 响应 <50ms；黑暗中的跳跃判定宽容 +0.2m（看不见就得公平）；死亡重生 2s 内。
- **性能**: 60 FPS @1080p；visibility 场 ≤ 2ms；启动 ≤ 1s。
- **可重玩**: 最少 ping 数通关 = 分数（硬核路线）。

## 9. 风险 + 先例

- **最接近的先例**: Devil's Tuning Fork（2D 声呐跳跃）、Beyond Eyes——差异：3D 精确平台跳跃、双频 ping、回声记忆。
- **风险**: 全黑导致挫败感 → 缓解：教学节奏 ≤60s + 平台边缘自发光 2%（勉强可见的安全网）+ 可调亮度选项。
