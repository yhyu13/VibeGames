# 01 — SHADOWSTEP (影跃)

> **One line**: 影子是唯一的地面——你不能踩光，只能踩影；转动手里的灯，整个世界的地形就重写一遍。

## 1. 命题证明 (thesis)

**"光定义碰撞"**。大多数平台游戏的碰撞是几何的、静态的；这个游戏的碰撞是光的函数：`solid(cell) = 不被阳光照到`。这意味着**地形是玩家手里的资源**——转灯 15°，一堵墙就凭空出现；灭掉自己的火，脚下的地面会消失。光线追踪在这里不是画质，是**关卡物理本身**。

## 2. Intro Scene 规格

- **场景**: 一座黄昏庭院（约 30m × 20m），一座 4m 高的断头台阶横在中央，出口在断崖对岸。阳光以 12° 低角射入，庭院里只有 1 根 3m 灯柱 + 玩家手持的 1 盏小油灯（主角光源，可旋转）。
- **极致 case**: 傍晚斜阳下 **90% 的庭院地面处于阴影**——刚出生的玩家站在唯一的光斑上，周围全是"可走"的暗面，30 秒内玩家必须意识到"光斑是深渊，影子是地面"的颠倒世界观。
- **教学节奏 (≤60s)**: 出生在光斑（唯一不可走处）→ 走向阴影（发现可走）→ 遇到高台（发现转灯可以让影子搭桥）→ 用灯影搭桥越过断头台阶 → 抵达出口。全程 1 个房间、1 种敌人（无）、1 个新动词。

## 3. 核心机制 (verbs + frozen numbers)

| Verb | 输入 | 行为 |
|---|---|---|
| 走/跳 | WASD / Space | 8 m/s，跳 11 m/s（复用 PRISM LEDGE 手感表） |
| 转灯 | Q/E | 主角光源绕自己 ±90° 旋转；阴影带以 30°/s 扫过地面 |
| 灯油 | 资源条 | 光越亮耗油越快（常亮 ≈ 3 min 耗尽）；耗尽是"全暗"状态 |

- 碰撞查询：对每个平台 cell，从太阳/灯柱/油灯发射遮挡射线——**在影 = solid，在光 = intangible**。
- 玩家的灯只照亮半径 6m、锥角 120°——它既是"造地工具"也是"挖坑工具"（照到脚下的影子 = 自己掉下去）。

## 4. 范围三分法 (intro-scene-until-perfect §5.3)

| 类别 | 内容 |
|---|---|
| **ship 范围** | 1 个 intro scene（黄昏庭院）+ 转灯 + 灯油经济 + 3 个可重玩布局（seed） |
| **数据冻结** | 多光源类型（烛台/火把/月光）、敌人"逐光者"类型定义 |
| **M2+ 路线** | 多房间、灯油商店、逐光者 AI、移动光源（手持火把敌人） |

## 5. 美术资产 4 tier

- **Tier 1 MUST**: 庭院地板（受光/阴影双材质）、断头台阶、灯柱、油灯光锥（1 盏）、玩家剪影
- **Tier 2 juice**: 影子边缘"融化"过渡、转灯扫影、落坑粒子、灯油将尽的火光颤抖
- **Tier 3 装饰**: 黄昏天空渐变、远处剪影墙、环境音（虫鸣 + 火苗爆响）
- **Tier 4 可选**: 灯油 HUD 造型、开场 2 秒"光斑是深渊"字幕

## 6. Three.js 技术计划（零 Tripo，全程序化）

- 几何: 全部 `RoundedBoxGeometry`/`LatheGeometry`（庭院、灯柱、断台）；无外部模型。
- **碰撞场 = 光场**: core 层复用 `raycastBvh()`——对每块平台顶面采样点向光源做可见性测试，结果写入 `Uint8Array solidMap`；sim 每帧只重算"灯光扫过"的脏 cell（光源旋转时增量更新）。
- **RT 收益 ★★★**: Tier 2 光追管线的阴影射线**直接就是碰撞查询**——solidMap 由真实光追阴影生成，raster 层用 shadow-map 采样近似，两层同一份数据接口（`solidMapProvider`）。
- 预算: 60fps / ≤ 30 draw calls / ≤ 25k tris；solidMap 每帧更新 ≤ 512 cells。

## 7. P0–P7（MGP ≈ 5.5–6 天）

P0 光场碰撞求解器（static sun，CPU raycast）→ P1 庭院最小场景 → P2 走/跳 + solid/intangible 切换 → P3 转灯扫影 → P4 灯油经济 + 影子边缘 juice → P5 落坑/重生 + 失败反馈 → P6 渲染接线（双层管线 + 后处理）→ P7 HUD + 10 次端到端 playtest。

## 8. "完美"定义（4 维）

- **视觉**: 前 30 秒意识到"光斑是深渊"；影子边缘有融化过渡；黄昏长影的压迫感。
- **手感**: 转灯响应 <50ms；灯油耗尽不宣判死刑（全暗仍有 1 条逃生路线）；每次死亡 2 秒内重生。
- **性能**: 60 FPS @1080p；solidMap 增量更新 lastFrameTime < 16ms；启动 ≤ 1s。
- **可重玩**: 3 个布局 seed 都能通过；灯油余量与路线选择相关（快 = 省油 = 高分）。

## 9. 风险 + 先例

- **最接近的先例**: Contre Jour（2D 拖拽光线改地形）——差异：3D、光影即碰撞、光由玩家携带。
- **风险**: 影子抖动导致手感漂移 → 缓解：solidMap 滞后 100ms 平滑 + 影子边缘 0.3m 渐变带。
