# 12 — ORBITFALL (轨道坠)

> **One line**: 你不是在跳，你是在变轨——你是一颗绕着小星球转的小月亮，跳 = 沿切线推自己一把，质量 = 轨道半径；吃掉环上的陨石碎屑你会变重、轨道收缩，甩掉质量你会变轻、轨道扩张。平台跳跃 = 轨道力学。

## 1. 命题证明 (thesis)

**"跳跃 = 开普勒"**。Mario Galaxy 的星球引力是装饰（跳还是跳）；这个游戏把平台跳跃**真正换成轨道动力学**：你的速度永远沿轨道切线，唯一的操作是切向脉冲（跳）和质量变化（吃/吐）。**从内环到外环不是跳过去，是算好相位差推一把**——玩家在 30 秒内建立起"高轨慢、低轨快"的直觉。

## 2. Intro Scene 规格

- **场景**: 1 颗直径 10m 的小星球（你从它表面起步）+ 3 圈同心碎环（内环=3m 高、中环=6m、外环=12m），外环上是出口光门。
- **极致 case**: 从星球表面到外环需要 2 次变轨——先沿切线跳起进入内环轨道（**第一次真正失重绕行，星球在脚下滚过**），在内环上吃掉 3 块陨石碎屑（质量 +，轨道收缩，擦着星球表面掠过），再甩掉全部质量（轨道扩张 3 倍），像被弹弓甩出去一样飘向外环。**全程没有一次"跳"，只有两次"变轨"**。
- **教学节奏 (≤60s)**: 表面走（重力正常）→ 第一跳（进入轨道，世界观反转）→ 学会"低轨快/高轨慢"的相位直觉 → 吃/吐质量变轨 → 抵达外环。

## 3. 核心机制 (verbs + frozen numbers)

| Verb | 输入 | 行为 |
|---|---|---|
| 切向脉冲 | Space | 沿当前速度切向 +3 m/s（跳 = 变轨） |
| 吃碎屑 | 接触 | +质量，轨道收缩（半径 = k × 星球质量 / 你的质量） |
| 吐质量 | E | −质量，轨道扩张；质量是"弹弓"资源 |
| 环面行走 | WASD | 在环上沿轨道方向加/减速（±1 m/s，相位调整） |

- 物理: 纯开普勒（中心力 + 切向速度，冻结公式）；碰撞 = 环半径判定。
- 危险: 轨道过近 = 坠毁（贴地摩擦减速）；轨道外逸 = 飘出场景 = 死亡。

## 4. 范围三分法

| 类别 | 内容 |
|---|---|
| **ship 范围** | 1 个 intro scene（1 星球 + 3 碎环）+ 变轨 + 质量交易 + 1 个 seed |
| **数据冻结** | 双星系统（拉格朗日点谜题）、轨敌（逆向轨道碎片） |
| **M2+ 路线** | 多星球、霍曼转移教学关、Boss = 吞噬轨道的黑洞 |

## 5. 美术资产 4 tier

- **Tier 1 MUST**: 小星球（噪声球体）、3 碎环（环带粒子）、玩家小月亮、出口光门
- **Tier 2 juice**: 变轨切向火花、轨道虚线、质量变化的体形缩放、失重音
- **Tier 3 装饰**: 深空背景、远处星系、环带尘埃
- **Tier 4 可选**: 轨道参数 HUD（半径/周期）、相位钟

## 6. Three.js 技术计划（零 Tripo，全程序化）

- 几何: 全部程序化（星球 = `SphereGeometry` 噪声位移，环 = 粒子带，玩家 = 小球 + 拖尾）。
- sim: 纯开普勒积分（确定性、零物理引擎）；轨道虚线 = 圆锥曲线解析渲染。
- 镜头: 玩家固定在画面中心，世界绕玩家旋转（消除晕动）；星球从脚下滚过 = 相对运动错觉。
- **RT 收益 ★★**: 星球表面在 Tier 2 反射玩家（小月亮映在星球上）。
- 预算: 60fps / ≤ 20 draw calls / 环粒子 ≤ 2k。

## 7. P0–P7（MGP ≈ 5.5–6 天）

P0 开普勒 sim + 轨道判定 → P1 星球 + 3 环场景 → P2 表面走 + 切向脉冲 → P3 轨道绕行 + 相位调整 → P4 吃/吐质量变轨 → P5 坠毁/外逸死亡 + 重生 → P6 渲染 + 轨道虚线 → P7 HUD + 变轨 playtest。

## 8. "完美"定义（4 维）

- **视觉**: 第一次切向跳起、星球从脚下滚过 = 屏息时刻；变轨火花如彗星。
- **手感**: 变轨直觉 30 秒内建立（低轨快/高轨慢）；吃吐质量响应 <100ms；坠毁前有摩擦预警。
- **性能**: 60 FPS @1080p；开普勒 sim ≤ 0.2ms；启动 ≤ 1s。
- **可重玩**: 最少变轨次数抵达 = 分数；零质量损失完美线。

## 9. 风险 + 先例

- **最接近的先例**: Mario Galaxy（星球引力平台）、Kerbal（轨道模拟）——差异：平台跳跃完全轨道化、质量=轨道资源、相位即谜题。
- **风险**: 轨道手感难建立 → 缓解：教学 ≤60s + 轨道虚线全显 + 第一次变轨强制剧情化慢镜（0.3× 2s）。
