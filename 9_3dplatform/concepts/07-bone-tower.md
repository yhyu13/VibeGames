# 07 — BONE TOWER (骨塔)

> **One line**: 你是一具行走的骷髅，而骷髅的身体就是关卡建材——拆下自己的腿骨搭桥、卸下肋骨当梯子；你爬的每一米，都是用自己换的。

## 1. 命题证明 (thesis)

**"身体 = 资源 = 能力"**。平台游戏里血条是数字；这个游戏里血条是**你还有几根骨头**。拆骨不是扣血动画——拆腿 = 不能跳，拆臂 = 不能抓边，拆颅 = 视野收缩。**每次造路都是交易**：用能力的残缺换前进的路。回程把骨头捡回来 = 能力的回归。

## 2. Intro Scene 规格

- **场景**: 一座 15m 高的断裂骨塔（塔身本身就是巨兽骸骨），塔内一条 5m 断口无法跳跃，塔顶是出口。
- **极致 case**: 断口前——玩家 **当着自己的面拆下左腿骨，掷到断口中央，变成一座 1.5m 的骨桥**；单腿跳过断口的瞬间，屏幕短暂一黑（单腿跳的失衡感）；跳过去捡回腿骨接上，能力恢复。整个过程 20 秒，玩家永久记住"身体是耗材"。
- **教学节奏 (≤60s)**: 走路（完整骨架，动作轻快）→ 遇断口（跳不过）→ 提示拆骨 → 掷骨搭桥 → 单腿跳过 → 接回腿骨 → 登塔。

## 3. 核心机制 (verbs + frozen numbers)

| Verb | 输入 | 行为 |
|---|---|---|
| 拆骨 | E（选中部位轮换） | 拆下 1 根骨（腿/臂/肋/颅），变成长 1.2m 的平台/投掷物 |
| 掷骨 | LMB | 投出 8m（腿=桥 / 臂=钩爪点 / 肋=阶梯 / 颅=光源） |
| 接回 | 走到骨旁 | 能力恢复；全身共 6 根可用骨 |
| 走/跳 | WASD / Space | 完整=8 m/s 跳 11 m/s；缺腿=5 m/s 且跳 5 m/s 单脚失衡 |

- 缺颅时视野收缩 30%（FOV 60→42）+ 声音低沉——死亡倒计时 30s 内必须找回头颅。

## 4. 范围三分法

| 类别 | 内容 |
|---|---|
| **ship 范围** | 1 个 intro scene（骨塔）+ 4 部位拆骨 + 接回 + 1 个 seed |
| **数据冻结** | 骨制敌人（拆你的骨）、骨爆（以骨为弹） |
| **M2+ 路线** | 多塔、骷髅商店、多人骨（捡别人的骨） |

## 5. 美术资产 4 tier

- **Tier 1 MUST**: 骷髅玩家（6 根骨分段 rig）、骨塔（巨兽骸骨）、4 种骨平台、断口
- **Tier 2 juice**: 拆骨爆音 + 骨渣粒子、单腿失衡镜头、接回"咔哒"回正、缺颅红晕
- **Tier 3 装饰**: 塔外荒野、风吹骨隙的哨音
- **Tier 4 可选**: 部位 HUD 骨架图、失衡计

## 6. Three.js 技术计划（零 Tripo，全程序化）

- 几何: 全部程序化（骨 = `CapsuleGeometry` 双头球，6 段 hierarchical rig；塔 = 巨型肋骨 `TorusGeometry` 弧）。
- rig: 手写 6 节点层级动画（跑/跳/单腿/无臂摇摆）；骨平台 = 拆下的 mesh 直接转 collider（**mesh 即碰撞**，PRISM LEDGE 的 BvhBuilder 思路复用）。
- **RT 收益 ★☆**: 骨面在 Tier 2 有骨质次表面高光。
- 预算: 60fps / ≤ 25 draw calls / 6 骨 × 500 tris。

## 7. P0–P7（MGP ≈ 5.5–6 天）

P0 6 段 rig + 跑跳动画 → P1 骨塔场景 → P2 走/跳完整态 → P3 拆骨/掷骨/骨平台 → P4 部位残缺状态（缺腿/缺臂/缺颅）→ P5 死亡（无骨）→ P6 渲染 + 后处理 → P7 HUD（骨架图）+ playtest。

## 8. "完美"定义（4 维）

- **视觉**: 拆腿搭桥 20 秒内完成"身体是耗材"的传达；骨渣粒子有分量感。
- **手感**: 拆/掷/接 <50ms；单腿失衡有真实感但不恶心；全骨耗尽前 30s 预警。
- **性能**: 60 FPS @1080p；rig 动画 CPU 骨骼 ≤ 0.5ms；启动 ≤ 1s。
- **可重玩**: 最少拆骨数通关 = 分数；无颅速通挑战。

## 9. 风险 + 先例

- **最接近的先例**: Skeleton Boomerang（2D 骨制回旋镖）、Never Alone（身体部件谜题）——差异：3D、能力与身体部件强绑定、6 根骨经济。
- **风险**: "拆自己"挫败感 → 缓解：接回无惩罚 + 教学明确 + 缺颅倒计时给的紧张是趣味不是惩罚。
