# 08 — COMPASS ROT (罗盘坠)

> **One line**: 重力不再向下——它指向你手里罗盘的方向。转动罗盘，墙变成地板、天花板变成跑道；世界不动，是你的"下"在转。

## 1. 命题证明 (thesis)

**"重力是绕你的"**。Gravity Rush 的重力方向是"指向你瞄准的地方"；这个游戏更极端：**重力矢量绕玩家旋转，且带着动量**——转罗盘不是瞬移，是你的坠落在弧线上甩尾。墙上的奔跑是甩出来的：先向反方向坠，再在最低点猛转罗盘，把自己甩上墙面。**平台跳跃变成"甩鞭"**。

## 2. Intro Scene 规格

- **场景**: 一个直径 20m 的离心轮房——四周是 12m 高的环形墙，出口在轮顶。
- **极致 case**: 从地面到轮顶没有任何平台——玩家要**逆时针甩 3 鞭**：坠向右墙 → 转罗盘甩上右墙跑 2 步 → 再转，甩向天花板 → 再转，甩上轮顶。全程 12 秒，重力方向转了 360°，玩家的"上"变了 4 次。
- **教学节奏 (≤60s)**: 出生（重力向下）→ 转一次罗盘（重力指墙，直接"坠"到墙上，震撼）→ 学会"先坠后甩"→ 3 鞭登顶。

## 3. 核心机制 (verbs + frozen numbers)

| Verb | 输入 | 行为 |
|---|---|---|
| 转罗盘 | 鼠标滚轮 / Q/E | 重力方向绕玩家以 240°/s 旋转（不是瞬切） |
| 走/跳 | WASD / Space | 走 = 沿"当前地面"（重力反方向为地面）；跳 = 沿重力反向 11 m/s |
| 甩鞭 | 空中转罗盘 | 速度切向保留，重力换向——坠落弧线变向心弧线 |

- 物理: `v += g_dir × 30 dt`（g_dir 由罗盘角定义）；所有"地面判定" = 与 g_dir 相反的法线面。
- 镜头: 相机随 g_dir 滚动（roll），保证"下就是下"的直觉。

## 4. 范围三分法

| 类别 | 内容 |
|---|---|
| **ship 范围** | 1 个 intro scene（离心轮房）+ 转罗盘 + 甩鞭 + 1 个 seed |
| **数据冻结** | 重力陷阱（g 场区域）、离心敌人（贴墙怪） |
| **M2+ 路线** | 多轮房、罗盘升级（转速/多段）、双重重力区域 |

## 5. 美术资产 4 tier

- **Tier 1 MUST**: 环形轮房（镜面抛光墙）、罗盘（3D 悬浮指针）、玩家剪影、轮顶出口
- **Tier 2 juice**: 甩鞭时的重力线拖尾、落地冲击波、罗盘转动咔哒声、镜头滚动
- **Tier 3 装饰**: 轮房外的深空、抛光墙面的环境反射
- **Tier 4 可选**: 重力方向指示环 HUD、甩鞭连击计

## 6. Three.js 技术计划（零 Tripo，全程序化）

- 几何: 全部程序化（轮房 = 圆柱壳，罗盘 = 指针 + 环）。
- sim: 纯质点积分（g_dir 旋转 + 碰撞 = 面法线 vs g_dir 判定）——零物理引擎、确定性。
- 镜头: 相机 up 向量随 g_dir 指数阻尼（`1 - exp(-20·dt)`），避免翻滚眩晕。
- **RT 收益 ★★**: 抛光墙在 Tier 2 是全景镜面——甩鞭时看到自己的弧线反射。
- 预算: 60fps / ≤ 25 draw calls / 轮房 ≤ 10k tris。

## 7. P0–P7（MGP ≈ 5.5–6 天）

P0 可变重力质点 sim → P1 轮房场景 → P2 走/跳（重力向下）→ P3 转罗盘 + 重力换向 → P4 甩鞭动量 + 镜头滚转 → P5 落地/墙面判定 → P6 镜面墙渲染 + 后处理 → P7 HUD + 眩晕 playtest。

## 8. "完美"定义（4 维）

- **视觉**: 第一次"坠向墙壁"的失重感是屏息时刻；甩鞭弧线有丝绸般的重力线拖尾。
- **手感**: 罗盘响应 <50ms；甩鞭可预测（切向守恒直觉）；镜头滚转不引起眩晕（0 晕 playtest 通过）。
- **性能**: 60 FPS @1080p；重力 sim ≤ 0.5ms；启动 ≤ 1s。
- **可重玩**: 最少甩鞭数登顶 = 分数；连续甩鞭 combo。

## 9. 风险 + 先例

- **最接近的先例**: Gravity Rush（重力指向瞄准）、And Yet It Moves（2D 旋转世界）——差异：重力绕玩家旋转 + 甩鞭动量 + 世界不动。
- **风险**: 3D 眩晕 → 缓解：相机 up 指数阻尼 + 地平线参照物（轮房边缘光带）+ 可调滚转强度。
