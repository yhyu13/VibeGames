# 02 — ECHO FORGE (回声铸台)

> **One line**: 你的过去是实体的——每一次跳跃都留下一个 2 秒的回声，你可以把回声铸成真实的平台，站上自己的过去。

## 1. 命题证明 (thesis)

**"时间变成建材"**。Braid 的时间倒流是回看，Super Time Force 的时间叠加是合体；这个游戏的不同在于：**回声是物理实体**——你跳过的轨迹不消失，而是成为下一个跳跃的踏脚石。你一个人，就构成一支"自己踩自己"的接力队。

## 2. Intro Scene 规格

- **场景**: 一段 12m 宽的断崖峡谷，对面是出口祭坛。峡谷需要 4 连跳（总宽 14m，单人极限 6.6m）。
- **极致 case**: 一次通关的完整操作链 = 跳① → 铸回声①（半透明，浮在起点上空）→ 踩回声①再跳② → 铸回声② → 踩②跳③ → 铸③ → 踩③跳④ 抵达——**全程 4 跳里 3 跳踩在自己身上**，屏幕上一串 4 个渐隐的自己。
- **教学节奏 (≤60s)**: 跳①（发现空气里有自己的残影）→ 提示"按 E 铸回声" → 踩上去 → 重复 3 次过谷。1 个动词学会整局。

## 3. 核心机制 (verbs + frozen numbers)

| Verb | 输入 | 行为 |
|---|---|---|
| 走/跳 | WASD / Space | 8 m/s，跳 11 m/s，二段跳 9.5 m/s |
| 铸回声 | E | 把最近 2 秒的轨迹固化为实体平台（1.2m × 0.4m 平面，持续 6s 后消散） |
| 回声上限 | 3 个并存 | 第 4 个铸造时最旧的先消散——顺序即关卡解 |

- 回声平台可以被敌人踩碎、被自己再次经过时化为粒子（二段利用）。
- 回声带冲量：踩上时继承你铸造那一刻的水平速度（踩"高速回声" = 弹射）。

## 4. 范围三分法

| 类别 | 内容 |
|---|---|
| **ship 范围** | 1 个 intro scene（断崖峡谷）+ 铸回声 + 回声上限 3 + 2 个 seed 布局 |
| **数据冻结** | 回声分类（普通/冲量/碎块）、回声敌人类型 |
| **M2+ 路线** | 多房间、回声机关（压力板回声）、时间减速道具、boss = 你的全速回声 |

## 5. 美术资产 4 tier

- **Tier 1 MUST**: 断崖两侧地形、回声平台（半透明 + 边缘光）、玩家剪影、出口祭坛
- **Tier 2 juice**: 铸造成型粒子（点阵汇聚成面）、踩碎渐隐、跳跃拖尾、消逝音
- **Tier 3 装饰**: 峡谷雾、远景落日、风鸣环境音
- **Tier 4 可选**: 回声计数器 HUD 造型、残影调色

## 6. Three.js 技术计划（零 Tripo，全程序化）

- 几何: 全部 `RoundedBoxGeometry` + 平面回声板；无外部模型。
- **回放系统**: sim 固定 1/60 步（PRISM LEDGE 确定性纪律）——回声 = 60 帧/s × 2s 的状态快照环形缓冲；铸 = 把缓冲轨迹的落脚点段固化为 collider。确定性是零成本功能（skill：先垂直后水平）。
- 回声渲染: `MeshPhysicalMaterial` transmission 0.4 + emissive 边缘光；消逝 = opacity 动画。
- **RT 收益 ★☆**: 回声板在 Tier 2 里反射峡谷（半透明镜面）。
- 预算: 60fps / ≤ 20 draw calls / 3 回声 × 120 采样点。

## 7. P0–P7（MGP ≈ 5.5–6 天）

P0 回放环形缓冲 + 快照回放 → P1 峡谷最小场景 → P2 走/跳 + 二段跳 → P3 铸回声 + 踩踏碰撞 → P4 回声消散 + 成型粒子 → P5 掉落重生 + 顺序谜题 → P6 渲染接线 + 后处理 → P7 HUD（回声计数）+ 10 次 playtest。

## 8. "完美"定义（4 维）

- **视觉**: 第一次踩上自己时"哇"出声；4 连跳后一串自己渐隐的剪影留在视网膜上。
- **手感**: 铸键响应 <50ms；回声平台边缘宽容 +0.3m；踩碎不惩罚（重生 2s 内）。
- **性能**: 60 FPS @1080p；3 回声回放零 GC（环形缓冲）；启动 ≤ 1s。
- **可重玩**: 2 个 seed 均通过；"最速过谷"计时挑战（回声数量 = 分数）。

## 9. 风险 + 先例

- **最接近的先例**: Super Time Force（2D 合体回放）、Braid（倒流）——差异：回声是**实体建材**、可踩可碎、3D。
- **风险**: 回放漂移 → 缓解：固定 dt + 整数帧回放，禁止浮点时间插值。
