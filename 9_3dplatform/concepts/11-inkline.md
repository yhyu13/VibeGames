# 11 — INKLINE (墨线)

> **One line**: 路不是找到的，是画出来的——你拿着一支射墨笔，红墨是实心平台、蓝墨是弹床、绿墨是滑轨；在坠落的半空中连画三笔，把自己接住。

## 1. 命题证明 (thesis)

**"创作 = 移动"**。The Unfinished Swan 的墨是"揭示"；Splasher 的墨是"涂鸦敌人"；这个游戏的墨是**即时地形**：射出的墨点在空中凝固成 0.5m 的实体团块，连成线就是平台、堆成块就是阶梯。**玩家坠落的每一秒都是创造窗口**——先跳再画，画的形状就是落点。墨量有限：画得越省，跳得越远。

## 2. Intro Scene 规格

- **场景**: 一面 30m 高的空白断崖，崖顶是出口，崖底是虚空。崖面是巨大的"画布"（可吸附墨点）。
- **极致 case**: 中段一处 8m 的纯虚空——玩家纵身跃出，在**自由落体的 1.2 秒里连画 3 笔**：红墨接住第一落点、蓝墨弹起、红墨接住第三落点，全程不落地。回放里看到一条用墨点连成的折线，像书法。
- **教学节奏 (≤60s)**: 射第一笔（墨点凝固成平台，站上去）→ 学会"跳-画-落"循环 → 虚空自救三连画 → 登顶。

## 3. 核心机制 (verbs + frozen numbers)

| Verb | 输入 | 行为 |
|---|---|---|
| 射墨 | LMB（红）/ RMB（蓝）/ 滚轮（绿） | 射出墨点（0.5m 团块，30m/s 弹道），命中表面 0.2s 后凝固 |
| 走/跳 | WASD / Space | 8 m/s，跳 11 m/s；红墨=实心 / 蓝墨=弹起 1.5× / 绿墨=无摩擦滑轨 |
| 墨量 | 资源条 | 100 点，红 3/蓝 5/绿 2 每发；墨池会随收集光棱回充 |
| 擦除 | E | 清除 4m 内自己画的墨（回收 50%） |

- 墨点会干涸（40s 后崩解为粒子）——画的路是暂时的，规划要趁早。

## 4. 范围三分法

| 类别 | 内容 |
|---|---|
| **ship 范围** | 1 个 intro scene（空白断崖）+ 三色墨 + 墨量经济 + 1 个 seed |
| **数据冻结** | 墨敌（食墨兽）、墨型升级（喷射/扇面） |
| **M2+ 路线** | 多崖面、墨水商店、Boss = 会擦你墨的清洁灵 |

## 5. 美术资产 4 tier

- **Tier 1 MUST**: 断崖画布、三色墨团块（球体簇）、射墨笔准星、玩家剪影、崖顶出口
- **Tier 2 juice**: 墨点凝固波纹、弹床回弹音、擦除粒子、干涸崩解
- **Tier 3 装饰**: 水墨天空（渐晕）、笔触风声
- **Tier 4 可选**: 墨量毛笔 HUD、三连画 combo 计

## 6. Three.js 技术计划（零 Tripo，全程序化）

- 几何: 全部程序化（崖 = 平面，墨团 = 3-5 个 `SphereGeometry` 簇 + 表面吸附方向）。
- 墨碰撞: 凝固后的墨团 = 动态 collider（半径 0.5 球）写入场景；sim 的碰撞数据结构支持运行时增删（球体集 + 稀疏 grid）。
- **RT 收益 ★☆**: 湿墨在 Tier 2 有真实光泽反射（roughness 0.15）。
- 预算: 60fps / ≤ 120 个墨团并存 / 墨渲染 InstancedMesh 1 draw call。

## 7. P0–P7（MGP ≈ 5.5–6 天）

P0 动态球体碰撞集 → P1 断崖画布场景 → P2 走/跳 → P3 射墨 + 凝固 + 三色行为 → P4 墨量经济 + 擦除 → P5 干涸 + 坠崖重生 → P6 墨团渲染 + 后处理 → P7 HUD + 三连画 playtest。

## 8. "完美"定义（4 维）

- **视觉**: 空中三连画后墨点折线如书法；湿墨有高光；干涸崩解有水墨味。
- **手感**: 射墨弹道直觉（30m/s 直线）；凝固 0.2s 可预测；自救窗口（1.2s 坠落）公平。
- **性能**: 60 FPS @1080p；120 墨团稳定；启动 ≤ 1s。
- **可重玩**: 最少墨点登顶 = 分数；无蓝墨硬核路线。

## 9. 风险 + 先例

- **最接近的先例**: The Unfinished Swan（射墨揭示世界）、Splasher（2D 墨）——差异：3D 即时地形、三色墨物理、墨量经济。
- **风险**: 空中自救容错窄 → 缓解：坠落判定前 0.3s 的"墨点吸引"（准星 2m 内墨点自动吸附成落点）。
