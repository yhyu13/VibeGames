# GDD — Kerr 旋转黑洞 (11_blackhole)

## 一句话

一个基于 **Kerr 测地线逐像素光线追踪** 的旋转黑洞引力透镜实时可视化：完整的爱因斯坦环、帧拖拽（frame-dragging）导致的不对称 D 形影子、被拖拽的吸积盘、光子环与多普勒束流的星际穿越式画面，纯 Web 实时渲染。史瓦西（自旋 â=0）是其中 â→0 的特例。

## 体验目标

打开页面即见一颗带吸积盘的黑洞。用户可拖拽旋转相机、滚轮缩放、切换是否开启引力透镜、是否显示吸积盘，并实时调节黑洞质量、**自旋 â**、盘温度/亮度、星空密度、辉光、曝光、测地线步数等参数。HUD 依据质量与自旋实时显示史瓦西半径、内外视界、能层静态限、顺行/逆行 ISCO、吸积效率等物理量。

## 核心机制

### 物理模型（几何单位 G = c = 1，r_s = 2M = 1，故 M = 1/2）

坐标约定：**自旋轴 = +z**，吸积盘在 **z = 0**（θ = π/2）平面；使用 Boyer–Lindquist 坐标。

| 物理量 | 表达式 | 说明 |
| --- | --- | --- |
| 自旋参数 | â = a/M ∈ [0, 1) | 无量纲，0 = 史瓦西 |
| 视界 | r₊/₋ = M ± √(M²−a²) | 内外视界 |
| 能层静态限 | r_s = 2M | 赤道面处 = 史瓦西半径 |
| ISCO（顺行/逆行） | BPT 公式 3+Z₂∓√[(3−Z₁)(3+Z₁+2Z₂)] | 盘内缘 |

- **Carter 分离的零测地线**：守恒量 (E, L_z, Q)，归一化碰撞参数 λ = L_z/E、η = Q/E²。径向势 `R(r) = (r²+a²−aλ)² − Δ[η+(λ−a)²]`，角向势 `Θ(u) = η + (a²−η−λ²)u² − a²u⁴`（u = cosθ，极点正则）。`Δ = (r−r₊)(r−r₋)` **因式分解避免 float32 相消**。
- **初值（ZAMO 四元组种子）**：相机射线 → 正交标架基矢 → 反变 p^μ → 共变 p_μ → (E, L_z, Q)，精确到有限 r。
- **积分器**：仿射时间 RK4（CPU 参考 + GLSL 同构），自适应步长 `dt = clamp(0.16r, 0.03, 1.5)`；转向点用根二分（返回允许侧端点）反射。
- **俘获判定**：r < r₊；近临界光子壳风数 > 8 次视为俘获 → 光子环。
- **吸积盘**：z=0 平面薄环 [ISCO, diskOuter]，顺行开普勒 `Ω = √M/(r^{3/2}+a√M)`，Shakura–Sunyaev 发射率 `I ∝ (r_isco/r)³(1−√(r_isco/r))`、温度 `T ∝ (r_isco/r)^{3/4}(1−√(r_isco/r))^{1/4}`。
- **频率移动**：`g = 1/[u^t(1−Ωλ)]`，束流 `I_ν ∝ g³`。帧拖拽使顺行侧增亮、逆行侧减亮 → 盘左右不对称。

### 渲染

- 每个像素发射一条射线，逐像素数值积分 Kerr 测地线（GLSL，与 CPU 参考同构）。
- 逃逸射线由 BL 动量转回笛卡尔方向，采样程序化星空/星云（引力透镜免费实现：背景星场随测地线弯曲）。
- 远场优化：碰撞参数 `b > 8` 的射线视为直线（弱场偏折 ≲15°）。
- 后处理：HalfFloat 渲染目标 → UnrealBloomPass → OutputPass（ACES 色调映射 + sRGB）。

## 交互

- 拖拽旋转、滚轮缩放（OrbitControls，关闭平移，俯仰限位，绕自旋轴 +z）。
- 自动环绕开关。
- 参数滑杆：质量（对数）、**自旋 â（0–0.998）**、盘温度、盘亮度、盘外半径、星空密度、辉光、曝光、测地线步数。
- 开关：吸积盘、引力透镜（关闭后回到平直空间做对照）。
- 重置按钮恢复默认。

## 美学

- 热盘偏白青的炽热内缘 + 暗红/橙色外缘的天然温度梯度。
- 爱因斯坦环、光子环、D 形影子由测地线自然涌现，非贴图。
- 高自旋下影子明显偏离中心（拖向顺行侧），盘被帧拖拽扭曲 —— 旋转黑洞的视觉签名。
- 辉光突出光子环与内盘，暗色玻璃拟态 HUD/面板。
