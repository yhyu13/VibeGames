# GDD — Schwarzschild 视界 (11_blackhole)

## 一句话

一个基于 **Schwarzschild 测地线逐像素光线追踪** 的黑洞引力透镜实时可视化：完整的爱因斯坦环、吸积盘环绕、光子环与多普勒束流的星际穿越式画面，纯 Web 实时渲染。

## 体验目标

打开页面即见一颗带吸积盘的黑洞。用户可拖拽旋转相机、滚轮缩放、切换是否开启引力透镜、是否显示吸积盘，并实时调节盘温度/亮度、星空密度、辉光、曝光、测地线步数等参数。HUD 依据黑洞质量实时显示史瓦西半径、光子球、ISCO、影子半径、俘获截面、ISCO 轨道速度等物理量。

## 核心机制

### 物理模型（几何单位 G = c = 1，r_s = 1）

| 物理量 | 值 | 说明 |
| --- | --- | --- |
| 事件视界 r_s | 1 | 单位长度的基准 |
| 光子球 | 1.5 r_s | 不稳定光子轨道 |
| ISCO | 3 r_s | 吸积盘内缘 |
| 影子半径 b_crit | (3√3/2) r_s ≈ 2.598 r_s | 临界碰撞参数 |

- **零测地线（笛卡尔 Binet 形式）**：`x'' = -(3/2) h² x / r⁵`，守恒量 `h² = |x×v|²`。
- **积分器**：Leapfrog（kick-drift-kick），自适应步长 `dt = clamp(0.16 r, 0.03, 1.5)`。
- **俘获判定**：`r < r_s`；或在步数耗尽时仍滞留光子球附近（`r < 2`）视为俘获 → 光子环。
- **吸积盘**：XZ 平面薄环 [ISCO, diskOuter]，发射率 `I ∝ r^-3`，温度 `T ∝ r^-3/4`（Shakura-Sunyaev）。
- **频率移动**：`g = √(1−1.5/r) / (γ(1−β cosθ))`，束流 `I_ν ∝ g³`；`β = 1/√(2(r−1))`（ISCO 处 0.5 c）。

### 渲染

- 每个像素发射一条射线，逐像素数值积分测地线。
- 逃逸射线采样程序化星空/星云（引力透镜免费实现：背景星场随测地线弯曲）。
- 远场优化：碰撞参数 `b > 8` 的射线视为直线（弱场偏折 ≲15°）。
- 后处理：HalfFloat 渲染目标 → UnrealBloomPass → OutputPass（ACES 色调映射 + sRGB）。

## 交互

- 拖拽旋转、滚轮缩放（OrbitControls，关闭平移，俯仰限位）。
- 自动环绕开关。
- 参数滑杆：质量（对数）、盘温度、盘亮度、盘外半径、星空密度、辉光、曝光、测地线步数。
- 开关：吸积盘、引力透镜（关闭后回到平直空间做对照）。
- 重置按钮恢复默认。

## 美学

- 热盘偏白青的炽热内缘 + 暗红/橙色外缘的天然温度梯度。
- 爱因斯坦环与光子环由测地线自然涌现，非贴图。
- 辉光突出光子环与内盘，暗色玻璃拟态 HUD/面板。
