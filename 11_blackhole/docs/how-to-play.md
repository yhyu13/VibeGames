# Kerr 旋转黑洞 · 怎么玩

> 不是游戏，是一封写给广义相对论的情书。每个像素都是一条沿 Kerr 测地线数值积分的光线——实时渲染一个**旋转黑洞**：完整的爱因斯坦环、被帧拖拽扭曲的非对称 D 形影子、被拖拽的吸积盘、以及嵌套的光子环。

## 快速开始

```bash
npm install
npm run dev      # 打开 http://localhost:5188
```

## 操作

| 输入 | 作用 |
|---|---|
| 鼠标拖拽 | 环绕视角（绕黑洞轨道） |
| 滚轮 | 缩放，向黑洞坠落 |
| 右键 | 平移（关闭） |
| 控制面板 | 见下 |

## 控制面板

**滑块**：

| 参数 | 范围 | 说明 |
|---|---|---|
| 黑洞质量 | 10^0 – 10^12 M☉ | 质量（对数刻度） |
| 自旋 â | 0 – 0.998 | 0 = Schwarzschild；调到 0.998 看影子滑向顺行侧 |
| 盘温度 | 1500 – 40000 K | 吸积盘黑体色温 |
| 盘亮度 | 0 – 3 | 吸积盘发光强度 |
| 盘外半径 | 4 – 60 r_s | 吸积盘外缘 |
| 星空密度 | 0 – 1 | 背景星空密度 |
| 辉光强度 | 0 – 4 | Bloom 强度 |
| 曝光 | 0.2 – 3 | 色调映射曝光 |
| 测地线步数 | 16 – 256 | 光线积分步数（画质/性能） |

**开关**：自动环绕 · 吸积盘 · 引力透镜。

**HUD 计算真实物理**：史瓦西半径、内外视界、能层（ergosphere）、顺行/逆行 ISCO——光会按爱因斯坦预言的那样运动。
